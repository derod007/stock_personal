# 유형 1 미사용 평가 구간: TOP100 수집 준비

현재 상태: 수집 준비 완료, 실자료 수집 미실행. ChatGPT 실행 환경에 KRX 인증키가 없다. 새 구간의 수익률은 아직 없다.

- 고정 기간: 2023-07-03~2024-06-28, 예정 243거래일 / 두 시장 486개 응답.
- 기존 이전 기간 후보의 가능한 비중첩 구간 중 60봉 입력 최솟값은 2024-07-09다. 이번 평가 구간의 종료일은 그보다 이르다. 이는 입력 날짜의 겹침 점검이며 사후 선택 편향을 없애는 독립성 증명은 아니다.
- 군집·유형1·시가/지정가 실행 정의 유지. 더 좋은 결과가 나오는 기간을 찾아 바꾸지 않는다.
- 운영 저장소·설정·예약·계좌를 변경하지 않고, 계좌를 실행하지 않는다.

## 사용자 PC에서 실행

Cursor나 Git 병합 없이 실행할 수 있다. `type1-holdout-collector.zip`을 새 폴더에 풀고 루트의 `RUN_COLLECT.cmd`를 실행한다. 기존 noramu의 .venv Python이 있으면 실행 파일만 사용하고, 없으면 Windows Python launcher `py -3`를 사용한다.

로컬 터미널이 KRX AUTH KEY를 물으면 기존에 승인받은 키를 입력한다. 입력은 숨겨지고 파일에 저장되지 않는다. 키는 채팅에 보내지 않는다. API 권한이 없으면 중단된다. 공식 이용 안내: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp

성공하면 `READY_TO_UPLOAD:` 뒤에 ZIP 경로가 표시된다. 그 ZIP을 ChatGPT에 첨부한다. 결과는 압축을 푼 코드 폴더의 옆 `type1-holdout-20230703-20240628-data` 폴더와 같은 이름의 ZIP이다. TOP100 원본이 포함된 자료는 GitHub에 게시하지 않는다.

중단됐을 때는 원본이 남는다. 오류를 확인한 뒤 터미널에서 `RUN_COLLECT.cmd --resume`으로 수집만 재개할 수 있다. 이미 받은 정상 원본은 기존 수집기가 날짜·형식·해시로 확인하여 재사용한다. 다른 날짜 자료나 변경된 프로토콜로 이어 쓰는 것은 거절한다. 인증 실패를 다른 공개 키로 우회하지 않는다.

인증 없이 확인만 하려면:

```text
python docs/research/type1_holdout_collect.py
```

수동 실행:

```text
python docs/research/type1_holdout_collect.py --collect --output C:\Users\acdun\Desktop\type1-holdout-20230703-20240628-data
```

## 검증과 범위

신규 wrapper 테스트 6개와 기존 수집/검증 테스트 합계 34개 통과. 인증키 없음 시 네트워크·출력 없음, 정의가 바뀐 수집 재개 거절, 불완전 수집의 ZIP 생성 거절, ZIP 파일 허용목록 및 인증키 문자열 포함 거절을 확인했다. Windows CMD 자체 실행 및 실제 KRX 인증 요청은 이 환경에서 검증하지 못했다.

기존 검증기로 원본을 다시 순위 계산하고 날짜·해시·100종목·제외 규칙을 검사한다. 모든 예정 날짜가 완전해야 성공 ZIP을 만든다. 빈 응답을 임의 휴장 처리하지 않는다.

이번 ZIP은 **TOP100 목록·거래대금 원본 수집 단계**다. 종목별 Yahoo 일봉·업종 준비와 두 모형의 신규 계좌 실행은 이 자료를 받은 다음 단계이며 아직 수행하지 않았다. KRX와 Yahoo 가격을 섞지 않는다.

## 2026-10-18 배포 누락 수정

독립 ZIP에 기존 수집기가 요구하는 `docs/historical-top100-pilot/evidence.json`이 빠져 API 호출 전에 중단됐다. 저장소의 기존 파일을 그대로 포함했다. 이번 기간은 2025년 10월과 겹치지 않아 과거 원본을 복사하지 않는다. 수집기·검증기·달력·프로토콜 해시 및 run-manifest 정의는 유지한다. 수정 ZIP을 같은 코드 폴더에 덮어 푼 뒤 `RUN_COLLECT.cmd --resume`으로 기존 수집 폴더를 재개한다. 별도 --output을 썼다면 같은 경로를 함께 지정한다. CMD 성공/실패 안내도 종료 코드에 따라 분리했다.

압축 해제한 배포본에서 실제 수집기의 재사용 사전 검사를 실행하여 누락 오류 없음, 겹침 0일, 원본 복사 없음 및 manifest 해시 호환을 검사한다. 실제 KRX 인증·Windows CMD 실행은 이 환경에서 검증하지 못했다.
