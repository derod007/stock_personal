# 시가 매수 독립 거래: 자금 한도 제거

PR113의 고정 KRX 입력을 사용한다. 유형1과 나머지 유형, 전체를 집계한다. 보유 수·현금·종목 비중·개별/전체 위험·업종 비중 한도는 사용하지 않는다. 모든 저장 신호를 독립 평가하며 거래당 수익률을 동일 가중한다. 자본금·수량·가상의 투자금액을 설정하지 않는다.

다음 세션 시가 매수, 그 시가 기준 5% 손절·15% 목표, 같은 봉 동시 접촉 손절 우선, 손절 아래 시가 갭은 시가 청산, T+20 종가 만기, 매수 1.0015/매도 0.9985 비용 계수를 유지한다. 목표 위로 갭이 나도 PR107과 같이 목표가 청산이다. 지정가 계획 필드는 사용하지 않는다.

원래 저장된 판단 시점 품질 조건·종목별 비중첩 관찰 구간·기간말 미래창 부족 제외는 유지한다. 이번 제거 대상은 계좌 및 금액 제약이다. 봉/참고가격 불연속 문제는 해당 거래만 미확정(null)으로 남기며 다른 거래 평가를 중단하지 않는다. 이미 종료한 거래는 이후 사건으로 삭제하지 않는다. 미래 품질로 과거 신호를 사전 제거하지 않는다.

완료 부분집합의 평균·중앙·승률·청산·보유봉·종목동일가중을 보고하고 미확정은 0으로 넣지 않는다. 월별 집계는 신호월의 거래평균이며 월간 계좌수익률이 아니다. 자료는 KRX 단일 출처·수정 기준 미확정, 중심은 미래에 학습된 고정 중심이다. 독립 전진검증이나 계좌 수익률을 주장하지 않는다.
