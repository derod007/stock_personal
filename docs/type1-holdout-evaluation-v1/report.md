## 자료와 해석

Yahoo 1405심볼 요청, 1364개 저장. 미확보 41개는 원인별로 summary.json에 남겼다. 과거 TOP100 등장 심볼은 삭제하지 않았다.
분류 신호 3618건, 유형별 {0: 387, 1: 775, 5: 423, 4: 1023, 3: 632, 2: 378}. 분류 제외 사유 {'missing_anchor': 138, 'insufficient_history': 153, 'period_end': 323}.

완주하지 못한 결과의 수익률은 전체 기간 성과로 표시하지 않는다. 중단 이후의 손익은 미확정이며 입력을 고치고 같은 계좌를 재실행하지 않았다. 월별 값은 청산 거래의 실현손익이며 월간 계좌 수익률이 아니다. 종목별 기여도도 청산 거래만 집계한다.

## 고정 조건과 한계

- 중심·유형 1·손절 5%·목표 15%·20세션·한도 규칙은 그대로다. 전체 유형과 유형 1을 두 방식 모두 보고한다.
- opening은 다음 시가 기준 사이징, limit는 T종가 기준 지정가/손절/목표와 기존 PHP 엔진이다. 두 방식 차이를 단순 체결 방식 하나의 효과로 해석하지 않는다.
- Yahoo quote OHLCV를 그대로 보존했다. adjclose 적용·KRX 가격 대체·가격 보정 없음. 이전 데이터셋의 Naver 확인 종가 보정 파이프라인과는 차이가 있으므로 기간 차이의 원인을 전략 하나로 단정하지 않는다.
- 2023-01-01부터 준비 이력을 요청했다. 종목별 60봉 부족은 그대로 분류 제외된다. 기간말 20세션 부족 제외는 기존 코드와 같다.
- 022100·066970의 시장별 식별자를 이어 붙이지 않았다. 03473K.KS는 동일 심볼/KRW/EQUITY 응답을 직접 확인했다.
- Yahoo instrumentType이 EQUITY가 아니거나 심볼/통화가 다르면 해당 응답으로 가격 파일을 만들지 않았다. 이는 원본의 실제 상장 유형을 확정한 판정이 아니다.
- 운영 코드·설정·예약·기존 장부 변경 없음. 새 연구 계좌만 실행했고 병합하지 않는다.

상세 중단 원인, 월별 실현손익, 종목별 기여도, 취소/한도 차단은 summary.json과 별도 재현 ZIP의 실행 기록에 있다. 공개 PR에는 압축 실행 기록을 포함하지 않는다.
