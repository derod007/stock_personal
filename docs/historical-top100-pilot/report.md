# 2025년 10월 거래대금 TOP100 복원 1개월 파일럿

계좌 재현·수익률·운영 수정은 하지 않았습니다. 종가×거래량으로 거래대금을 대체하지 않았습니다.

## 결론

**일부 제한.** 날짜별 전 종목 **실제 거래대금**을 주는 공식 경로는 확인했습니다. 이 환경에서는 본자료를 받을 권한이 없어 18거래일 TOP100을 만들지 않았습니다. 샘플 10행을 전 종목처럼 쓰지 않았습니다.

운영 스캐너와 **같은 TOP100이라고 주장하지 않습니다.** 운영은 20:20 실시간 다음 `accTradePrice`이고, KRX 자료는 일별 확정 주권(및 별도 ETF/ETN) API입니다. 정규장/시간외·KRX/NXT 합산 여부는 명세서 전문 없이 단정하지 않습니다.

## 운영 스캐너 (사실)

코드: `src/KrAmountLeadersClient.php` (`sha256`는 `evidence.json`).

| 항목 | 운영 |
|---|---|
| 시장 | KOSPI+KOSDAQ. KONEX 없음 |
| 대금 | 다음 `accTradePrice`(원). 폴백은 네이버 거래량 표의 대금 칸 |
| 시점 | 예약 20:20, 날짜 파라미터 없음. 과거 일자 조회 불가 |
| 제외 시점 | 행을 맵핑할 때. 제외 후 남는 종목만 순위 |
| 제외 규칙 | `excludedFromAmountRank`: 스팩·기업인수목적·단일종목·ETN, ETF 브랜드 접두, 인버스·레버리지·커버드콜·ETF |
| 유지 | 보통주·우선주·리츠 이름(테스트 픽스처와 동일) |
| 동률 | 대금 내림차순. PHP 8 `usort`는 안정 정렬 |
| 깊이 | 시장별 제외 후 100종까지, 페이지당 100·최대 10페이지, 합친 뒤 상위 100 |
| NXT·시간외 | 코드에 없음 |

스팩·ETF·ETN·단일종목 레버리지는 운영과 같은 함수로 맞췄습니다. 파이썬 이식은 `tests/test_historical_amount_top100_pilot.py`와 `tests/amount_exclude.php`가 같은 이름을 씁니다.

## 원천 조사 (사실)

1. **KRX 정보데이터시스템 전종목 시세** (`MDCSTAT01501`)  
   화면 HTML은 200. `getJsonData.cmd`는 세션 없이 **400 / `LOGOUT`**. 2026년 2월부터 비회원 조회가 막힌 상태와 같습니다. 로그인 우회는 하지 않았습니다.

2. **KRX Open API** (`data-dbg.krx.co.kr`)  
   - 유가증권·코스닥 일별매매정보: 하루 한 번에 그 날 **주권** 매매정보. 필드 `ACC_TRDVAL`(원).  
   - 본호출 키 없음: **401 Unauthorized Key**.  
   - 문서의 샘플 키로 본호출: **401 Unauthorized API Call**.  
   - 샘플 URL은 200, **시장당 10행**. 전 종목이 아닙니다.  
   - ETF/ETN 샘플(`etp/etf_bydd_trd`, `etp/etn_bydd_trd`)도 각 10행.  
   이용: Data Marketplace 회원가입(본인인증) → 인증키 신청 → **카테고리별 활용 신청·관리자 승인**. 약관상 무료·1년이나 즉시 쓸 수 없습니다. 포털 `openapi.krx.co.kr`은 이 점검 중 일시 오류 페이지를 낸 적이 있습니다.

3. **다음 거래대금 API**  
   운영이 쓰는 실시간 API. 과거 날짜 인자가 없습니다. 라이브 순위를 2025-10에 씌우지 않았습니다.

4. **유료 벌크**  
   KRX Data Marketplace 데이터 판매(일별 매매정보 등)는 별도 상품입니다. 구매·우회 없음.

로그인이 필요한 자료는 요청하지 않았습니다.

## 샘플로만 확인한 것

2025-10-02 샘플 KOSPI 10행에서 `ACC_TRDVAL`과 종가×거래량은 **한 건도 같지 않았습니다.** 예: 맥쿼리인프라 대금 8,782,520,125원, 종가×거래량 8,779,876,680원. 그래서 종가×거래량 근사로 복원하지 않았습니다.

샘플 원응답은 Git 밖 `data/raw/research/historical-amount-top100-202510/raw/`에만 둡니다. 해시는 `evidence.json`.

## 상장·상품 구분

- 일자별 Open API 행 = 그 날 시세가 있는 종목. 현재 상장 목록을 과거에 적용하지 않는 방식입니다.  
- 주식 API는 **주권**만 준다고 안내되어 있습니다. ETF/ETN은 증권상품 API.  
- 스팩은 주권에 남을 수 있어 이름 규칙을 그대로 적용합니다.  
- 키 없이 2025-10 전 종목 상품 구분을 확인하지 못했습니다. 확인 못 한 종목은 미확인으로 두라는 규칙은 수집 코드에 반영되어 있고, 이번 산출 목록은 없습니다.  
- 상장폐지·이름 변경 공시 대조는 전 종목 시세 파일이 없어 하지 않았습니다.

## 부하 (실측 / 추정)

실측(이번 `--probe`): 화면 1 + JSON 1 + 본호출 1 + 샘플 5. 동시성 1. 오류 재시도 없음. 소요 약 7초. 샘플 원본은 시장당 3–5KB.

1년 확장 **추정**(키가 있을 때):

| 항목 | 값 | 구분 |
|---|---|---|
| 거래일 | 247 | 추정 |
| 주권만 요청 | 494회 | 하루 2호출 |
| ETF/ETN 포함 | 988회 | 하루 4호출 |

불확실성: 일 한도, 연속 호출 403, 카테고리 승인, NXT/시간외 정의, 주권-only와 운영(다음에서 ETF를 받은 뒤 제외)의 차이.

일봉은 받지 않았습니다. 합집합을 세기 전에는 종목 수를 확정하지 않습니다. 참고 가정만: 월 고유 200–400이면 종목당 1구간 요청 200–400회, 연 고유 600–1200이면 600–1200회. 운영 일봉 캐시에 쓰지 말 것.

## 재현

```
python docs/research/historical-amount-top100-pilot.py --probe
python -m unittest tests.test_historical_amount_top100_pilot
php tests/amount_exclude.php
```

전 종목 수집은 **승인된 개인 키**가 있을 때만 실행됩니다. 키가 없으면 `collect_ran: false`, `collect_status: skipped_no_auth_key`입니다. 키를 Git·채팅·명령 기록에 남기지 마세요.

Windows PowerShell:

```powershell
$env:KRX_AUTH_KEY = Read-Host 'KRX AUTH KEY'
python docs\research\historical-amount-top100-pilot.py --collect
Remove-Item Env:KRX_AUTH_KEY
```

`Read-Host`로 세션에만 넣고, 호출이 끝나면 환경 변수를 지웁니다. 한 줄에 키를 붙여 넣으면 PowerShell 기록에 남을 수 있습니다.

원본 위치: `data/raw/research/historical-amount-top100-202510/` (`.gitignore`의 `/data/raw/`). 운영 캐시 `data/raw/cache`는 건드리지 않습니다.
