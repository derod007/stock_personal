# 1번 계좌용 플레이북 (노라무식 → 변환)

## 1번 계좌 전제

- 국장: SK하이닉스, 삼성전자, 유진테크
- 미장: 마이크론
- ISA/연금/IRP: S&P500 + AI/HBM ETF + 단기채
- 성격: **메모리 집중 중장기**. 레버리지 단타 계좌가 아님

## 가져올 것 / 버릴 것

| 노라무 | 1번 계좌 |
|--------|----------|
| 차트 그림(쌍봉·급락·저점 올림·중간에서 사기) | **그대로 사용** (사는 타이밍·비중 조절 필터) |
| 프로그램 타점 숫자 | 보조 점수화 (`pullback_long_score`) |
| 레버/인버스/배수 | **직접 매매 안 함** → 본주로 바꿔 대응 (SOXS→MU 방향반대, 2배→본주, 코루→삼전) |
| 양빵 | **사용 금지** (애매하면 현금) |
| 3% 초단기 손절 단타 | 최근 저점이 깨질 때만 비중 줄이기 |
| “따라하지 마라”식 저점 스캘핑 | FOMO 금지, 내려올 때만 |
| 애매하면 양빵 | 애매하면 **현금/지금은 안 삼** |

## 운영 규칙

1. **새로 사기 조건**
   - 최근 급락 이후
   - 저점이 직전 저점보다 높음
   - 가격이 최근 고점·저점의 **중간 ±4%** 안
   - 점수 70+ 일 때만 가진 현금의 10~20%씩 나눠서

### 점수 구성 (기본 100점 + 가감점, 최종 0~100)

| 항목 | 배점 | 통과 기준 |
|------|-----:|-----------|
| 저점 상승 | 25 | 현재 구조 저점 > 이전 구조 저점 |
| 고점 유지·돌파 | 10 | 현재 구조 고점이 이전 20봉 고점보다 낮지 않음 |
| 최근 하방 슈팅 | 15 | 최근 5봉 안에 큰 음봉 또는 긴 아래꼬리 |
| 중간 가격 근접 | 25 | 고점·저점 중간값 ±3% 이내. ±3~6%는 12점 |
| 단기 추세 | 15 | 현재가 ≥ 20일선, 동시에 5일선 > 10일선 |
| 거래량 증가 | 10 | 당일 거래량 ≥ 20일 평균의 1.5배 |
| 불법과외1 | -15~+25 | 선호캔들·돌파 후 윗박스 가산, 하락 중 패턴·돌파 추격·과도 랠리 감점 |
| 가로 지지 | +4/+8 | 3회 이상 반복 지지 +4, 저항→지지 전환 +8 |

불법과외1 적용 뒤 0~100으로 제한하고, 가로 지지를 더한 뒤 다시 최대 100으로 제한한다.

2. **갖고 있을 때**
   - 점수 35 미만 + 저점 다시 못 올림 → 올라올 때 일부 줄이기 검토
   - 업황과 충돌하면 차트만으로 전량 사지 말 것

3. **절대 금지**
   - SOXS/코루/2배 상품을 1번 계좌에서 **직접** 매매 (글이 나오면 본주 방향만 반영)
   - 장중 고점 쫓아 사기
   - “오늘 반등하니까” 일시 몰빵

3-0. **불법과외 1편** (`NoramuLesson1`, 원글 [차트 불법과외 -1편](https://www.fmkorea.com/10160571194))
   - 선호 캔들: 장대양봉 → 도지 연속 → **거래량 없는** 장대음봉 → 즉시 장대양봉
   - 그 패턴은 **앞 매물대 돌파 후**에서만 가산. **빠지는 중**이면 신규 매수 후보에서 제외
   - 수렴 **돌파만** 보고 추격 금지 → 돌파 후 **윗구간 박스**가 있어야 롱 가산
   - 저점 대비 **+40%** 후 타이트 구간(수렴)은 신뢰도↓
   - 점수에 ± 가산되며, UI/제안에 `lesson1_note`로 표시

3-0-1. **가로 매물대·2단 손절** (`HorizontalLevels`, 원글 [대원전선 종가베팅](https://www.fmkorea.com/10194043747))
   - 시/고/저/종이 같은 가격대(±0.7%)에 **몇 번 걸렸는지**를 세서 가로 지지·저항을 잡음
   - 연속 봉은 1회로 묶고, **3회 이상** 걸린 자리만 레벨로 인정
   - 저항으로 막히다 지지로 바뀐 자리(`flip`)는 가중치↑
   - 손절은 2단: **타이트 = 당일 저가**, **넓게 = 가로 매물대**
     ("오늘 저가 이탈 안 하면" / "넓게 보면 13400 이탈만 안 하면")
   - 스윙 저점이 너무 멀면(예: 10,110) 손절선을 **가로 매물대(13,440)**로 바꿔 잡음
   - 발굴: `php bin/find_level_setups.php` — 저점 상향 + 고점 재도전 + 아래 매물대

3-0-2. **국내 일봉 당일 고저 보정** (`NaverDailyQuotes`)
   - Yahoo는 장중 국내 종목 당일 봉 OHLC를 null로 주고 `meta.regularMarketPrice`만 채움
     → 합성 봉이 되어 **고가=저가=현재가**가 되고, 타이트 손절선이 현재가로 잘못 잡힘
   - 네이버 «일별 시세»(`sise_day`)의 최근 10거래일 실측 시/고/저/종·거래량으로 덮어씀
   - 고정 날짜 없음. 호출 시점에 네이버가 주는 최근 거래일과 봉의 KST 날짜를 맞춰 붙임
   - 캐시 5분(장중 고저 갱신용). 네이버가 막히면 Yahoo 값 그대로 사용
   - 예(대원전선): Yahoo 저가 14,950(합성) → 네이버 실측 **13,940** = 원글의 타이트 손절가

3-1. **레버 글 대응**
   - SOXS 롱 ≈ MU/반도체 **숏 쪽** → 새로 사기 보류·비중 줄이기 검토
   - 샌디 2배 롱 ≈ SNDK 롱 그림 참고 (레버 호가는 본주가로 쓰지 않음)
   - 코루 ≈ 삼전/국장 롱 방향 참고

4. **주간 루틴**
   - `php bin/score_symbol.php MU`
   - `php bin/score_symbol.php SNDK`
   - 국·미장 핵심 종목 점수와 **손절선**만 메모

## UI/점수 읽는 법 (중요)

프로그램은 **과거 매수가를 평균 내지 않습니다.** 지금 차트에 위 규칙을 적용한 결과입니다.

### 간단 / 분석 모드
- 상단 **간단 | 분석** 토글 (`?mode=simple|analyze`, 브라우저에 기억)
- **간단**: 행동 · 진입·가격 / 손절·매물대 카드 · 차트. tip 숨김
- **분석**: 위 + 패턴·보조 / 작성자 관점 카드. tip은 `?`로만
- **거래대금 스캔**은 별도 화면 (`?scan=kr_amount`) — 단건 분석과 좌우 분할하지 않음
- 최근 원글·시드 이벤트 목록은 UI에서 숨김

### 섹터(업종) 색
- 국장: 네이버 업종명 → 8버킷(반도체·자동차·금융·바이오·소프트웨어·에너지·소재·소비재·기타)
- 스캔 행 왼쪽 색띠·업종 뱃지·칩 필터. 단건 헤더에도 같은 색

| 표시 | 의미 |
|------|------|
| 관심구간 | 고점·저점의 중간 ±4%. **지금 시장가로 사라가 아님** |
| 손절 | 타이트=당일 저가 / 넓게=가로 매물대(또는 최근 저점) |
| 미래 눌림 진입의 손절 | 예정 진입가 아래 구조 저점·가로 지지만 사용. 진입가보다 높은 현재 당일 저가는 제외 |
| 가로 매물대 | 같은 가격대 접촉 횟수. 전환=저항→지지 |
| 저점 상향 / 고점까지 | 구간별 최저가 상승 횟수 / 최근 고점 대비 % |
| 익절 | 1차=직전 고점 / 2차=같은 폭을 위로 한 번 더(또는 그 사이 가로 저항) |
| 도달 | 최근 14봉 하루 평균 움직임으로 손절·익절까지 **거래일 거리**. 날짜 예측 아님 |
| 익절/손절 — 과거 글 | 원글 중앙값 **참고** (분석 모드) |
| 오늘 돈 몰린 곳 | 네이버 테마 전일대비 + 대금 TOP 급등(ETF 제외). 점수·매수 신호 아님 |

가격이 관심 구간보다 **위**이면 → 중간 가격까지 내려오길 기다림.  
손절선 **아래**이면 → 이번 그림 기준으로 새로 살 가격 없음.
