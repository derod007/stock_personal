# 상승 눌림 제외 계좌 비교 v1

2026-10-15 고정 탐색 실험. 이미 알려진 손실을 보고 정한 가설이며 독립 검증이 아니다.

## 한 가지 개입
기준은 PR96의 원조건 baseline이다. recovery_close 완화 계좌를 기준으로 쓰지 않는다.
대안은 ChartPlanEngine의 최종 패턴 선택 이전에 눌림의 선택 자격을 제거한다. 재지지 우선,
회복 대체, 상위 추세와 공통 위험 차단은 기존 코드 그대로다. 눌림 자체 계산은 진단에 남지만
선택 후보가 될 수 없다. 기존 눌림 주문을 사후 삭제하거나 손익만 빼지 않는다.
세 패턴·점수·손절·목표·비용·한도·코드순 우선순위·초기 1억원은 변경하지 않는다.
새 신호가 주문·현금·수량·보유 자리·다음 신호에 미치는 영향은 계좌 전체 재실행으로 계산한다.

## 입력·격리
2024-10-08~2025-10-02, 243세션. PR96의 1248종 KRX JSONL, 고정 일별 TOP100,
전체 섹터 맵·PR94/95 해시를 그대로 사용한다. src/config/전략 지문은 변경하지 않는다.
새 계좌 hist-krx-no-pullback-v1-baseline/variant, 출력 history-research/krx-no-pullback-account-v1.
PR96 baseline 저널 SHA256 620b53a7d97587bd016597b60ffa62751c093d4e22be495aa7ae397a84180101을 필수로 고정한다.
코드·PHP·설정 변경 시 이어가기를 거부한다. 기존 계좌·보고서를 덮어쓰지 않는다.

## 새 추천과 안전 검사
기준은 PR95 frozen baseline과 대조한다. 대안에서는 눌림에 가려졌던 회복형이 새로 선택될 수 있다.
따라서 PR95 추천 합집합으로 제한하지 않고 매번 실제 대안 엔진을 완료봉으로 다시 계산한다.
새 추천에도 PR95와 같은 trace를 적용하고 단절 교차·근거 미확정이면 보류한다.
보류 뒤 다른 패턴을 재선택하지 않는다. 기존 replay의 continuity_source_eligible 플래그는
대안에서 새 as-of trace가 실행되었다는 의미로만 재사용하며 PR95 구성원이라는 뜻이 아니다.
research_eligibility_source에 no_pullback_asof_recomputed를 기록한다.
보유·대기는 TOP100 이탈 후에도 관리하며, 그날 봉·품질·단절 문제가 있으면 기존 원자적 정지 규칙을 유지한다.

## 실행과 검증
양쪽 8세션 및 별도 일괄 대조 후 전체 실행. 같은 길이 기준 완료·대조 전 대안 금지.
기준은 매 실행 PR96 baseline의 같은 시점까지 모든 날짜 포함 이벤트와 대조한다.
계좌 시작의 ID·연구 메타만 비교에서 제외하고 주문·취소·체결·청산·신호·평가 기록은 비교한다.
양쪽 장부 대사, 같은 TradeSimulator 검사, 실제 엔진 as-of 주문 감사, 신규 주문 TOP100 여부,
대안 눌림 주문 0건, 단절/품질 정지 이력, 분할·일괄 대조를 요구한다. 독립 전략 구현은 아니다.
하나라도 실패·정지하면 다음 단계 중단. 종료 코드를 바꾸거나 정지일·종목을 제외하지 않는다.
기간말 강제 청산 없음. 보고서는 총자산·실현/미실현·낙폭·거래 구성·추가/누락/수량변화·전후반을 비교한다.
목표 수익률·필터 탐색은 하지 않는다. 원가격 수정 기준 미확정, 현재 업종의 과거 적용,
미탐지 기업행사, 공통 위험/추세 전체의 미추적 의존성 및 일봉 체결 가정은 남는다.
