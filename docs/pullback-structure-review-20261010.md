# 상승 눌림 구조 검토 — 2026-10-10

현재 상승 눌림은 서로 다른 국소 저점 구조를 함께 선택한다. 그러나 **저점상향 유지형만 남기면 성과가 좋아진다는 결과는 두 기간에서 반복되지 않았다.** 이번 검토로 운영 필터·진입·손절·목표를 바꾸지 않는다.

## 범위와 검토 순서

기준 main 커밋은 `bbb77abae0566348a306e9b04fd4ff5243250e92`, 패키지의 전략 지문은 `934012285f2ddb3867fff4576dba05fb7df290a36a987c36fc260e8917bbe465`, 프로필은 account1/상위 추세 적용이다. 패키지 ZIP SHA256은 `1fe0fe05335393f447f0fe0002b56bb2f46812eda3c5804eb8ea1a23010257b2`다.

[고정 기준](pullback-structure-protocol.md)을 작성하고 A 입력만으로 최종 선택 상승 눌림 157건을 분류했다. 이후 L1/L2 표시를 덧붙인 A 120일 차트 전부를 20개 모음 화면에서 육안으로 대조했다. 라벨 수동 변경은 0건이다. 그 다음 B/C를 열어 기존 거래 결과를 연결했다. 자동 분류의 차트 대조이며 저자 또는 독립 전문가의 정답 라벨이 아니다. 이전 연구의 집계와 일부 결과를 이미 알고 있어 완전한 맹검은 아니다.

H에도 긴 횡보나 하락 후 회복이 들어가며, D에도 큰 추세는 상승인 경우가 있다. 가장 최근 확정 피벗이 오래전이면 현재 조정의 시작점을 정확히 표현하지 못할 수 있다. 이 분류는 추세·첫 박스 돌파·엔벨로프·수평 저항을 종합한 원문 패턴 판정이 아니다.

원문 엔벨로프 글의 ‘앞 저점 상향’은 정배열·이격·엔벨로프라는 맥락 안의 선호다. 회복형 글의 저항 회복→높은 저점 순서도 별도 패턴 맥락이다. 이를 기존 상승 눌림의 보편적 필수 조건으로 곧바로 옮길 수 없다. ATR 배수·봉 수·거래량 비율과 이번 좌우2봉 피벗은 프로그램 선택이다.

## 한계와 다음 판단

- 저장 스캔에서 사후 고정한 종목군이며 당시 TOP100이나 전체 시장이 아니다. 종목 선택 편향이 남는다.
- 동일 종목·인접일·겹친 보유는 독립 표본이 아니다. 이번 표는 군집 보정한 유의성 검정이 아니다.
- 수정주가 여부와 과거 시점에 보였을 가격의 동일성은 확정하지 못했다.
- 157건은 선택 사례다. 미선택 376건과 신호 없음 등의 누락률·과잉 차단은 이번 범위에서 판정하지 않았다.
- 프로토콜에 언급한 ATR 거리의 추가 연속값 진단은 이번 산출물에 포함하지 않았다. MA20·종가·피벗 좌표만 기록했으며 분류 입력에 ATR/MA20 거리 임계값은 없다.
- U에서 `bullish_recovery:false`는 구조 부족에 따른 조기 반환 기본값이다. 실제 재상승 실패를 뜻하지 않는다. `reason`을 우선 해석해야 한다.

다음에는 수익률 최적화보다 **현재 조정의 시작 고점과 저점이 무엇인지**를 원문별로 명확하게 정의하는 것이 우선이다. 그 정의를 다시 고정한 뒤 미선택의 대기·무효·목표 없음 사례와 함께 대조해야 선택 누락을 평가할 수 있다. 이미 살펴본 두 기간은 탐색 자료로 두고, 운영 변경을 검토할 때는 이후 완료봉 또는 별도 미사용 기간에서 확인한다. 이번 결과에 맞춰 피벗 봉 수나 창을 바꾸지 않는다.

```sh
python docs/research/pullback-structure.py test
python docs/research/pullback-structure.py classify --pack=PACK > labels-repro.json
python docs/research/pullback-structure.py compare --pack=PACK --labels=docs/pullback-structure-labels-20261010.json > comparison-repro.json
```

검증: 구조 경계·피벗 확정 지연·바깥봉 모호함·미완료 분모 관련 8개 검사 통과. classify 재계산 일치, 157건/종료137건 및 기간별 기존 평균 일치, 프로덕션 파일 변경 없음. GitHub CI 결과는 별도로 확인하지 않았다.
