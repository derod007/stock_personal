# 기존 역저점 점수 단독 진입 연구 v1

결과 집계 전 고정. 고점판독기 src/NoramuTopPattern.php의 analyze를 그대로 호출한다. 이 파일은 확인한 origin/main과 동일하다. 역저점 status에 기존 가산점 confirmed=12, warning=5, watch/none=0만 적용한다. topPenalty·다른 특징점수·유형1·추세/RR/섹터 필터는 적용하지 않는다. phase는 기록하며 조건으로 쓰지 않는다.

## 범위와 한계

- 보유한 같은 출처 KRX 2023-07-03~2024-06-28 243일 TOP100 전체(24,300관찰). 기존 군집/추천 표본에 제한하지 않음. 앞선 유형1 연구와 같은 가격 자료이나 새 신호 연구다.
- 원문 설명 자체의 완전한 재현이라는 주장이 아니라 현재 구현 검증. 반전 가격의 백분율 조건은 실제 가격의 하락률과 같지 않다. 코드의 파동/고점 시도 근사도 그대로 유지한다.
- 입력 이력은 판단일 포함 최근 **65개 평가 가능한 완료봉**으로 고정. detectTop의 최대 lookback=65에 맞추며 상하반전 anchor에 오래된 가격이 추가 영향을 주는 것을 방지. 실제 서비스는 제공받은 전체 이력에서 반전 anchor를 계산하므로 실행 이력 길이가 다르면 결과가 다를 수 있다. 운영과 바이트 같은 판독기를 사용하지만 입력창은 연구의 고정 가정이다.
- 65봉 부족, 판단일 봉 없음, 최근90일 비정상봉, 해당65봉 사이 기준가격 불연속은 진입 시점 품질 차단. 거래량0도 자료 문제로 제외. 미래 정보로 진입을 거르지 않음.
- 점수는 T종가 확인 후만 알 수 있음. T+20 창이 완성되는 신호만 거래집계. 마지막20일 점수 분포는 유지하고 거래집계 제외.

## 진입·청산

세 경로를 사전에 고정한다: 전체(점수>=0) 대조, 역저점>=5, 역저점=12. 점수/청산 최적화 없음. 각 경로에서 최초 적격 신호를 채택하고 같은 종목 T..T+20은 다시 세지 않음. 최초신규상장/TOP100최초등장이라는 의미 아님. 세 경로는 같은 종목·날짜로 짝지은 인과비교가 아님.

기존 연구 TradeSimulator와 IndependentTradeDiagnostic을 그대로 사용: T종가 지정가, 다음1봉 유효, 손절 T종가−5%, 목표+15%, 최대20봉. 비용 편도 수수료10bp·슬리피지5bp. 체결 전 목표 터치 등은 기존 보수적 취소 규칙 유지. 같은 봉 손절/목표는 모형상 손절 우선. 독립 동일금액 거래이며 현금·보유수·업종 한도 없는 **비계좌** 연구. 거래 차단/미체결도 집계한다.

별도로 T+1 시가 대비 1/5/10/20세션 종가, 20세션 고저가 변화를 손절 없이 측정한다. 이는 가격경로이며 실제 매매 손익과 구분한다. 이 관찰에도 기준가격 불연속·누락·비정상봉은 미확정 처리하고 이후를 채우지 않는다.

전체·반기·월별·종목동일가중·상위5종목 기여 제외를 보고한다. 현재 자료는 이미 연구한 과거 구간이며 독립 검증이라고 부르지 않는다. 점수가 높을수록 좋아지는지, 실제 수익인지, 시기/종목에 편중되는지 판단한다. 유리해도 바로 운영 반영하지 않는다.

실제 자료·성과는 비공개 산출물로 보관. 코드·합성 테스트·방법론만 PR. 계좌 재실행·운영 변경·병합 없음.
