# 탈락 종목 자동 후속 추적

기존 `python bin/paper_daily.py --config=config/paper-kr.json` 예약을 그대로 사용한다.
한국 스캔 이후 계좌 처리의 finally 단계에서 후속 추적을 실행한다. 추천/보유 0건에도 실행하며 계좌 처리 실패와 별개로 관측한다. 미국·고정 연구 계좌에는 연결하지 않는다.

## 화면과 운영 상태

- 탈락 로그 화면 하단: 누적 사유별 결과, 자동 지정가/기존 추천 재검증, 최근 200개 개별 관측 결과.
- 주간 화면 및 `bin/paper_weekly.php`: 선택 주의 **판정 세션**에 속한 종목의 이후 성과를 최신 갱신 시점까지 집계. 그 주 안의 수익률이 아니다. 계좌 거래가 없어도 출력한다.
- 기존 실행 로그의 `followup.status`는 saved/partial/no_observations/failed. 운영 success가 후속 추적 성공을 의미하지 않는다. 후속 추적 실패는 운영 주문 결과/종료 코드를 바꾸지 않는다.
- 자동 단계 최대 2400초. 강제 종료 시 실행 로그 running 또는 후속 추적 running과 화면의 마지막 갱신 시각을 확인한다.

## 기준

기존 `rr-audit/<account>/*.json`의 observed_scan_only 원본만 사용한다. 미리보기/과거 연구 합집합은 제외한다. 종목×세션별 최초 기록을 사용하며 재실행은 중복 집계하지 않는다. 이후 실행에서 달라진 판정으로 최초 판정을 덮지 않는다. 매일 같은 종목이 탈락하면 별도 관측이며 독립적인 거래 표본이라는 뜻은 아니다.

판정일 종가 대비 이후 1/3/5/10/20개 완료 일봉의 종가 수익률과 해당 기간 고가/저가 기준 최대 상승/하락을 계산한다. 상승폭 하한 0, 하락폭 상한 0. 실제 종목의 완료 봉을 세므로 거래정지/누락을 거래소 달력으로 보충하지 않는다. 관측 부족은 null이며 평균 분모에 넣지 않는다. 당시 캡처보다 앞선 후속 봉이 있으면 사후 관측으로 집계를 보류한다.

사유 그룹: 손익비, 거래량(선택 패턴의 거래량 미충족), 추세, 위험, 그 외. 사유별 중복 포함을 명시하고 실제 평가되지 않은 조건을 탈락으로 만들지 않는다. 손익비/위험/추세가 겹친 종목은 여러 그룹에 들어간다. 이후 상승/하락은 기회 상실/손실 회피의 관측 자료이지 조건별 인과효과·실제 매매 손익이 아니다.

지정가 후보 및 기존 ready 계획은 당시 손절/목표/진입값으로 PaperRrAudit::outcome과 기존 TradeSimulator를 재사용한다. 다음 3봉 유효 지정가, 체결 뒤 최대 20봉, 편도 수수료 10bp/슬리피지 5bp. 순수익률 평균은 청산 거래만 포함하며 자금 한도 없는 독립 거래다. 원래 지정가 정수 절삭/호가단위 제한은 동일하다. 운영 주문이나 전략 지문은 바꾸지 않는다.

## 수집과 보존

TOP100에서 빠진 종목도 미완료 관측이 있으면 종목별 1회 조회한다. 전용 캐시에 기존 YahooChartClient의 네이버 일봉 병합을 사용하고 운영 수집 파일을 수정하지 않는다. 기존 클라이언트가 오래된 캐시로 폴백하면 확보된 봉까지만 집계하며 마지막 봉 시각과 관측 중 상태를 남긴다. 데이터 없음/변경/품질 오류를 수익률 0으로 대체하지 않는다.

원본 해시·과거 일봉 일치·중복/비정상 가격 검사 실패 시 계산 보류. 모든 기간 및 모의 거래가 끝난 관측은 결과를 고정하여 추가 조회하지 않는다. 완료 이후 발생한 공급자 가격 정정은 자동 반영하지 않는다. 수집 오류나 원본 변경으로 보류된 관측은 재시도한다.

`PAPER_STATE_DIR` 또는 저장소 옆 stock-personal-paper 아래:
- `followup/<account>/latest.json`: 원자적으로 교체하는 최신 파생 결과
- `followup/<account>/<시각>-<고유번호>.json`: 실행별 결과 보존
- `followup/<account>/evidence/<sha256>.json`: 결과에 사용한 가격 원본. 행의 price_hash로 대조
- `followup/<account>/prices/`: 전용 가격 캐시

계좌별 파일 잠금으로 동시 갱신을 차단한다. 원본 감사 로그·계좌 원장은 수정하지 않는다. 자동 삭제 정책은 없으므로 용량은 운영 환경에서 관리한다.

## 수동 재실행 / 오프라인 검증

```bat
php bin/paper_followup.php --account=paper-kr
php bin/paper_followup.php --account=paper-kr --prices=data/ohlcv
```

prices에는 SYMBOL.json 또는 SYMBOL_2y_1d_closed_v2.json 일봉 배열. `--as-of=2026-09-23T20:20:00+09:00`처럼 과거/현재 관측 마감 지정 가능(미래 금지). 현재 저장 결과보다 과거인 마감은 최신 결과를 덮지 못한다. 과거 재현은 별도 PAPER_STATE_DIR에 원본 로그를 복사해서 실행한다.
