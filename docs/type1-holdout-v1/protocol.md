# 유형 1 미사용 평가 구간 수집 프로토콜

결과를 보기 전에 고정: 2023-07-03~2024-06-28. 당시 KOSPI+KOSDAQ 거래대금 TOP100을 기존 제외 규칙으로 만든다. 현재 상장 목록이나 현재 TOP100으로 과거를 대체하지 않는다.

이 기간은 기존 계좌 평가 구간보다 앞선 별도 역사 구간이다. 미래 기간에서 만들어진 중심을 과거로 가져가는 **미사용 역사 구간 검증**이지, 당시 알 수 있었던 모델을 사용한 전진 검증이나 완전히 독립된 실험이라고 부르지 않는다. 연구 전체의 사후 선택 가능성도 남는다.

고정 중심 SHA256: 768c083a5c51cb452dad032f018a97b20527d07ff6fc1ab36559b53c406b4dfd. 유형 1 및 전체 유형 대조군을 유지한다. PR #107의 다음 시가 모형과 PR #108의 T종가 지정가 모형을 별도로 평가하며 결과를 합치지 않는다. 신규 조건·손절·목표·비중 최적화 없음. 계좌는 별도 신규 연구 계좌만 사용한다.

자료 단계:
1. KRX의 두 시장 일별 거래대금 원본, 날짜별 선정 목록, 재정렬 검증 및 해시 고정.
2. 합집합 종목의 Yahoo quote OHLCV 일봉 확보 및 식별자·기간·조정 기준 확인. KRX 가격과 섞지 않는다. 최소60봉을 위해 평가 시작 전 이력을 확보한다. 가격 누락/오류는 별도 표시하고 계좌 규칙을 완화하지 않는다.
3. 평가에 필요한 가격·업종 자료가 확보된 후에만 고정된 두 실행 모형을 신규 실행한다. 첫 단계 ZIP만으로 수익률을 산출하지 않는다.

이번 수집 도구는 1단계만 실행한다. 원본 응답·인증키는 GitHub에 게시하지 않는다. 인증키는 환경변수 또는 로컬 터미널 숨김 입력으로만 사용하며 파일·ZIP에 넣지 않는다. API 인증 실패 또는 불완전한 시장 응답은 중단/검증 실패다. 빈 응답을 휴장으로 추정하거나 다른 날짜로 대체하지 않는다.

새 입력 결과를 보기 전의 분석 기준: 완주 여부, 비용 반영 계좌 수익률·최대 낙폭·거래수·한도 차단·취소 원인·월별 손익·종목 집중도를 두 모형과 각 대조군별로 전부 보고한다. 한 방식의 좋은 결과만 선택해 나머지를 숨기지 않는다. 과거 값과의 단순 합산으로 독립 표본 수를 부풀리지 않는다.
