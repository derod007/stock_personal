# 돌파 종목 목표가 모의 비교

```sh
php bin/paper_target_comparison.php --account=paper-kr --source-dir=docs/paper-kr-5d-source
```

현재 저장 증거는 --source-dir 생략. 결과는 PAPER_STATE_DIR의 target-comparison/paper-kr에 저장한다. 화면: paper_rr.php?account=paper-kr&mode=forward&target_comparison=1. 기존 원본·운영 계좌·전략을 변경하지 않는다.

## 고정 규칙

- 목표 진단에서 확인 완료이며 기존 20봉 고점을 종가로 엄격하게 돌파한 모든 사례를 선택한다. 동결 표본 13건이다. 단일 조건 제거 가정 2건은 포함하지 않는다.
- 원본 해시·현재 공식 재현·저장 가격·후속 증거 해시와 연결을 확인한다. 현재 공식 연구이며 과거 코드 검증은 아니다.
- 대안은 판정 시점에 알려진 가장 가까운 상단 저항 후보 1개다. 좌우 2봉 확정 고점 중 진입가보다 높고 이후 종가가 초과하지 않은 후보를 저장 전체 기간에서 찾는 기존 진단 정의를 그대로 쓴다. 후보 없음은 제외, 낮은 RR은 유지하며 더 먼 후보로 대체하지 않는다.
- 진입·손절·신호 시점·3봉 유효기간·20봉 보유·수수료·슬리피지·일봉 체결 순서 규칙은 동일하다. 목표 및 이에 따른 RR·통과 상태만 달라진다.
- 독립 위험·품질·확인 조건 차단은 유지한다. 상위 추세는 동일 규칙으로 다시 계산한다(일 추세 하락 차단, 주 추세 하락은 일 상승 및 RR>=2 필요). 근거 미확인은 통과로 추정하지 않는다.
- 두 방식이 모두 비교 가능한 사례만 집계하며, 제외 사례는 목록에 남긴다. 통과한 계획만 다음 완료봉부터 모의 체결한다. 취소 사유·미체결 만료·추적 중·후속 봉 없음을 구분한다.
- 청산 평균에 진행 중 결과를 0%로 넣지 않는다. 양쪽 동일 사례 청산 차이는 별도 표시한다. 기존 방식이 거래하지 않은 사례의 대안 결과를 기존 대비 확정 개선으로 표현하지 않는다.
