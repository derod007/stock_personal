# 본전 손절 연구 마무리 · 2026-10-10

연구 규칙은 그대로다. 완료봉 종가가 실제 체결가보다 3% 이상 높으면 다음 세션부터 손절을 체결가로 올린다. 진입, 목표, 3봉 주문, 20봉 보유, 비용, 일봉 순서는 기존 `TradeSimulator`다. 이 규칙을 운영 전략이나 전략 지문에 연결하지 않았다. 2%나 5%로 다시 맞추지 않았다.

공통 종료만 평균에 넣었다. 연구 때문에 새로 끝난 거래는 그 평균에 넣지 않았다. R은 순수익률을 체결가 대비 초기 손절 폭으로 나눈 값이며 계좌 수익률이 아니다.

| | 최근 공통 종료 70 | 이전 공통 종료 67 |
|---|---:|---:|
| 기존 평균 | +0.8914614286% | +0.2641283582% |
| 연구안 평균 | +2.0058557143% | −0.5150089552% |
| 기존 평균 R | +0.2512395016 | +0.1706652463 |
| 연구안 평균 R | +0.2844600537 | −0.0035664774 |
| 개선 / 악화 / 동일 | 14 / 6 / 50 | 12 / 10 / 45 |

최근 수치는 `docs/pullback-breakeven-20261010.json`의 `summary`와 같다. 선택 82건 중 공통 종료 70이다. `incomplete -> closed` 1건은 `newly_closed`이며 공통 평균에 없다.

이전 수치는 같은 브랜치의 명령으로 로컬 전체 replay를 읽어 확인했다. 선택 75, 공통 종료 67, 새로 끝난 거래 0이다. 출력은 `%TEMP%\pullback-breakeven-prior.json`이다.

최근 기간은 퍼센트 평균이 높아졌고, 이전 기간은 퍼센트 평균과 R이 모두 낮아졌다.

**두 기간에 걸친 일관된 개선을 확인하지 못했으므로 운영 적용 보류. 기존 고정 손절 유지.**
