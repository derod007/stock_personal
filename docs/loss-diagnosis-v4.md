# v4 탈락·손실 진단과 단일 조건 실험

## 사용법

v3의 profitability-research 아티팩트를 내려받아 data/research에 압축을 풉니다.

```bash
python3 -m unittest discover -s tests -p 'test_diagnosis.py'
php tests/v4.php
python3 bin/diagnose_research.py --root=data/research
python3 bin/run_research.py
```

진단은 재생 전에 실행해야 기존 거래를 분석합니다. 재생 결과는 같은 폴더의 종목별 결과를 갱신하므로 원본은 보관하세요.
Actions의 Frozen research diagnosis는 v3 실행 34879718710의 입력/결과를 받아 진단한 후 같은 OHLCV로 실험합니다.
해당 아티팩트가 만료되면 다운로드 단계는 실패합니다. 보관한 원본으로 위 로컬 명령을 실행하세요. 새로 수집한 데이터는 동일한 재현으로 표시하지 않습니다.

## 출력

- diagnosis.md: 손실 분류와 탈락 사유별 후속 움직임 표
- diagnosis.json: 전체 집계
- loss-examples.json: 손실 거래의 종목·시각·분류·순손익
- report.md / summary.json: 기존 네 방식과 candidate_recovery_fixed 비교
- 종목별 JSON/JSONL: 거래 내역과 시점별 판단 근거

탈락 사유 표의 수익률은 제외 후보가 관찰된 종가에서 이후 10봉 종가까지 변화입니다.
중복 날짜 관찰이며 실제 체결 수익률이나 필터 제거의 인과 효과가 아닙니다.
게이트별 pass/fail은 해당 단계에 도달한 후보만 포함합니다. 그룹별 조건 구성이 다르므로 단순 평균 비교로 필터를 제거하면 안 됩니다.

## 손실 분류

상호 배타 우선순위:

1. 체결/청산일을 제외한 중간 거래일 종가가 체결가 대비 2% 이상 오른 뒤 순손실
2. 위 조건에 해당하지 않으며 보유 3봉 이내 손절
3. 시간 만료로 순손실
4. 기타 순손실

일봉에서 체결 전 고가나 청산 후 가격을 수익 반납으로 잘못 계산하지 않도록 양끝 거래일을 제외합니다.
따라서 장중 상승 후 반납은 포착하지 못할 수 있습니다. 2%/3봉은 고정 진단 기준이며 최적화된 매매 조건이 아닙니다.

## 선택한 단일 실험

앞 60% candidate_fixed 손실 65건 중 조기 손절 41건이 가장 큰 분류였습니다.
이를 근거로 **신호일 종가 > 전일 고가** 하나만 후보 진입에 추가했습니다.
후보 가격, RR>=1.5, 추세/위험 차단, 손절·목표·수수료·보유기간은 candidate_fixed와 같습니다.
실제 주문·포지션 중복 제한을 적용하므로 이후 거래 기회는 두 방식에서 달라질 수 있습니다.

실험은 연구 CLI에서만 선택됩니다. 화면과 실시간 추천에는 적용하지 않습니다.
기존에 본 자료에서 원인을 찾고 실험했으므로 validation/holdout도 새로운 독립 검증으로 주장하지 않습니다.
