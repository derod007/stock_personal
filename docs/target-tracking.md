# 누적 목표 비교 연구 자동 추적

기존 KR 20:20 예약 작업의 `paper_daily.py`에서 운영 스캔/계좌 처리와 일반 후속 추적 뒤에 `paper_target_tracking.php`를 실행한다. 예약 시각과 Windows 작업 자체는 변경하지 않는다. 추천 0건, 계좌 실행 실패, 일반 후속 실패 때도 연구 갱신을 시도한다. 스캔 실패 때도 이미 저장된 연구 거래를 추적한다. 연구 실패는 독립 실행 로그의 target_tracking에 기록하며 운영 계좌 실행 상태를 덮지 않는다.

## 최초 실행과 이전 13건

```sh
php bin/paper_target_tracking.php --account=paper-kr
```

보관된 모든 거래대금 스캔 기록에서 확인 완료 + 이전 목표 고점 종가 돌파 조건을 찾는다. 최근 5일로 제한하지 않는다. 기존 자료가 운영 상태에 있다면 첫 예약 실행에서 자동 등록된다. 별도로 깃의 동결 자료를 가져오려면 한 번 실행한다:

```sh
php bin/paper_target_tracking.php --account=paper-kr --source-dir=docs/paper-kr-5d-source --saved-evidence
```

이 명령은 원본 자료를 변경하지 않고 PAPER_STATE_DIR/target-tracking/paper-kr에 후보와 가격 증거를 복사·보존한다. --saved-evidence는 가격을 수집하지 않는다. 이후 일반 예약 실행은 이 후보들을 계속 추적한다. --prices=디렉터리, --as-of=시각은 오프라인 검증용이다. 미래 시각 및 최신 원장보다 오래된 갱신은 거절한다.

## 보존과 갱신

- 종목×판정봉의 첫 저장 기록을 사용하고 재실행 시 중복 등록하지 않는다. 원본이 달라져도 기존 후보를 교체하지 않고 충돌을 기록한다.
- 원본 일봉·판정·진입·손절·기존/대안 목표·후보 선정 근거·등록 시각·계산 버전·실행 버전을 고정하고 체크섬으로 확인한다. 원본 전략 버전 미기록은 미기록으로 남긴다.
- 독립 위험 차단과 상단 후보 없음, 손익비 미달도 원장에 남긴다. 통과한 계획만 모의 체결한다. 차단된 옛 판정을 나중에 통과로 재작성하지 않는다.
- TOP100/최근 기록일에서 빠지거나 원본 감사 파일이 사라져도 자체 원본 사본으로 계속 추적한다. 미완료 연구 거래의 종목 가격을 별도로 수집하므로 일반 후속 관찰 20봉 완료와 무관하게 주문/거래 종료까지 갱신한다.
- 기존 3봉 주문 유효기간·체결 이후 20봉 보유 한도·비용·일봉 취소/손절 우선 규칙을 유지한다. 다음 완료봉부터 평가하며 늦게 저장된 판정과 원본/가격 불일치를 차단한다.
- 실행 코드 버전이 바뀌면 기존 후보를 새 규칙으로 재계산하지 않고 오류로 보류한다. 명시적 호환 검증이나 별도 버전 처리가 필요하다.
- 가격 오류 때 마지막 성공 결과를 남기되 update_error와 이전 평가 시각을 표시한다. 종료 결과는 고정하고 다시 수집하지 않는다. 프로세스 잠금과 임시 파일/원자적 교체, 실행별 원장 이력, 가격 해시별 증거를 보존한다.

## 화면과 주간 집계

`paper_rr.php?account=paper-kr&mode=forward&target_tracking=1`에서 누적 원장과 최근 예약 실행 상태를 본다. 기존 동결 연구 화면은 그대로 유지한다.

주간 화면과 JSON에도 연구 요약을 별도로 연결했다. 후보/통과는 판정일, 체결/청산은 발생일, 최초 등록은 등록일 기준이다. 이전 주 후보의 이번 주 체결·청산도 포함한다. 현재 추적·오류 상태는 현재 상태이며 과거 주말 상태로 표현하지 않는다. 계산/원본 전략 버전별로 분리하고 운영 계좌 수익과 합산하지 않는다. 미청산은 순손익 평균에서 제외한다.

모의 개별 거래이며 포트폴리오 자금 한도를 적용하지 않는다. 자동 조건 완화·실전 주문·운영 전략 변경은 없다.

## 검증 결과

GitHub Actions에서 동결 입력 등록 시 후보 13건, 대안 조건 통과·체결 2건, 미청산 추적 2건, 갱신 오류 0건을 확인했다. 원본 디렉터리를 제공하지 않는 재실행에서도 후보와 결과가 유지됐다.

합성 가격 경계 검사에서 3번째 봉 체결 후 판정 20봉 시점에는 보유 18봉으로 추적을 계속하고, 판정 22봉에서 보유 20봉 기간 청산하는 것을 확인했다. 이는 실제 피에스케이/HPSP의 청산 결과가 아니라 추적 수명 검증이다. 이후 주간 요약에 과거 후보의 이번 주 청산이 포함되며 종료 결과를 재수집하지 않는 것도 확인했다.

중복 실행·변경 원본·계획 체크섬·실행 버전 변경·공급자 오류·동시 쓰기·원본 파일 불변 및 예약 경로 실패 처리를 검증했다. 실제 사용자 Windows 예약 실행과 실시간 공급자 응답은 사용자 환경에서 다음 실행 로그로 확인해야 한다.
