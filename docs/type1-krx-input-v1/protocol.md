평가 기간은 2023-07-03~2024-06-28 그대로다. 이번 작업은 가격 입력 준비이며 계좌를 실행하지 않는다. PR110 Yahoo 계좌/판정/원본은 보존한다.

준비 이력은 기존 Yahoo 요청 범위에 대응하는 2023-01-02~2023-06-30, 달력 기준123거래일/246시장 응답이다. 최소60봉과 기존 엔진 최근90일 품질 검사를 평가 시작일부터 수행할 수 있도록 상반기를 요청한다. 신규 상장/거래정지 등으로 종목별60봉이 없으면 임의로 채우지 않는다. 준비 기간 TOP100은 검증기의 부수 출력일 뿐 평가 종목 선정이나 후보 수를 바꾸는 데 쓰지 않는다. 전체 시장 원본에서 기존 평가 후보 종목의 이력을 꺼낸다.
