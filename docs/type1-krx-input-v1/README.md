PR110 후속. 2026-10-18 진행/완료(추가 원본 수집 대기). 계좌 실행 없이 저장 원본을 감사하고 독립 준비 이력 수집기를 작성했다.

여기서 정상은 가격의 일별 형식/관계 검사다. 수정주가 일관성·기업행사 처리·거래 가능성을 보장하지 않는다. 0 이하 가격을 실제 체결가격으로 쓰지 않는다. 참고가격은 종가에서 전일대비 가격차를 뺀 값이며 전일이 아닌 이전 관측일과 비교될 수 있다. 경보를 분할/무상증자로 확정하거나 보정계수로 사용하지 않는다.

2024-01-15에는 평가 후보 합집합 중 1,355개 정상 행과 9개 0 이하 가격 행이 있었다. PR110 중단 대표 003010.KS, 012330.KS, 041510.KQ의 KRX OHLC는 모두 정상이다. Yahoo 계좌 결과는 보존하며 KRX 값으로 덧대지 않았다.

## 실행 방법

`type1-krx-prehistory-collector.zip`을 **새 폴더**에 풀고 `RUN_COLLECT.cmd`를 실행한다. KRX 키를 로컬 숨김 입력창에 입력한다. 채팅에 키를 보내지 않는다. 기존 수집 데이터와 다른 `type1-krx-prehistory-20230102-20230630-data` 폴더가 생성된다.

대상은 2023-01-02~2023-06-30의 123일, 두 시장246응답이다. 상반기 준비 이력만 추가하며 기존 243일 자료는 다시 요청하지 않는다. 완료하면 `READY_TO_UPLOAD`에 나온 결과 ZIP을 전달한다. 실패하면 파일을 보존하고 같은 폴더의 터미널에서 `RUN_COLLECT.cmd --resume`으로 이어받는다.

이전 배포 누락 원인인 `docs/historical-top100-pilot/evidence.json`을 포함했다. 기존 폴더/해시 검사도 키 입력 전에 수행한다. 수집기/검증기 본체는 변경하지 않았다. 수집 도구는 TOP100을 부수 산출하지만 준비 구간 TOP100을 평가 후보로 쓰지 않는다.

현재 실행 환경에는 KRX 키가 없어 실수집은 수행하지 않았다. Windows CMD 및 실제 인증 요청은 검증하지 못했다. ZIP을 푼 상태의 의존성/해시/달력 및 실패 시 무쓰기 검사를 포함한8테스트를 통과했다.

## 다음 입력 판정

준비 자료를 받은 뒤 기업행사/참고가격 불연속이 60봉 특징과 보유기간을 가로지르는 범위를 먼저 정리한다. 원인이 구분되지 않는 항목은 미확정으로 남긴다. KRX 가격 기준은 `krx_tdd_ohlcv_adjustment_unverified`로 별도 표시하며 기존 Yahoo 도구의 가격 기준 검사를 우회하지 않는다. 계좌 실행 프로토콜이 정리되기 전 새 수익률을 산출하지 않는다.

달력 근거: 한국천문연구원 2023 월력요항, 삼성증권 5/1 휴장 공지, 대신증권 5/29 대체공휴일 휴장 공지. 정확한 URL은 `trading-calendar.json`에 있다. 빈 API 응답을 휴장 근거로 사용하지 않는다.

운영·설정·예약·기존 원본·장부 변경 및 병합 없음. 원본과 전체 work-log는 공개 업로드하지 않는다.

공개 ZIP 업로드는 자동 승인 검토에서 거절되어 PR에는 ZIP을 포함하지 않는다. 로컬 재생성: `python docs/research/build_type1_krx_prehistory_bundle.py --output collector.zip`. 사용자 전달 ZIP은 별도 파일로 제공한다.
