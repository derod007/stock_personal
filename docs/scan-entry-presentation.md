# 수동 스캔 진입 확인·관찰 표시

수동 스캔과 검색은 현재 당일 OHLCV 검증 성공 시 진행 중 봉을 포함한다. 현재가만으로 OHLCV를 만들지 않는다. 조회/검증 실패는 `completed_fallback`으로 완료봉을 참고하며, 화면에 **장중 자료 실패 · 완료봉 대체**와 제공처 실패 사유·분석 기준 시각을 표시한다. 이 대체 상태를 진입 확인 종목으로 분류하지 않는다. 장 마감 자료 검증 성공 시 완료 일봉, 장중 성공 시 장중 잠정이다.

수동 화면의 기본 순서는 확인된 지정가 계획 → 관심 구간 안 관찰 → 구간 밖 대기 → 목표 초과 관찰 → 조건 차단/자료 보류다. 동일 관찰 단계는 현재가에서 관심 구간까지 필요한 변동률(절댓값), 구조 점수, 대금순위 순이다. 화면 전체에 진입 확인 건수를 항상 표시한다. 확인 0건의 맨 위 종목은 추천 1위가 아니다. 확정 계획도 '지정가 대기'로 표시하며 시장가 매수 지시가 아니다.

현재가 ≥ 목표 후보이면 목표 초과로 표시한다. 현재가 ≤ 손절 후보, 차단 상태, 가격 누락 등은 진입 확인에서 제외한다. 거리 기준은 관심 구간 상·하단 중 가까운 경계이며 `(경계와 현재가 차이 / 현재가) * 100`이다. 구간 안은 0%이다. 별도의 거리 임계값이나 점수 감점은 추가하지 않는다.

예: 하나마이크론 53,400원, 관심 39,173~41,301원, 손절 35,018원, 목표 51,200원은 관심 상단까지 약 22.7% 하락 필요·현재가 목표 초과로 표시한다. 66점은 구조 점수로 보존한다.

정렬 규칙은 ScanEntryView가 계산하고 브라우저는 부여된 순서를 사용하여 서버/브라우저 간 ready 처리 불일치를 없앤다. 점수순을 눌렀다가 기본 정렬로 돌아와도 같은 순서를 복원한다. 예약 스캔·모의계좌의 선별 순서, 전략 지문, 점수/가격 산식은 변경하지 않는다.
