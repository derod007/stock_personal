# 유형1 장중 관찰 v1

기존 유형1 분류와 모의 계좌의 매매 규칙을 변경하지 않는 수동 조회 화면이다.
`type1_intraday.php`에서 최신 마감 기록의 신규 유형1 후보를 개별 또는 전체 조회한다.
종목별 조회는 순차 실행되므로 동일 시각의 일괄 신호가 아니다. 자동 갱신·주문은 없다.

## 규칙

- 후보 다음 거래일에만 표시한다. Yahoo KOSPI·KOSDAQ 지수의 날짜가 모두 다음 거래일을 오늘로 확인해야 한다. 휴일을 평일 계산으로 추정하지 않는다.
- Yahoo 5d/5m 원본으로 당일 09:00~15:30 중 완료봉만 사용한다. 첫 30분은 관심 후보다.
- 첫 30분 고점이 시가보다 높고, 09:30 이후 직전 봉보다 낮은 종가가 나타나면 조정 시작이다. 이는 사람이 말하는 파동 전체를 판독하는 알고리즘이 아니라 첫 버전의 명시적 정의다.
- 조정 시작 전 고점을 돌파 기준으로 고정한다. 조정 중 저점은 갱신한다.
- 이후 완료된 5분봉 종가가 돌파 기준을 넘고 해당 봉에서 새로운 조정 저점을 만들지 않으면 반등 확인이다. 확인 봉 마감 시각을 표시한다. 확인 가격 체결을 가정하지 않는다.
- 반등 전 첫 30분 저점 이하, 반등 후 고정 조정 저점 이하이면 당일 조건 무효다. 재진입 없음.
- 조회 시각부터 완료봉까지 15분 초과 지연, 09:00 이후 중간 봉 누락, 합성봉·OHLC 모순은 판단 불가다. 제공자 장중 봉 지원 여부와 지연은 실제 운영 환경에서 확인해야 한다.
- 시초 급등 뒤 조정이 없으면 진입 확인 없음. 별도의 과열 수치·목표가·금액 한도·부분 청산·추적 손절은 정의하지 않았다.

## 저장과 한계

기존 snapshot/latest와 계좌는 읽기만 한다. 조회 캐시는 `data/type1-cache/intraday`에 저장된다.
화면 상태는 조회 시점 자료로 재계산되며 신호 이력으로 저장하지 않는다. 공급자 수정으로 이전 상태가 바뀔 수 있다.
`as_of`는 최근 사용 봉의 마감 시각이고 `checked_at`는 서버 조회 시각이다. UI 시각은 KST다.
캐시 fallback에서도 최신성과 연속성을 검사한다. 실시간 체결가나 거래소 인증 데이터는 아니다.

## 검사

`php tests/type1_intraday.php`
완료봉, 첫30분, 조정/돌파, 윗꼬리, 동일봉 저점 갱신, 무효화 이후 재진입 방지,
누락·중복·합성·OHLC 오류·지연, 신규 후보 제한 포함.
기존 `type1_scan`, `type1_tracking`, `type1_tracking_ui` 검사도 유지한다.
외부 시세 조회 및 사용자 운영 계좌 실행은 테스트하지 않는다.

## 2026-10-30 공급자 끝 행 처리

첨부 캐시 10개 모두 마지막 행이 거래량0·OHLC 동일이었다. 9개는 14:10:06~17의 비정규 시각, 1개는 14:10:00이었다. 원시 HTTP 응답은 없어 이 행의 공급자 의미는 확정하지 않는다. 당일 가장 마지막 행 한 개만 위 조건(양수 유한가격, 고유 timestamp, 비합성)을 만족하면 보수적으로 제외한다. 중간 행·거래량 있는 비정규 행·중복은 제거하지 않고 차단한다. 정상 무거래 끝 봉도 보수적으로 제외될 수 있다.

제외 행은 완료봉 시각이나 신호·최신성 계산에 사용하지 않는다. 따라서 첨부 자료의 최신 완료봉은 모두14:10이고, 조회가14:25를 넘으면 계속 지연으로 차단한다. 지연 기준은 완화하지 않는다. 원인별 오류에 문제 시각을 표시하고 조회 시각도 노출한다.
