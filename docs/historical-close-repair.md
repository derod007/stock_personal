# 과거 일봉 종가 오류 확인과 제한적 보정

2026-10-09 재조회에서 11종목 모두 Yahoo chart API의 2026-03-27 원응답에 `close > high`가 재현됐다. 첨부 동결 원본의 값과 같으며 PHP 저장 과정에서 새로 생긴 불일치가 아니다. 공급자가 내부적으로 잘못된 값을 만든 이유까지 확인된 것은 아니다.

네이버 fchart 일봉 600개와 비교했다. 10종목은 해당일 O/H/L/V 및 직전·직후 거래일 OHLCV가 모두 일치한다. 한화솔루션은 주변 날짜까지 가격·거래량이 다르므로 같은 가격 기준으로 볼 수 없어 보정하지 않는다.

## 적용 조건

- 국내 완료 일봉, Yahoo 일봉 종가, 정상 O/H/L/V이며 종가만 고저 범위를 벗어난 경우만 대상이다. 특정 날짜 예외는 없다.
- 독립 공급자의 같은 날짜 O/H/L/V가 정확히 같고 그 종가가 정상 범위여야 한다.
- 양옆 거래일 OHLCV도 모두 일치해야 한다. 종목·일봉 응답 식별, 중복 날짜, 미래·미완료·합성 봉을 검증한다.
- 네이버 원응답을 SHA256 파일로 보존한 뒤 반환 데이터의 종가만 바꾼다. 원래 봉 전체와 출처 해시·수집 시각을 보정 내역에 남긴다.
- 정상 봉은 수정하지 않는다. 실패·불일치·증거 훼손 시 원본을 반환하여 기존 품질 차단을 유지한다.
- 원응답 보관 위치: Yahoo 캐시 폴더 아래 `historical-close/<sha256>.xml`. 종목별 색인은 하루 동안 재사용한다. 600개 밖의 이력이나 양옆 검증이 불가능한 봉은 보정하지 않는다.

## 적용 후 확인

PR을 적용하면 기존 예약 실행 또는 아래 명령의 새 수집 입력에 자동 적용된다.

```powershell
.\.venv\Scripts\python.exe bin/paper_daily.py --config=config/paper-kr-recovery-v1.json
```

실행은 실행 시점 자료의 새 관측을 만든다. 과거 20:20 재현 명령이 아니다. 기존 Yahoo 원본 캐시, 동결 관측, 계좌 장부는 덮어쓰지 않는다. 과거 엔벨로프 품질 보류 11건은 계속 보존하며 같은 세션을 재실행해도 그 동결 관측은 자동 복구되지 않는다. 후속 거래일의 새로운 관측에서 보정 입력이 사용된다. 전략 파일 목록·계좌 전략 지문·과거 가격 변경 차단은 유지한다.

한화솔루션은 별도의 동일 가격 기준 자료 확인 전까지 보류한다. 이번 비교만으로 수정주가 여부나 기업행사를 단정하지 않는다.
