# 수동 조회 현재가와 분석 종가

수동 거래대금 스캔은 `interactive: true`로 실행한다. 스캔 결과/거래대금 순위 캐시를 재사용하지 않고 이번 요청에 받은 순위 시세를 `price`에 표시한다. 분석 종가는 `analysis_price`로 분리한다. 현재가 칸에는 가격만 보여 주고 조회 시각은 붙이지 않는다. 긴 분석 동안 계속 갱신되는 스트리밍 시세는 아니다. 화면을 다시 조회하면 새 시세를 요청한다.

종목 검색은 분석 후 별도 CurrentQuoteClient로 국내 다음 시세를 요청하고 실패하면 Yahoo 시세 메타데이터를 사용한다. 해외는 Yahoo의 regular/pre/post 중 가장 최근 시각의 가격을 사용한다. 공급자 지연 가능성과 제공된 시세 시각을 표시한다. 조회 시각을 체결 시각으로 꾸미지 않는다. 시세 조회 실패 시 현재가는 비워 두며 일봉 종가나 오래된 캐시로 대체하지 않는다.

완료 일봉 OHLC·패턴·추천 조건은 그대로 계산한다. 화면 주 가격과 현재가 대비 퍼센트/복사 메모는 조회 시세를 사용하며 분석 기준 종가와 날짜도 따로 표시한다. 현재가가 바뀌었다고 미완성 봉으로 패턴을 확정하지 않는다.

수동 스캔은 일별 스냅샷 및 자동 실행용 스캔 캐시를 덮어쓰지 않는다. CLI/예약 실행은 기본 `interactive: false`여서 기존 기록 경로와 분석 결과를 유지한다. 예약 실행 시간 자체는 수정하지 않는다.
