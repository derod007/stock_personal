# 유형1 손절 후 경로 최종 진단

저장된 독립 거래 결과를 읽는다. 계좌·거래를 재실행하지 않는다. 실제 데이터·결과는 공개 저장소에 올리지 않는다.

## 결과 집계 전 고정

- 대상: 저장된 cluster=1 전체. 청산·미체결·미확정 분모를 분리.
- 기간: 원래 신호 T부터 T+20까지. 달력 날짜·상승 소요를 서로 맞추지 않음.
- 회복: 손절일 **이후** 원래 계획 목표(T종가×1.15)를 고가가 터치. 실제 체결가 대비 15%와는 다른 정의이며 실현수익이 아님.
- 손절일에도 목표 터치: 장중 순서 미확정으로 별도 분류. 나중 터치 여부도 별도 저장.
- 진입~T+20에 원본 봉 누락·비정상 OHLCV·기준가격 불연속이 있으면 향후 경로 미확정. 원래 청산 손익은 변경하지 않음. 전창 유효성을 요구하므로 보수적으로 제외함.
- 목표 미도달을 계속 하락과 동일시하지 않음. T+20 종가가 체결가보다 높은 건수를 함께 제시.
- 회복 소요, 도달 전날까지 최저가, 도달 당일 저가 분리. 일봉 진입 당일 저가는 체결 전일 수 있어 실제 체결 후 최대하락으로 단정하지 않음.
- 판단일 완료봉 특징 **4개만**: 20봉 종가 수익률, ATR14/종가, 평균거래량10/50, 20봉 고가 대비 종가 낙폭. 재학습·특징 조합·임계값 최적화 없음.
- 손절 후 회복 vs 목표 미도달, 저장 순익 양수 vs 손절을 비교. 중앙값·순위 AUC를 전체/2023하반기/2024상반기로 제시. AUC는 값이 큰 쪽이 양성일 확률(동률 0.5). 0.5면 구별 없음.
- 반복 종목 의존성 때문에 거래 수를 독립 표본 수로 간주하지 않음. AUC에 유의성 주장을 붙이지 않음.
- 기존 결과를 본 뒤의 탐색. 앞/뒤 반기도 새 독립 검증이 아님.

## 종료 판단

더 연구할 가설로 언급하려면 최소한 같은 특징의 구별 방향이 두 반기에서 같고 두 비교(회복/미도달, 수익/손절)에서 모순되지 않아야 한다. 크기·표본 편중도 함께 판단한다. 이를 통과해도 새 전략이나 수익성 증명이 아니다. 약하거나 불일치하면 유형1 후속 탐색 중단을 권고한다. 조건·손절·목표·운영은 바꾸지 않는다.
