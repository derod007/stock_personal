# 업종 부분 실패 처리 보완

PR #67 후속. 버킷 분류 규칙과 계좌 한도는 바꾸지 않는다.

- 일반 주식의 이름만 있고 업종이 없거나 `기타`이면 성공 캐시로 저장하지 않는다.
- 업종코드가 있으나 목록에 대응 이름이 없거나 비어 있으면 조회 실패로 보고 기존 HTML 경로를 시도한다. 그 경로도 실패하면 캐시를 쓰지 않는다.
- 업종코드가 없다는 이유만으로 ETF로 판단하지 않는다. 기존 `isEtfName` 이름 규칙을 만족하는 경우에만 업종 없는 정상 캐시를 허용한다.
- 실제 업종명을 얻었으나 버킷이 `other`인 경우는 유효한 분류다.
- 이름이 있는 기존 `기타` 자리표시자도 TTL 안에서 재조회한다. 자리표시자를 성공 결과처럼 다시 쓰지 않는다.
- 강제 조회 또는 TTL 만료 후 조회가 실패해도 기존 유효 캐시 바이트는 보존한다. 실패한 호출에는 과거 업종을 현재 조회 성공처럼 반환하지 않는다.

이 변경은 운영의 신규 주문 수량에 영향을 줄 수 있다. PR만 갱신하며 병합하지 않는다. 연구 계좌는 이미 고정한 맵 v2를 사용하므로 이 운영 수정에 의존하지 않는다.

검증: sector_collect 17개, rr_scan·amount_exclude 통과. PHP 8.3.6(mbstring/iconv/curl) 환경. 임시 폴더 실제 조회에서 삼성전자·SK하이닉스 semi, LG화학 energy 확인. 운영 캐시는 사용하지 않음.
