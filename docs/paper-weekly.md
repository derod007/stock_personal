# 주간 모의 계좌 요약

머지 후 갱신하면 모의 계좌 → 주간 요약에서 조회할 수 있습니다. 기존 스케줄러가 쌓은 자료를 화면/CLI 조회 시 자동 집계합니다. 새 예약 작업, 알림 전송, 전략 변경 또는 계좌 리셋이 필요하지 않습니다. 고정된 주간 파일을 자동 저장하는 작업은 설치하지 않습니다.

## 기간과 기준

기본은 현재 한국시간 ISO 주차입니다. 주차 선택으로 과거 주도 조회합니다. 월요일 00:00 이상 다음 월요일 00:00 미만입니다. 미국 거래도 세션 시각을 KST로 변환한 주차에 들어갑니다. 미국 현지 달력 주간과 같다고 가정하지 마세요.

추천/주문/체결/청산/평가자산은 payload.session 기준, 실행 로그는 started_at 기준, 중단 발견 이벤트는 recorded_at 기준입니다. 나중에 입력된 catchup은 해당 평가 주로 집계됩니다. 과거 주 결과는 새로운 사후 기록에 따라 늘어날 수 있으며 당시 주말에 저장한 고정 보고서가 아닙니다. forward/catchup/replay를 분리하고 계좌 통화를 합치지 않습니다.

조건 충족은 plan.ready이며 품질/자금 등으로 주문이 제외될 수 있습니다. 체결·청산에는 이전 주 주문이 포함되므로 평가→주문→체결 건수로 전환율을 계산하지 않습니다. 청산 사유별 손익은 기록된 net_pnl입니다. 완료 거래 표본이 작을 때 우수 전략을 선정하지 않습니다.

평가자산 변화는 주 시작 전 마지막 평가와 주 안 마지막 평가의 차이입니다. 첫 평가 주는 초기자금에서 시작합니다. 기준 시점을 표시하며 오래된 직전 평가라면 여러 주 변동이 포함될 수 있습니다. 누락된 주말 평가를 만들어내지 않습니다. 가격 누락 추정치가 양 끝에 있으면 자산 변화 계산을 보류합니다. 주 안 평가가 없으면 미실현손익도 미집계로 표시합니다.

비교 계좌 상태와 현재 계좌 중단 상태는 명시적으로 '현재 상태'입니다. 선택한 과거 주의 비교 상태를 복원한 것처럼 표시하지 않습니다. source_cursor와 source_hash를 확인해 원본 갱신과 비교 갱신이 다르면 표시합니다. 주간 실행 횟수는 정상적으로 읽힌 로그만 집계하고 손상 로그는 별도로 표시합니다. 로그가 없다고 자동 실행 누락이라고 단정하지 않습니다.

## 조회

- paper_weekly.php?account=paper-us
- paper_weekly.php?account=paper-kr&week=2026-W38
- mode=replay로 과거 재현을 별도 조회
- format=json으로 동일 결과 JSON 제공

```
php bin/paper_weekly.php --account=paper-us --week=2026-W38
php bin/paper_weekly.php --account=paper-kr --mode=forward
```

CLI는 JSON을 stdout에 출력합니다. 원본 계좌/실행/비교 파일을 쓰지 않습니다. 웹과 동일한 PAPER_STATE_DIR를 사용합니다. 무결성 오류는 0건 정상 결과로 대체하지 않습니다.

검증: KST 주 경계, 잘못된 ISO 주차, forward/catchup 분리, 실현/평가손익 구분, 누락·추정 평가, 손상 실행 로그, 비교 갱신 불일치, 실제 CLI 및 HTML 조회 후 원본 무변경.
