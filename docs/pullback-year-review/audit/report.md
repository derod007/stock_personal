# 상승 눌림 종료 42건 — 가격·구현·판정일 구조 검토

## 판단

검토 범위에서 가격·차트·상승 눌림 산식의 불일치는 발견하지 못했다. 다만 현재 `trend_pullback_v1`은 **완만한 상승 추세의 눌림만 선별하는 규칙이 아니다.** 급등 후 깊은 조정, 최근 하락 중 하루 반등, 횡보·추세 전환 구간도 포함한다. 이는 이번 42건의 차트와 코드에서 확인한 정의의 범위이며, 모두 잘못된 추천이라는 뜻은 아니다.

거래 횟수를 늘리거나 운영 조건을 바꾸기 전에, 이 서로 다른 구조를 관찰 항목으로 구분하는 편이 타당하다. 이번 연구로 MA20 아래 진입 금지나 새로운 ATR 하한을 채택하지 않는다.

## 실제 확인 범위

- ZIP/Git 목록 바이트 일치, 종료 42건 전체. 종목·판정일별 가격 해시, 날짜·순서·미래봉 차단·OHLC 관계·MA20/60을 확인했다. 입력 28,068봉은 사례별 중복을 포함한다.

**한계:** 독립 계산은 상승 눌림 산식의 범위다. 공통 위험 엔진 전체의 독립 구현이나 원천 Yahoo 응답 검증, 이후 봉의 체결·청산 경로 감사는 아니다. ZIP에는 판정일 이후 봉과 공급자 원본이 없다. 따라서 가격 급변이 기업행사인지, 체결 모델이 실제 장중 순서를 반영하는지는 이번 결과로 확정하지 않는다.

차트 거래량은 비례 계산하되 기존 도구의 최소 높이 1px가 적용된다. 작은 거래량·0 거래량까지 엄밀히 비례하는 것은 아니다. 이 동작을 감안해 검증했으며 차트 도구를 변경하지 않았다.

## 코드가 허용하는 구조

### 1. MA20 ‘근접’은 양방향 거리 검사가 아니다

현재 식은 `직전 5봉 최저가 <= 신호일 MA20 + 0.75 ATR`이다. MA20 아래로 얼마나 내려갔는지에는 제한이 없다. 같은 5일 안에서도 서로 다른 날의 저가가 조건을 만족할 수 있으며, 해당 날짜의 MA20과 비교하는 방식도 아니다.

- 신호 종가가 MA20 아래: **22/42건**
- 직전 5봉 최저가가 신호일 MA20 − 0.75 ATR보다도 아래: **28/42건**

두 번째 경계는 기존 위쪽 허용폭의 대칭 위치를 보여 주기 위해 사전에 기록한 관찰 기준이다. 성과로 최적화한 수치나 채택할 필터가 아니다.

### 2. 상승 구조는 두 20봉 창의 비교다

MA20이 5봉 전보다 높고, 최근 20봉의 최저·최고가가 앞선 20봉보다 높으면 통과한다. 따라서 앞서 크게 급등했다면 최근 며칠의 고점·저점이 낮아져도 통과할 수 있다. 연속적인 높은 저점이나 실제 조정 구간의 저점을 확정하는 조건은 아니다.

육안 사례: 동양고속·대성산업·광전자는 급등 후 큰 반납이 보인다. 현대건설 2025-11, NAVER, 삼성E&A 2026-09, 삼성SDI 2026-09는 장기 창에서 하락 후 회복 또는 넓은 횡보 맥락이 섞인다. 이름만 보고 모두 같은 상승 눌림으로 간주하기 어렵다. 메모는 주관적 관찰이며 수익성에 대한 합격·탈락 판정이 아니다.

### 3. ‘고점 회복 확인’은 직전 하루 고가 회복이다

신호 종가가 직전 봉 고가보다 높다는 조건이며, 조정 전체 저항이나 추세선을 회복했다는 뜻이 아니다. 이번 기준 H(신호 전 20봉 최고가의 마지막 발생일) 다음부터 신호 전일까지 모든 고가를 넘은 사례는 0건이다. 초반 조정 봉의 고가까지 요구하는 강한 비교이므로, 0건을 근거로 확인 실패라고 분류하지 않는다. 해당 필터를 추가하면 이번 표본을 모두 제외할 수 있다는 점도 유의해야 한다.

진입이 ‘늦다/빠르다’는 정답도 이 사실만으로 정하지 않았다. 현 코드는 하루 반등에 진입할 수 있고, 큰 구조 확인은 별도의 정의가 필요하다.

### 4. 손절은 10봉 저점이다

H 이후부터 신호 전일까지 최저점 L과 손절 기준 10봉 최저가의 가격이 같은 경우 34건, 다른 경우 8건이다. H는 목표 창의 기준이지 사람이 확정한 눌림 시작점은 아니다.

다른 8건 중 7건은 H 이후 더 오래된 저점이 10봉 밖으로 빠졌고, 에스피지 1건은 신호 당일 저가가 이전 구간의 L보다 낮았다. 따라서 차이가 모두 ‘눌림 이전 저점을 손절로 쓴 오류’인 것은 아니다. 초기 손절 폭은 최소 3.41%, 중앙값 12.09%, 최대 29.28%다. 손절 폭이 넓다는 사실과 주식 수를 조절한 계좌 위험은 구분한다.

## 고정 관찰 뒤 성과 비교

`protocol.md`를 먼저 작성하고, 사례별 성과를 이번 집계에 결합하기 전에 `asof-metrics.json`과 `visual-notes.json`을 해시로 고정했다. 같은 작업 중 만든 로컬 체크포인트이며 외부 사전등록은 아니다. 검토자는 PR #77 집계 및 이전 감사에서 거래 결과를 이미 보았으므로 **블라인드·독립 검증이 아니다.**

아래 평균은 종료 거래별 `net_pnl / (진입금액 + 매수 비용)`의 단순 평균이다. 그룹은 서로 겹치며 계좌 수익률이나 필터 적용 후 재실행 수익률이 아니다.

|관찰 구분|건수|이익 / 손실|평균 순수익률|
|---|---:|---:|---:|
|전체|42|11 / 31|−2.17%|
|신호 종가 < MA20|22|5 / 17|−4.13%|
|신호 종가 ≥ MA20|20|6 / 14|−0.01%|
|직전 5봉 최저가 < MA20 − 0.75 ATR|28|5 / 23|−5.40%|
|그 외|14|6 / 8|+4.29%|
|손절 기준 저가 = H 이후 L|34|8 / 26|−3.33%|
|서로 다름|8|3 / 5|+2.77%|

손절 기준이 다르거나 MA20 아래였다고 모두 실패한 것은 아니다. 로보티즈(2025-11-24)는 MA20 아래 신호로 +42.33%, 삼성E&A(2026-09-03)는 +11.34%였다. 대한해운(2026-03-31)은 손절 창 저점과 H 이후 L이 다른데 +42.47%였다. 반면 동양고속은 −26.24%, 대성산업은 −17.15%였다. 이 반례들을 남겨 손실 사례에만 맞춰 정의를 바꾸지 않도록 한다.

## 다음 조치 권고

1. **운영 수정 보류.** 현 산식과 산출물의 차이를 고치는 버그 수정 사유는 이번 범위에서 발견하지 못했다.
2. **정의 구분을 먼저 연구.** ‘MA20 근처에서 지지 후 반등’과 ‘MA20 아래 깊은 조정 후 하루 반등’을 별도 관찰로 표시한다. 지금의 42건을 보고 선택한 관점이므로 새로운 기간 또는 앞으로 쌓이는 사례에서 고정 기준으로 확인해야 한다.
3. 초기에는 추천·주문을 차단하지 않는 연구 로그만 추가하는 것이 적절하다. 단순 MA20 위/아래 및 현재 코드의 이격값을 기록하고, 수익을 최대화하는 임계값 탐색은 하지 않는다.
4. 보유 한도 차단 28건 연구는 그 뒤 수행한다. 거래 수 확대가 이 문제를 해결하는지는 아직 확인되지 않았다.

## 재현

Python 3 표준 라이브러리만 필요하다. ZIP을 Git 밖에 풀고 아래 `<가격 폴더>`를 `list.json`과 `json/a`가 있는 경로로 바꾼다. 고정 파일은 덮어쓰지 않도록 새 출력 경로를 사용한다.

```sh
python docs/research/pullback-year-audit.py --prices-dir="<가격 폴더>" --output="<새 검증 결과.json>"
python docs/research/pullback-year-audit.py --prices-dir="<가격 폴더>" --output="<새 성과 비교.json>" --join-outcomes
python tests/pullback_year_audit.py --prices-dir="<가격 폴더>"
```

추가 검증에서 B 차트·고정 창 검사 범위를 넓혔으나 고정된 42건의 판정일 지표·메모는 변경하지 않았다. 최신 검사 범위는 `verification.json`이며 최초 A 검사 결과는 `asof-metrics.json`에 그대로 보존했다. 운영 src/config/계좌/원본/기존 결과는 변경하지 않았다.
