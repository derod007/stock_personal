# 독립 거래 진단 프로토콜

기존 고정 KRX 입력의 모든 분류 신호를 대상으로 한다. 재학습·추가 조건 탐색 없이 유형1, 나머지유형, 전체를 비교한다. 계좌 보유한도·현금·업종한도를 제거한 개별 거래 연구이며 실제 포트폴리오 수익률이 아니다.

기존 TradeSimulator의 T종가 지정가·손절0.95T종가·목표1.15T종가·TTL1·20보유봉·비용을 유지한다. 최초 진입 다음 봉부터 순서대로 실행한다. 신호/계좌 재실행이 아니라 고정 신호의 독립 체결 진단이다. 기존 계좌 파일은 읽지도 수정하지도 않는다.

종목별 미래 봉을 날짜 순서대로 확인한다. 거래가 끝나기 전에 참고가격 불연속·가격 누락·품질 차단이 나오면 unresolved로 종료하고 손익을 null로 둔다. 해당 날짜의 거래를 먼저 추정하지 않는다. 이미 종료한 거래 뒤의 행사로 그 거래를 제외하지 않는다. 미래 이벤트로 과거 신호를 제거하지 않는다. 미체결·진입 전 취소는 수익거래로 세지 않는다.

보고할 항목: 신호/체결확정/종료/미체결·취소/미확정 수, 종료거래 동일가중 평균·중앙·승률, 신호월 기준 월별 수와 평균, 고유종목/종목동일가중 평균, 상위 기여1·5종목 제외 민감도, 전반/후반. 종목 기여는 동일 명목금액을 가정한 수익률 합이며 실제 원화 기여가 아니다. 월별 값도 월간 계좌수익률이 아니다.

완료 거래 평균은 완료 부분집합의 기술통계다. 미확정 손익을0으로 넣거나 전체기간 수익률로 발표하지 않는다. 20세션 미래창이 부족한 기간말 신호 제외와 진입 전 품질 제외는 기존 입력 그대로이며 별도로 밝힌다. 이미 살펴본 기간이고 고정 중심도 미래기간 학습이므로 독립 전진검증이 아니다.

실제 자료에서 파생된 상세 결과는 비공개 파일로 제공하고 공개 PR에는 일반 코드·가상 테스트·프로토콜만 포함한다. 실제 기업행사 원문·개별 실제 종목 목록은 공개하지 않는다.
