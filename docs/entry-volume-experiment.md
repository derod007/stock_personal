# 진입 조건 진단과 거래량 완화 실험

기존 신호·계좌·TTL 실험은 그대로 유지합니다. 새 실험은 공통 고정 종목군의 같은 스냅샷으로 두 빈 계좌를 동시에 시작합니다. 현재 보유분이나 과거 수익률을 복사하지 않습니다.

## 먼저 탈락 원인 보기

모의 계좌의 ‘진입 조건’ 탭에서 원본 ID를 조회합니다. `paper_entry.php?account=paper-us`, `account=paper-kr`로 기존 계좌도 진단할 수 있습니다. 각 기록의 최종 상태, 패턴별 상태, 주문 차단, 미체결/취소 사유와 추세 눌림 조건별 통과/탈락/미평가/단독 탈락을 집계합니다.

- 단위는 종목×평가일이며 독립 거래 수가 아닙니다.
- 앞 조건에서 일찍 반환되거나 옛 기록에 진단 항목이 없으면 미평가입니다. 없는 조건을 실패로 간주하지 않습니다.
- 단독 탈락은 눌림 패턴의 9개 조건 중 하나만 실패했다는 뜻입니다. 최종 추세·손익비·품질 검사까지 통과했다는 뜻은 아닙니다.
- forward/catchup/replay를 구분합니다. 체결/취소는 선택한 종류의 스냅샷이 있는 평가일에 발생한 건수입니다.
- 한국 거래대금 스캔에서 계좌로 전달되지 않은 종목은 집계할 수 없습니다. 전체 스캔 후보의 탈락 분포라는 주장은 하지 않습니다.

## 사전 지정한 후보

상승 추세 눌림의 평균 거래량 기준만 **기존 기준 거래량의 85% 미만 → 95% 미만**으로 변경합니다. 기준 거래량은 기존 엔진과 같은 20봉 구간, 눌림 거래량은 같은 3봉 구간입니다. 실제 PC 로그가 없으므로 거래량이 최대 병목이라는 결론은 내리지 않았습니다. 진단에 단독 거래량 탈락이 없다면 이 실험에서 추천이 늘지 않아도 정상입니다.

기존 재지지 준비 신호가 있으면 그대로 사용합니다. 상승 구조, ATR, 가격 구간, MA20 눌림, 종가 회복, 양봉, 거래량 회복, 새 확인 신호를 모두 요구합니다. 손절·목표 가격 계산, 최소 손익비 1.5 및 주간 하락 시 추가 조건, 고점 붕괴/급락 차단, 데이터 품질, 수수료·슬리피지, 현금·보유·업종·위험 한도는 유지합니다. 95%와 같은 값은 통과하지 않습니다.

실험 후보를 계산할 때 원본 입력 해시와 현재 엔진의 기준 계획을 저장된 스냅샷과 대조합니다. 다르면 중단하며 신호를 추측하지 않습니다. 미래 봉은 해당 세션 이전으로 잘라냅니다. 현재 전략 버전과 다른 원본도 CLI에서 차단합니다. 새 실험 코드 변경 시에는 새 실험 ID가 필요합니다.

## 실행

머지 후 프로젝트 폴더에서 실행합니다.

```sh
python bin/paper_entry_daily.py --config=config/paper-research-us-v1.json --experiment=us-volume95-v1
python bin/paper_entry_daily.py --config=config/paper-research-kr-v1.json --experiment=kr-volume95-v1
```

이 래퍼가 고정 연구 계좌를 갱신한 뒤 같은 입력으로 기준/후보를 계산합니다. PR14의 **연구용** 예약 작업을 이미 만들었다면 그 명령을 위 래퍼로 교체하세요. 연구용 수집을 중복 예약할 필요가 없습니다. 기존 paper-us/paper-kr 및 identity 비교 예약 작업은 유지합니다. 한국은 20:20 이후, 미국은 기존 완료 일봉 수집 시간에 실행합니다. PHP/Python PATH 및 PAPER_STATE_DIR는 기존과 동일하게 설정합니다. 이 PR은 사용자 PC에 예약 작업을 직접 등록하지 않습니다.

원본 수집 실패·중단 시 비교를 실행하지 않습니다. 실행 기록은 `entry-experiment-runs/<실험 ID>`, 비교 원장은 `entry-experiments/<ID>-forward.json`입니다. 기존 `experiments`와 분리했습니다. 늦게 실행한 과거 신호를 소급 매수하지 않으며 같은 입력 재실행은 중복 주문을 만들지 않습니다.

원본 갱신 없이 이미 저장된 최신 기록만 비교하려면:

```sh
php bin/paper_entry_compare.php --source=research-us-v1 --experiment=us-volume95-v1
```

동일 전략 검증은 **다른 ID**로 `--identity`를 추가합니다. 과거 재현은 별도 원본 replay 기록과 `--mode=replay`를 사용하며 forward 성과와 섞지 않습니다.

## 결과

- 미국: `paper_entry.php?account=research-us-v1&experiment=us-volume95-v1`
- 한국: `paper_entry.php?account=research-kr-v1&experiment=kr-volume95-v1`

진입 확인/주문/체결, 비용과 평가손익을 포함한 순손익, 완료 거래, 최대 종가 낙폭을 함께 봅니다. 미체결 증가만으로 개선이라고 하지 않습니다. 완료 거래 30건은 탐색 표본 기준일 뿐 수익성 입증이 아니며 자동 채택·원본 조건 완화는 없습니다. 중단/갱신 지연 시 마지막 기록임을 표시합니다.
