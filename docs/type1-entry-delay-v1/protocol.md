# 유형1 고정 신호의 시가 진입 지연 — 결과 전 고정

2026-10-24. KRX 과거2023-07-03~2024-06-28과 PR107 최근2025-10-10~2026-10-08을 분리한다. KRX는 기존771 유형1 신호, 최근은 PR107 저장 fill/blocked 이벤트의 전체1010 유형1 신호를 복원한다. 체결183건으로 제한하지 않는다. 후보를 추가/재선정하지 않고 보유/현금/위험/업종 한도 없이 독립 거래로 비교한다.

기존=T+1 시가, 1일지연=T+2 시가, 2일지연=T+3 시가. 각 실제 진입 시가×0.95 손절·×1.15 목표, 매수1.0015/매도0.9985, 만기 원래T+20 유지. 최대보유는 각각20/19/18봉이다. 같은 봉 손절/목표는 손절 우선, 손절 아래 시가갭은 시가, 목표위 갭도 목표가. 지연 동안 상승/하락/목표 접촉 여부로 진입을 취소하거나 선별하지 않는다.

지연 대기 동안은 미보유이므로 OHLC 누락/불량만으로 이후 진입을 거절하지 않는다. 다만 KRX 참고가격 불연속이 T 다음날~지연진입일 사이에 발생하면 신호와 진입의 가격 기준 관계를 확정할 수 없어 해당 arm을 미확정으로 둔다. 진입 후에는 원래 품질 중단 규칙 유지. 미래 오류로 과거 종료 거래를 제거하지 않는다. 공급자별 가격기준은 섞지 않는다.
