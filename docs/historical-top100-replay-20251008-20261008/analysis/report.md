# 일별 TOP100 1년 연구: 거래 빈도와 손익 구조

PR #76의 저장 장부를 읽어 분석했다. 기준 main은 `113e5cbc9526e6beb60b1d9dceab7df245213aed`. 운영 전략·계좌·원본·기존 재현 결과는 변경하지 않았으며 계좌를 다시 실행하지 않았다.

## 거래가 적은 이유

244세션의 최종 추천은 103건이다. 170일(69.7%)에는 추천이 없었다. 추천은 종목·날짜 단위이므로 같은 종목의 반복 추천도 포함한다(고유 75종목).

|단계|건수|
|---|---:|
|최종 추천|103|
|주문 생성|68|
|보유 한도로 주문 차단|28|
|이미 보유·대기|5|
|현금·위험·섹터 조건으로 차단(합산 사유)|2|
|체결|59|
|취소|9(미체결 만료 6, 진입 전 취소 3)|
|청산 / 기말 보유|56 / 3|

체결한 고유 종목은 48개다. 68건은 거래 체결 수가 아니라 주문 수다. 추천 자체의 빈도가 낮고, 이후에는 보유 한도가 주요 감소 요인이다. 보유 한도로 막힌 28건은 상승 눌림 19, 재지지 6, 회복 3이다. 이들이 모두 체결되거나 이익이 되었을 것이라는 뜻은 아니다.

종가 기준 현금/총자산의 일별 단순 평균은 86.53%, 주문 예약금을 뺀 현금 비율은 83.64%다. 보유+대기가 4개인 날은 57일이다. 높은 현금 비중과 슬롯 제한이 함께 나타나지만, 이것만으로 한도 완화가 유리하다고 판단할 수 없다.

평가 건수는 TOP100 24,400에 이탈 후 관리 대상 202를 더한 24,602다. 품질 차단 고유 종목·세션 840을 제외한 최종 상태는 `metrics.json`에 전부 기록했다. 예를 들어 `risk_blocked` 6,954, `await_confirmation` 7,405는 최종 상태이며 패턴별 독립 탈락 사유의 빈도가 아니다. 해당 조건을 풀면 그만큼 추천이 증가한다고 해석하지 않는다.

## 패턴별 종료 거래

|패턴|주문 / 체결 / 종료|이익 / 손실|순실현손익|거래별 순수익률 평균|이익 합계 / 손실 절댓값 합계|
|---|---:|---:|---:|---:|---:|
|재지지|9 / 9 / 9|6 / 3|+8,497,092원|+14.84%|5.35|
|상승 눌림|52 / 44 / 42|11 / 31|+934,323원|−2.17%|1.04|
|회복|7 / 6 / 5|3 / 2|+2,965,458원|+6.68%|2.28|

순수익률은 각 종료 거래의 `net_pnl / (진입금액 + 매수 비용)`이다. 상승 눌림의 평균 수익률은 음수인데 금액 합계는 양수인 이유는 거래별 투자금이 다르기 때문이다. 패턴 손익은 공동 계좌에서 실제 선택·체결된 거래의 기여도이며, 패턴을 단독 운용한 계좌 수익률이 아니다. 재지지 9건, 회복 5건으로 우열을 확정하지 않는다.

순실현손익은 이익에서 손실을 뺀 값이므로 기여 비율이 100%를 넘을 수 있다. 위 나머지는 산술 차감이며 해당 거래 없이 계좌를 다시 돌린 결과가 아니다.

## 최대낙폭

- 고점: 2026-05-11, 총자산 119,576,508원
- 저점: 2026-07-03, 총자산 107,823,466원
- 감소: 11,753,043원(종가 최대낙폭 9.83%)
- 2026-10-08까지 위 고점 미회복

고점→저점의 거래별 기여 변화는 상승 눌림 11건 합계 −13,325,403원, 재지지 1건 +1,572,360원이다. 합계가 총자산 감소와 일치한다. 회복형 기여 변화는 없다.

가장 큰 감소는 `017900.KS@2026-05-07`의 −3,424,196원이다. 고점일 기여 +2,255,030원이 저점일 −1,169,166원으로 변한 것이며, 진입 대비 확정 손실이 342만원이라는 뜻은 아니다. 미실현 이익 반납도 포함된다. 전체 거래별 기여는 `metrics.json`에 있다.

## 검증과 재현

```sh
python3 docs/research/dated-year-analysis.py
python3 tests/test_dated_year_analysis.py
```

세 입력 파일의 SHA256은 `metrics.json`에 기록한다. 244일 모두 거래별 누적 기여 합계와 총자산 변화, 종료 거래 손익 합계와 누적 실현손익, 현금+보유 평가액과 총자산을 0.01원 미만 오차로 대조한다. 신규 주문 68건의 신호일 TOP100 소속, 저장 추천과 패턴·진입·손절·목표 일치를 검사한다. 최대낙폭과 기여 합계도 대조한다. 종료 손익을 100원 변조한 사본에서 검사가 실패하는지 시험한다.

이번 검증은 저장 산출물 사이의 회계·집계 일관성 검사다. 전략의 독립 구현, 원천 일봉의 정확성, 새 체결 경로 검증은 아니다. PR #76 엔진 재검증과 역할이 다르다. 스크립트의 출력은 새 `analysis/metrics.json`뿐이다.

## 다음 판단

1. 운영 조건을 유지하고 상승 눌림 종료 42건 전체를 동일한 판정일 차트 기준으로 검토한다. 최대낙폭에 기여한 11건을 표시하되, 이익 거래도 함께 비교해 손실 사례만으로 조건을 만들지 않는다.
2. 보유 한도 차단 28건은 별도 관찰 연구 대상으로 삼는다. 종목·날짜 반복과 동일 구조를 구분하고, 저장 신호와 이후 봉으로 체결 가능성을 먼저 점검한다. 이번 분석에서는 그 성과를 계산하지 않았다.
3. 한도 변경을 시험한다면 총위험·현금·섹터 제한을 포함한 별도 계좌 재실행이 필요하다. 놓친 추천의 손익을 기존 계좌에 단순 합산하지 않는다.

KRX 확정 일별 TOP100은 운영 다음 실시간 TOP100과 다르다. 현재 업종의 과거 적용, 공급자 수정주가 불확실성, 일부 심볼·봉 누락은 기존 연구 한계로 남는다. 한 해의 관찰 결과이며 전향적 수익성 검증이 아니다. 월별 실현손익은 청산월 집계이고 월간 계좌 수익률이 아니다. 양 끝 10월은 부분 기간이다.
