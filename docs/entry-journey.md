# 진입 확인 → 결과

`paper_journey.php?account=paper-kr&profile=account1` 또는 거래대금 스캔의 **진입 확인 → 결과 보기** 링크로 엽니다.

- 완료봉: `rr-audit/{account}`의 당시 ready 계획과 `followup/{account}/latest.json`의 baseline 모의 결과만 연결합니다. 심볼·판정봉·원본 파일·원본 해시·추적 정책이 모두 일치해야 합니다. 지정가 연구(limit)나 계좌 체결로 대체하지 않습니다.
- 기존 후속 갱신: `php bin/paper_followup.php --account=paper-kr`. 예약 작업도 기존 경로로 갱신합니다. 같은 종목의 뒤늦은 재실행 결과는 첫 저장 신호의 결과와 임의 연결하지 않습니다.
- 수동: 적용 이후 `index.php` 거래대금 스캔 실행 결과를 프로필별로 별도 보존합니다. 같은 캐시 결과는 중복 저장하지 않으며 새 실행은 이전 계획을 덮지 않습니다. 전 종목의 최종 상태를 저장하고 화면은 완료봉 확인 계획과 장중 잠정 관심 후보를 표시합니다.
- 장중에는 엔진이 ready를 확정하지 않습니다. 관심 구간과 잠정 분석을 보존하고 고정 지정가 칸은 비워 둡니다. 같은 날 이후 완료봉 감사 기록이 있으면 그 판정을 관찰용으로 함께 표시합니다. 프로필·전략의 동일성이나 같은 주문이라는 뜻은 아닙니다.
- 수동 관찰은 모의 계좌의 주문이 아닙니다. 수동 실행 시점 이후의 장중 가격 경로가 없으므로 당일 전체 일봉으로 체결을 소급 판정하지 않습니다. 완료봉 모의 체결 결과도 복사하지 않습니다.
- 완료봉 감사 기록의 실제 실행 주체(예약 실행/직접 CLI)는 과거 자료에 없으므로 추정하지 않습니다. 과거 전략 버전도 미확인입니다.

저장 위치는 기존 `PAPER_STATE_DIR`(기본 저장소 상위의 `stock-personal-paper`)/`entry-observations/manual`입니다. 잠금과 임시 파일 후 rename으로 저장하며 실패는 스캔 화면·JSON에 표시합니다. 파일명은 저장 원본의 SHA-256입니다. 페이지는 원본을 한 파일씩 읽고 50건씩 표시합니다.

순손익은 기존 후속 모형이 저장한 비용 반영 값입니다. 세부 취소 사유가 없으면 생성하지 않습니다. 일봉 내 도달 순서 불명 표시는 기존 결과를 사용합니다. 운영 계좌 거래는 별도 **거래** 화면에서 확인합니다.
