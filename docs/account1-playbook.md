# 1번 계좌용 플레이북 (노라무식 → 변환)

## 1번 계좌 전제

- 국장: SK하이닉스, 삼성전자, 유진테크
- 미장: 마이크론
- ISA/연금/IRP: S&P500 + AI/HBM ETF + 단기채
- 성격: **메모리 집중 중장기**. 레버리지 단타 계좌가 아님

## 가져올 것 / 버릴 것

| 노라무 | 1번 계좌 |
|--------|----------|
| 차트 그림(쌍봉·급락·저점 올림·중간에서 사기) | **그대로 사용** (사는 타이밍·비중 조절 필터) |
| 프로그램 타점 숫자 | 보조 점수화 (`pullback_long_score`) |
| 레버/인버스/배수 | **직접 매매 안 함** → 본주로 바꿔 대응 (SOXS→MU 방향반대, 2배→본주, 코루→삼전) |
| 양빵 | **사용 금지** (애매하면 현금) |
| 3% 초단기 손절 단타 | 최근 저점이 깨질 때만 비중 줄이기 |
| “따라하지 마라”식 저점 스캘핑 | FOMO 금지, 내려올 때만 |
| 애매하면 양빵 | 애매하면 **현금/지금은 안 삼** |

## 운영 규칙

1. **새로 사기 조건**
   - 최근 급락 이후
   - 저점이 직전 저점보다 높음
   - 가격이 최근 고점·저점의 **중간 ±4%** 안
   - 점수 70+ 일 때만 가진 현금의 10~20%씩 나눠서

2. **갖고 있을 때**
   - 점수 35 미만 + 저점 다시 못 올림 → 올라올 때 일부 줄이기 검토
   - 업황과 충돌하면 차트만으로 전량 사지 말 것

3. **절대 금지**
   - SOXS/코루/2배 상품을 1번 계좌에서 **직접** 매매 (글이 나오면 본주 방향만 반영)
   - 장중 고점 쫓아 사기
   - “오늘 반등하니까” 일시 몰빵

3-0. **불법과외 1편** (`NoramuLesson1`, 원글 [차트 불법과외 -1편](https://www.fmkorea.com/10160571194))
   - 선호 캔들: 장대양봉 → 도지 연속 → **거래량 없는** 장대음봉 → 즉시 장대양봉
   - 그 패턴은 **앞 매물대 돌파 후**에서만 가산. **빠지는 중**이면 신규 매수 후보에서 제외
   - 수렴 **돌파만** 보고 추격 금지 → 돌파 후 **윗구간 박스**가 있어야 롱 가산
   - 저점 대비 **+40%** 후 타이트 구간(수렴)은 신뢰도↓
   - 점수에 ± 가산되며, UI/제안에 `lesson1_note`로 표시

3-1. **레버 글 대응**
   - SOXS 롱 ≈ MU/반도체 **숏 쪽** → 새로 사기 보류·비중 줄이기 검토
   - 샌디 2배 롱 ≈ SNDK 롱 그림 참고 (레버 호가는 본주가로 쓰지 않음)
   - 코루 ≈ 삼전/국장 롱 방향 참고

4. **주간 루틴**
   - `php bin/score_symbol.php MU`
   - `php bin/score_symbol.php SNDK`
   - 국·미장 핵심 종목 점수와 **손절선**만 메모

## UI/점수 읽는 법 (중요)

프로그램은 **과거 매수가를 평균 내지 않습니다.** 지금 차트에 위 규칙을 적용한 결과입니다.

| 표시 | 의미 |
|------|------|
| 관심 사는 구간 (중간 가격) | 고점·저점의 중간 ±4%. **지금 시장가로 사라가 아님** |
| 손절선 | 최근 저점. 아래로 깨지면 이번 매수 계획은 끝 |
| 익절 — 규칙 | 중간↔최근 고점 사이 등 차트 규칙 |
| 익절/손절 — 과거 글 | 원글에 적힌 숫자의 중앙값 **참고**. 지금 적정가 아님 |
| 지금은 안 삼 | 중간 가격대가 보여도 매수 신호 아님. 현금 유지 |
| **새로 살 가격** | “현재가 X. Y~Z면 새로 검토 가능” 문장. 지금 시장가 매수가 아님 |

가격이 관심 구간보다 **위**이면 → 중간 가격까지 내려오길 기다림.  
손절선 **아래**이면 → 이번 그림 기준으로 새로 살 가격 없음.
