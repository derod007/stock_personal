한계: 같은 자료를 이미 검토한 뒤의 탐색 연구이므로 블라인드나 독립 검증이 아니다. 독립 재계산은 같은 일봉과 같은 규칙 정의를 쓰므로 구현 오류를 잡는 용도이며 규칙 선택의 타당성은 검증하지 않는다.
