# 코스피·코스닥 지수 일봉

요청 구간은 2024-09-01~2026-10-08이다. 두 시장 모두 일봉을 받지 못했다. 확인일 종가와 최근 60거래일 단순평균을 비교할 자료가 없다. 60일은 이 연구의 가정이며 작성자 원문 규칙이 아니다.

로컬에 있던 주식 일별매매용 키로 지수 API를 호출했다. 지수 API 승인이 없다. 키는 기록하지 않았다. 공개 샘플 키로 본호출을 대신하지 않았고, 로그인 세션도 만들지 않았다. 날짜·종가 필드의 의미는 응답이 없어 확인하지 못했다. 공식 설명은 2010-01-04부터의 일별시세, 요청 인자는 기준일자 `basDd`다.

Open API 이용약관은 제3자 제공을 금지한다. 받은 원응답이 없으므로 Git에 둘 원본도 없다. `data/ohlcv`와 `data/cache`는 쓰지 않았다.

`data/cache/kospi_naver.json`만 있다. 18837바이트, sha256 `1d495adcea3f55da345b220f202a278398b30c77e3d1cf65149569b6a5ac18df`. 날짜 285개, 2025-06-02~2026-07-31. 요청 구간의 앞뒤를 덮지 않는다. 코스닥 지수 캐시 파일은 없다. 공식 시계열이 없어 겹치는 날짜를 대조하지 않았다. 이 파일은 수정하지 않았다.
