# 유형1 + 20일 고가 돌파 후보

①을 관찰용 후보 보기로 개발한 기능이다. 기존 자동 추천/매매 조건을 교체하지 않는다.

- `type1_scan.php?scope=breakout`: 현재 조회 TOP100의 유형1 중 동일 완료봉에서 종가가 직전20봉 고가를 넘은 종목.
- `type1_scan.php?scope=all`: 유형1 전체와 돌파 상태·기준선·분석 종가의 거리.
- `type1_breakout.php`: 마지막 마감 스냅샷 해시를 검증한 후 당시 봉으로 계산한 돌파 후보. 기본 돌파 확인만 표시; 전체 보기 가능. 외부 시세 조회·장부 쓰기 없음.

장중 미완료봉의 돌파와 전일 유형1을 섞지 않는다. 유형1 분석 기준일과 돌파 기준일이 같아야 confirmed=true이다. 현재 조회 순위는 당일 최종 TOP100임을 보장하지 않는다. 마감 스냅샷도 제공자 순위 거래일 미확정 정보를 유지한다.

유형1은 동일한 고정 중심 사용. 20봉 조건은 PR141 표시 계산 사용. 자동 주문·추천점수·기존 고정 관찰의 다음시가/손절5%/목표15%/20봉 규칙은 변경하지 않는다.

이 목록은 **날짜별 조건 일치 후보**다. 연구의 같은 종목 재진입 간격·중복 거래 제외·자금 한도를 적용한 주문 목록이 아니다. 마감 고정 후보 화면의 신규 관찰 여부로 필터하지 않으므로 처음 유형1 등장 후 나중에 돌파한 종목도 표시 가능하다.

과거 연구: 두 기간 독립 실행 평균 +0.64%/+1.21%, 그러나 반기별 음수 및 기존 진입일 고정 필터의 이전기간 음수. 수익성 확정 아님. 이 기능은 자동 선택 목록으로 개선할 첫 단계이며 연구 성과를 계좌 수익률로 표시하지 않는다.
