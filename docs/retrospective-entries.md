# 진입 시각 기준 차트 재분석 (초기 샘플)

가능합니다. 방식은:

1. 글의 `posted_at` + 명시 가격/목표가 수집
2. 그 시각 **이전**까지의 OHLCV만으로 피처 계산 (미래 누수 금지)
3. 본인이 말한 구조(쌍봉·슈팅·절반·눌림)와 숫자가 맞는지 대조

아래는 Yahoo 일봉으로 재구성한 **1차 샘플**입니다.

---

## 케이스 A — 2026-07-09 `샌디 롱본이유` (목표가 1815)

**글 시각:** 2026-07-09 02:30 KST 전후  
**명시 규칙:** 쌍봉 → 하방 슈팅 → 쌍바닥 실패 → 저항 터치·저점 상승 → 절반 지지 + 1분봉·이상 거래량 → 롱 / 목표가 1815

### 당시 SNDK 일봉 (Yahoo)

| 날짜(KST 표기) | Open | High | Low | Close |
|---|---:|---:|---:|---:|
| 07-02 | 2043 | 2052 | 1693 | 1745 |
| 07-06 | 1828 | 1837 | 1713 | 1744 |
| 07-07 | 1619 | 1638 | **1485** | 1617 |
| 07-08 | 1591 | 1734 | 1590 | **1727** |
| 07-09 | 1835 | 1952 | 1801 | **1858** |

### 구조 해석 (글 작성 직전 기준)

1. **고점 실패/과열 후 붕괴:** 6월 말~7월 초 2000+에서 실패, 07-02에 1693까지 급락.
2. **하방 슈팅:** 07-07 저가 1485 — “지지하는 척 후 아래로 슈팅”과 일치.
3. **쌍바닥 실패 후 반등:** 1485 이탈성 슈팅 뒤 07-08에 1727로 회복 = 저점 다지기 시작.
4. **절반 구간:** 최근 스윙을 대략 1485~2050으로 잡으면 절반은 ~1767. 07-08 종가 1727은 절반 직하 눌림.
5. **목표가 1815:** 07-09에 고가 1952·종가 1858로 **목표가 도달·초과**.  
   → “목표가 찍으면 더 가도 안 가져간다” 스타일과 맞으면, 1815 근처는 익절 논리 구간.

**결론:** 이 글은 감이 아니라 **급락 슈팅 이후 절반 되돌림 눌림 롱**으로 읽는 것이 타당합니다. 1분봉·이상 거래량은 일봉만으로는 검증 불가(분봉 수집 필요).

## 케이스 B — 2026-07-08 SOXS 프로그램 타점 3.91

**글 시각:** 2026-07-08 14:40 KST  
**문제:** Yahoo SOXS 당시 가격대는 **약 45~50**. 3.91과 단위가 안 맞음.

가능한 해석:

- 역분할 전 표기/다른 화면 단위
- 한국 상장 유사상품
- 테스트용 가상 스케일

**구조만 보면:** 07-07~08 SOXS는 반도체 급락에 연동해 고가권(인버스 강세). “인버스 눌림 매수” 자리일 수는 있으나, **3.91을 그대로 학습 라벨로 쓰면 오염**됩니다.  
→ `entries.json`에 `symbol_note`로 경고 표기함. 학습 시 제외하거나 스케일 보정 후 사용.

## 데이터화 → PHP 프로그램 로드맵

1. **수집기 (다음 단계):** 노라무 글 URL/시간을 더 넣어 `entries.json` 확장  
2. **차트:** `bin/fetch_yahoo.php`로 일봉·1시간봉 캐시  
3. **피처:** `FeatureEngine` (절반·저점상향·슈팅·이평·거래량)  
4. **라벨:** 진입 후 N일 수익률 / 손절 여부  
5. **규칙 스코어 →** 나중에 로지스틱/간단한 ML  
6. **1번 계좌 출력:** `Account1Playbook`이 레버 시그널을 차단하고 비중만 제안

현재 레포에서 바로 실행:

```bash
php bin/fetch_yahoo.php SNDK 3mo 1d
php bin/fetch_yahoo.php MU 3mo 1d
php bin/analyze_entries.php
php bin/score_symbol.php MU
```
