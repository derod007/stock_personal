# 유형1 피보나치 되돌림 진단 v1 — 결과 집계 전 고정

2026-10-24. 대상은 PR124에서 완료한 KRX 독립 시가 거래의 유형1 전체 후보다. 계좌/신호/매매를 재실행하지 않고 저장 거래에 판단일 특징만 붙인다. 미래 수익으로 고점·저점을 고르거나 경계/기간을 최적화하지 않는다. 엘리엇파동은 이번 범위가 아니다.

판단일 T까지 마지막 60개 완료 유효 일봉을 사용한다. T봉이 반드시 있어야 한다. 60봉 안에 기준가격 불연속이 있으면 특징을 미확정으로 둔다. 미래 날짜는 잘라낸 뒤 계산한다.

피벗은 좌우 각각 3봉보다 고가가 엄격히 높은 봉(고점), 또는 저가가 엄격히 낮은 봉(저점)이다. 동률은 피벗이 아니다. 같은 봉이 고점과 저점이면 두 피벗 모두 제외한다. 우측 3봉이 완료된 뒤에만 확인되므로 미래 피벗을 T에 소급하지 않는다.

60봉 안에서 마지막으로 확인된 고점 H를 고르고, 그보다 앞선 가장 최근 확인 저점 L을 고른다. L→H가 시간순이고 H>L이어야 한다. 조건이 안 되면 이전의 다른 조합으로 갈아타지 않고 미확정이다. 별도 상승폭/거래량/기간 조건은 추가하지 않는다. 이것은 최근 상승폭의 한 가지 기계적 정의이며 유일한 정답이나 엘리엇파동 카운트가 아니다.

T종가 C의 되돌림 비율 d=(H-C)/(H-L). 0 미만(고점 위), 0~38.2% 미만, 38.2~50% 미만, 50~61.8% 이하, 61.8% 초과~100% 이하, 100% 초과를 별도 집계한다. 50%는 관행적 중간 기준선이며 피보나치 수열 비율이라고 주장하지 않는다.

사전 지정 주 비교는 38.2%≤d≤61.8% 대 그 외 계산 가능한 유형1이다. 전체 771후보 기준도 별도 제시하며 계산 불가는 탈락/손실로 취급하지 않는다. 세부 구간은 기술통계이며 결과가 가장 좋은 구간을 새 필터로 선정하지 않는다.
