# 자정 이후 완료 일봉

수동 스캔은 장중 거래소 시간에만 당일 실시간 일봉을 요청합니다. 장외에는 수집된 완료 일봉으로 분석하고 그 기준 시각을 표시합니다. 한국/미국 거래소 시간과 주말을 구분하며 휴장일 캘린더를 추정하지 않습니다. 평일 휴장 장중 시각에는 실시간 검증이 실패하면 기존 대체 표시를 유지합니다.

원인 경로: 네이버 보충 봉에 is_complete=false가 고정됐고 기존 장중 캐시 봉도 OHLCV 패치 이후 완료 여부가 갱신되지 않았습니다. 따라서 새 가격이 있어도 CandleClock에서 제외될 수 있습니다. 별도로 자정 이후 당일 자료 검증은 전날 시세를 거절했습니다. 제공 파일에는 로컬 캐시와 HTTP 응답이 없어 당시 어떤 수집 경로가 실행됐는지는 단정하지 않습니다.

네이버 일별 시세를 성공적으로 수집한 시각(캐시 사용 시 원래 저장 시각)이 해당 봉 마감 이후임을 확인한 경우에만 보충/갱신 봉을 완료 처리합니다. 마감 전 수집 캐시는 자정이 지나도 확정하지 않습니다. 실제 OHLCV를 검사하며 기존 완료 Yahoo 봉은 보존합니다. 네이버 수집 실패의 오래된 캐시를 현재 시각에 새로 수집한 자료처럼 취급하지 않습니다.

최신 자료 수집이 모두 실패하면 없는 완료봉을 만들지 않습니다. 화면의 분석 기준 시각은 실제 사용된 봉을 뜻하며 최신 거래일 확보를 보장하는 문구가 아닙니다. 예약 실행은 계속 완료봉 엔진을 사용합니다. 급등후급락·손익비 규칙과 고정 전략 파일은 바꾸지 않습니다.

검증: 마감 후 추가/갱신 봉, 마감 전 캐시 배제, 기존 확정봉 보존, 부분 OHLCV 거절, 한국 장중/저녁/자정/주말과 미국 시간, 제공된 레메디·아이씨티케이·제이앤티씨 10월 6일 원본으로 자정 재현.
