# 고정 종목군과 별도 연구 계좌

2026-09-16에 v1 수동 표본을 고정했습니다. 미국·한국 각각 10종목, 연구 업종 5개에 2개씩입니다. 최근 수익률 순위로 선별하지 않았으며 시가총액 상위 목록이나 전체 시장 대표 표본이라는 주장은 하지 않습니다. 현재 이름을 고른 표본에 생존 편향이 있고, 업종은 GICS/KRX 공식 분류가 아닌 연구용 수동 묶음입니다. 기업행동·상장 변경·공급자 오류를 자동 보정하거나 대체 종목을 넣지 않습니다.

- 미국: 반도체 MU/NVDA, 기술 AAPL/MSFT, 금융 JPM/BAC, 에너지 XOM/CVX, 헬스케어 JNJ/MRK
- 한국: 반도체 005930/000660, 자동차 005380/000270, 금융 105560/055550, 인터넷 035420/035720, 소재 051910/010130 (모두 .KS)

기존 paper-us/paper-kr 설정은 유지합니다. 새 ID는 research-us-v1/research-kr-v1입니다. 초기자금과 위험/보유/업종 한도는 기존 계좌와 같고 매매 조건도 그대로입니다. 종목이 늘어도 보유 한도를 확대하지 않습니다. 종목 코드 순서대로 주문을 검토하는 기존 방식 때문에 자금 경합과 순서 편향이 존재합니다.

## 시작

머지 후 main에서 git pull --ff-only. 기존 계좌/비교 예약 작업을 유지하면서 연구용 작업을 별도로 추가합니다. 기존 설정의 symbols를 덮어쓰지 마세요.

```
python bin/paper_research_daily.py --config=config/paper-research-us-v1.json
python bin/paper_research_daily.py --config=config/paper-research-kr-v1.json
```

프로젝트 밖에서 실행할 때 스크립트 절대 경로를 사용합니다. 기존과 같은 PAPER_STATE_DIR와 PHP/Python PATH를 사용합니다. 실제 관측 시작일은 첫 account_started 시각으로 기록됩니다. 정의일을 과거 성과 시작일로 소급하지 않습니다. 기존 계좌와 새 계좌의 누적 수익률을 시작일 조정 없이 비교하지 마세요.

종목/업종/한도/설정 변경은 기존 config hash 보호가 차단합니다. 새 실험이 필요하면 새 파일·새 research- ID·새 universe.version으로 시작합니다. 실패한 종목을 몰래 제외하거나 다른 종목으로 치환하지 않습니다. 리셋이나 자동 전략 변경은 없습니다.

## 수집 부담과 보류

기존 수집기는 순차 실행하며 단계별 기존 30분 제한을 유지합니다. 연구 래퍼는 수집/한국 정규장 보정/계좌 계산/총 소요 시간, 요청 종목별 확보 상태, 누락 사유를 research-runs/<account>에 원자적으로 남깁니다. 기존 runs/<account>-forward에도 표준 실행 로그를 남겨 주간 요약에서 볼 수 있습니다.

모든 요청 종목에 대해 중복 없는 manifest, 파일/원본 응답 SHA256, 숫자/범위 유효 OHLCV 60봉 이상을 확인한 뒤 계좌를 갱신합니다. 일부 누락이면 갱신하지 않고 실패 종료합니다. 이것은 새 연구 래퍼의 입력 사전 검사이며 완전한 가격 조정·시장 달력·최신성 확인이 아닙니다. 완료 일봉, 최신 데이터, 과거 변경 및 실행 품질 검사는 기존 계좌 엔진이 수행합니다. 입력 확보 10/10이어도 계좌는 품질 문제로 주문을 보류하거나 중단할 수 있습니다.

원본 공급자 응답은 기존 입력 보관 정책으로 유지됩니다. 부분 수집 실패의 임시 다운로드는 제거되며 상태/사유/소요 시간만 남습니다. 원본 계좌는 손대지 않습니다. 연구 계좌에 보유가 있다면 갱신 실패 기간의 평가가 오래됐을 수 있으므로 최신 실행 시각과 마지막 평가일을 확인하세요.

## 보기

모의 계좌 → 고정 종목군 연구 또는 paper_universe.php?account=research-us-v1 (한국 research-kr-v1).

연구 화면에서 종목군 정의일/버전, 실제 시작일, 요청/확보 종목, 수집 시간, 업종·종목별 평가/주문/체결/청산/이익 건수와 실현손익, 종목별 제외/품질 사유를 봅니다. 계좌·주간 요약·거래별 분석 링크는 해당 연구 계좌 ID를 유지합니다. mode=replay는 별도 기록이며 실시간 수집 로그를 섞지 않습니다.

업종 손익은 공통 자금 계좌의 실현손익 기여도입니다. 업종별 독립 투자 수익률이나 시장 지수 대비 초과 수익이 아닙니다. 미실현손익은 기존 계좌/주간 화면에서 확인합니다. 계좌 총 실현손익과 집계 결과가 맞지 않으면 경고합니다.

## 검증

네트워크 없는 테스트로 일부 누락 시 계좌 미실행, 정상 수집 후 실행, SHA/원본 응답 검사, 부족한 봉, 중복 manifest, 기존 계좌 ID 차단, 고정된 10종목/5업종, 업종 손익 대사와 읽기 전용 렌더링을 검사합니다.

GitHub Actions의 public-preflight는 공개 데이터 수집 가능 여부와 소요 시간을 기록할 뿐 계좌를 만들지 않습니다. 외부 서비스 실패는 코드 검사 성공과 구분해 artifact의 coverage/error_type을 확인합니다. GitHub 수집 성공이 사용자 PC에서의 성공을 보장하지 않습니다.

한국 연구 계좌도 최신 공통 수집 흐름(2년 일봉 → 네이버 정규장 보정)을 사용합니다. 보정 뒤 입력을 다시 검사합니다. 기존 한국 계좌의 거래대금 스캔 방식과 달리 연구 계좌는 위의 고정 10종목을 평가하므로, 두 계좌 차이를 종목 수만의 효과로 해석하면 안 됩니다. 한국 예약 작업은 기존 정규장 확정 이후 시간(20:20)에 별도로 추가하세요.
