# KRX 원가격 신규 추천 비교 v1

평가 2024-10-08~2025-10-02, 243세션, 당일 TOP100 24,300쌍. 준비 2023-10-13~2024-10-07 240세션. 합집합 1248종을 매일 후보로 사용하지 않는다.

기준은 운영 ChartPlanEngine(account1, context=true), 대안은 PR #84의 정적 미러에서 상승 눌림 recovery_close만 제외한다. 실행 전 미러 허용 변경을 검사하고, 매 판정마다 제외 옵션을 끈 미러와 운영 엔진의 전체 plan이 일치해야 한다. 독립 전략 구현 검증이 아니다.

KRX TDD 원본, 수정 여부 미확정. 가격 조정·Yahoo 혼합·0가격 제거·공백 보간 없음. JSONL을 신뢰하기 전에 966개 원본 해시·BAS_DD·종목 중복을 검사하고, 모든 1248×483행의 사용 필드·원출처·상태를 원본에서 별도 재구성해 대조한다. 이전상장은 PR #92에서 확인한 3종만 허용한다. raw 원본이 없는 실행은 거부한다.

입력은 각 판정일 15:30 KST까지다. OHL=0 원행은 PaperQuality에 남기고, CandleClock이 완료봉에서 제외한다. no_row는 원본 상태로 기록하되 가짜 봉으로 만들지 않는다. 기존 엔진의 중간 공백 미검사 정책은 바꾸지 않는다. 준비 240일은 추천 엔진의 240봉 제한을 뜻하지 않는다. 전체 과거 입력 길이에 의존하는 패턴은 이 준비 길이에 영향을 받을 수 있다.

단절은 to<=판정일일 때만 경고에 포함한다. 단절·초기 공백·중간 공백은 관찰값이며 새로운 진입 필터가 아니다. 단절 목록에 없다는 이유로 안전 판정하지 않는다. 신규 추천 입력만 다룬다. 보유·대기·체결·현금·기업행사 수량 처리를 호출하지 않는다.

숫자는 원가격 엔진 ready와 기존 PaperQuality까지 통과한 quality_eligible을 분리한다. 후자도 실제 매매 가능·계좌 주문·검증된 추천을 뜻하지 않는다. 두 엔진의 상태·패턴·진입·손절·목표·손익비·진단과 입력 해시·원인 날짜를 종목별로 저장한다. 추천 건수는 독립 거래 건수가 아니다. 수익률을 계산하지 않는다.

검증/실행마다 원본과 JSONL을 재대조한다. 연구 코드·PHP 버전·전략·공개 입력·JSONL 바이트 해시가 바뀌면 이어 하기를 거부한다. 새 연구 버전이 필요하며 기존 결과를 덮어 바꾸지 않는다. CLI 기본값은 첫 8세션(추가 8세션 아님), --sessions=all은 243세션까지 누적 확장한다. 종목별 결과는 원자적으로 저장하고 다시 실행하면 완료 쌍을 건너뛴다. 각 결과 내용 해시도 재검사한다.
