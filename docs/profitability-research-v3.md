# 수익성 연구 v3

## 순서와 사용법

1. 공통 엔진 diagnostics에 두 패턴 원래 상태와 최종 보류 상태를 보존합니다. 눌림목은 추세·가격 구간·거래량·확인봉 조건을 개별 기록합니다. gate는 해당 단계까지 도달한 경우에만 평가됩니다. 돌파 재지지는 상태별 집계입니다.
2. 여러 종목의 5년 일봉을 동일한 규칙으로 재생합니다.
3. 확인 후 지정가/후보 중앙값 지정가 × 고정 목표/추적 손절의 네 가지 사전 정의 조합을 비교합니다.
4. 앞 60%에서만 실험 후보를 선택하고 중간 20%와 마지막 20%를 별도로 보고합니다. 양의 평균 순손익·완료 30건·3종목 이상이라는 최소 연구 조건을 충족하지 못하면 선택하지 않습니다. 이것은 실시간 적용 승인 기준이나 통계적 유의성 기준이 아닙니다.

```bash
php tests/v3.php
python3 bin/fetch_comparison_data.py --years=5 --symbols=MU,AAPL,MSFT,JPM,XOM,005930.KS,000660.KS,005380.KS --out=data/research
python3 bin/run_research.py
```

GitHub Actions의 Strategy research에서 직접 실행할 수도 있습니다.
아티팩트 profitability-research의 report.md는 성과표, summary.json은 비교 요약입니다.
종목별 -research.json에는 매매 내역·탈락 집계·후속 움직임이, .jsonl에는 시점별 판단 근거가 기록됩니다.

## 공정한 비교와 한계

- 신호 시점까지의 완료 일봉만 계산에 사용합니다. 주문은 다음 봉부터 3봉 유효하며 한 종목/방식 내 주문·포지션은 겹치지 않습니다.
- 최대 보유 20봉, 편도 비용 10bp, 슬리피지 5bp. 시장별 비용은 아직 단순화되어 있습니다.
- 후보 조기 진입은 구조상 가격과 RR>=1.5가 있어야 하며 최종 추세/위험 차단은 유지합니다. 확인 조건을 생략하는 연구 대안으로, 실시간 추천에는 반영하지 않습니다.
- 추적 손절은 신호 시점 ATR의 2배 간격으로 종가 기준 상향하고 다음 봉부터 적용합니다. 체결 전 취소 규칙은 두 청산 방식이 같습니다. 체결 후 추적 방식은 고정 목표를 사용하지 않습니다.
- 구간 경계에서 미완료 거래는 불완전으로 남고 평균 손익에서 제외합니다. 주문 수/상태별 수를 함께 보세요. 각 구간 시작에는 주문/포지션을 초기화합니다.
- 낙폭은 **종목별 청산 거래 누적 자산 기준**입니다. 미실현 손실 및 동시 보유를 반영한 포트폴리오 MDD가 아닙니다.
- 제외 후보의 이후 10봉 종가 수익·최대 상승·최대 하락은 관찰용입니다. 중복 후보 날짜가 포함되며 체결 가능한 수익률이 아닙니다.
- 현재 생존한 8개 종목은 시장 전체를 대표하지 않습니다. 상장폐지/당시 편입 종목, 기업행위 보정, 실제 호가·부분체결을 추가 검증해야 합니다.
- v2에서 이미 본 종목/기간도 포함되므로 뒤 20%도 완전히 새로운 독립 검증 자료가 아닙니다. 이 결과를 바탕으로 조건을 조정하면 이후 모의 기록이나 미사용 자료로 재검증해야 합니다.
- 결과가 좋다는 이유만으로 운영 조건을 자동 변경하지 않습니다. 부족한 표본/검증 성과는 그대로 보고합니다.
