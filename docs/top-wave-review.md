# 보유 종목 고점 재시도 / L2 종가 이탈 표시

모의 계좌 `paper.php` 하단의 **고점 재시도 · 보유 축소 검토**에서 확인한다. 기존 daily가 저장한 계좌 history를 읽으므로 별도 예약/수집이 필요 없다. 보유(filled)만 표시하며 대기 주문은 제외한다. 원장/현금/수량/손절/목표/기존 추천 필터와 전략 지문을 변경하지 않는 보조 판독이다.

## 합의된 구조

`H1 → L1 → H2 → L2 → H3 → L3 → 재도전 고점`을 확인한다.
L2는 **H2와 H3 사이의 조정 저점**이며, 재도전 실패를 확인하는 날 고정한다. 이후 하락 저점으로 기준선을 내리지 않는다. 원문 그림의 모호한 파동 표현을 이 프로젝트에서 구체화한 정의이며 원문에 정량 규칙이 모두 제시된 것은 아니다.

- H1/H2/H3는 순차 상승 고점, L2 > L1, L3 ≥ L2. L3 < L2이면 파동 구조 제외로 표시하며 축소 후보가 될 수 없다. 최소 3개 상승 고점(그 사이 높은 고점 돌파 2회)을 요구한다. 4개 이상도 인정한다. 화면은 고점 수, JSON은 별도로 돌파 횟수를 제공한다.
- 고저점은 좌우 2봉보다 엄격히 높거나 낮은 극값. 오른쪽 2개 완료 봉이 확보된 날에만 확인한다.
- 서로 반대인 고저점은 최소 3봉 간격, 가격 차이는 이전 피벗의 3% 또는 피벗 당시 14봉 ATR 중 큰 값 이상. 같은 종류는 더 극단적인 값으로 갱신하되 고정된 L2는 갱신하지 않는다. 한 봉이 고점·저점을 동시에 만족하면 순서를 추측하지 않는다.
- 최근 3개 상승 고점은 각각 이전 고점보다 0.5% 초과 상승, H1~재도전은 120봉 이내.
- 재도전 고점은 H3의 97~102% 범위이고, 그 고점을 확인한 날의 종가는 H3 미만이어야 실패다. 작은 초과 돌파 후 실패도 포함한다.
- 위 수치는 구현 초깃값이다. 원문 수치나 검증된 최적값으로 주장하지 않는다. 이 PR은 박스권 선행 여부를 새 필수 조건으로 삼지 않는다.

## 상태

- 재도전 실패: 아직 축소 표시 없음.
- L2 지지 시험: 저가가 L2 이하이나 종가는 L2 이상. 같은 가격으로 마감해도 이탈 아님.
- 선행 이탈: L2 발생 다음 봉부터 실패 확인 전까지 종가 이탈 이력이 있으면 별도 표시. 회복해도 같은 에피소드를 정상 후보로 승격하지 않는다.
- 실패 확인 당일 이탈: 이전 이탈 없이 확인 당일 처음 종가가 L2 아래라면 별도 관찰하며 정상 후보에서 제외한다.
- 보유 축소 후보: 위 제외 사유가 없는 구조에서 실패 확인일보다 **뒤의 봉**부터 현재 완료 일봉 종가가 고정 L2보다 **엄격히 낮음**. 별도 완충률/2일 연속 조건 없음.
- L2 회복 관찰: 한 번 이탈한 뒤 종가가 L2 이상으로 복귀. 축소 후보 뱃지를 관찰로 바꾸지만 경고 에피소드는 유지.
- 전고점 회복: 돌파 후 높은 저점 확인을 기다리는 상태를 표의 판독 칸에도 표시한다. L2 종가 이탈은 이 상태보다 우선한다.
- 경고 해제: H3/실패 재도전 고점 중 높은 값을 종가로 돌파한 **뒤**, 돌파 전에 확인됐던 가장 최근 저점보다 높은 새 조정 저점이 확인되고 현재 종가도 L2 이상일 때. 돌파 시 기준 저점을 고정하며, 그 저점 아래 종가 하락 시 돌파 확인을 취소.
- 경고 해제 뒤에는 새 파동을 쌓아 다음 에피소드를 찾는다.

## 시점 / 자료 해석

피벗 발생일과 실제 확인 가능일을 함께 표시한다. 오른쪽 봉을 기다리는 동안 과거 날짜로 신호를 소급하지 않는다. 완료된 입력을 앞에서부터 재생하며, 뒤에 미래 봉을 추가해도 이전 상태 이력은 바뀌지 않는다. 실패를 확인한 날 이미 L2 아래인 사례는 정상 후보로 표시하지 않는다. 선행 이탈·동일일 이탈·구조 제외의 에피소드는 경고 해제 후 새로운 파동이 형성되어야 다시 정상 후보가 될 수 있다.

이 화면은 저장 일봉을 현재 규칙으로 **재현한 결과**다. 실제 그 날짜에 알림이 발송됐다는 이력이 아니다. 자동 매도·축소 비율·숏 주문을 생성하지 않는다. 기존 고점판독 점수/신규 진입 차단은 별개로 유지한다.

계좌 무결성 오류, 계좌 중단, 60봉 미만, 중복/잘못된 일봉은 정상 후보로 표시하지 않는다. 차트 판독은 `data_asof`의 마지막 저장 일봉 기준으로 유지한다. 경과 4일 기준 삭제는 제거했다. `reduce_candidate` 역시 그 기준일의 차트 판독이며 실시간 주문 권고가 아니다. 최신성은 별도 `freshness` 필드/표 열에 표시한다. 같은 시장의 저장 이력에 더 최신 완료 봉이 있으면 `missing_observed_session`(갱신 필요), 아니면 `unverified`(시장 전체 최신성 확인 불가)다. 미래 관측과 다른 시장 관측은 비교하지 않는다. 거래소 휴장 달력이 없어 시장 전체 수집 중단이나 예정 거래일 누락을 확정하지 못한다. 장기 휴장 때문에 판독을 지우거나 최신이라고 단정하지 않는다. replay 계좌는 그 계좌의 마지막 평가 시각 기준이다.

## JSON 조회

```bat
php bin/paper_top_wave.php --account=paper-kr
php bin/paper_top_wave.php --account=paper-us --mode=replay
```

파일 저장 없이 stdout으로 내보낸다. 규칙 버전·설정, 입력 해시, 고정 구조, 상태 전환 확인일, 피벗 발생/확인일을 포함한다. 한 에피소드 안에서는 L2를 고정하지만, 공급자가 과거 봉을 바꾸거나 규칙을 바꾸면 전체 재현 결과는 달라질 수 있다.

## 원문과의 차이

터치 대신 종가 이탈을 쓰는 것은 사용자 선택이다. 박스권 선행 조건은 이번 보완에서도 추가하지 않는다. 이 구현은 원문 전체를 그대로 재현한 신호가 아니라 합의된 파동·종가 규칙의 보유 검토다. 판독 버전은 `top_wave_review_v2`다.
