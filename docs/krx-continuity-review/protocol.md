# KRX 신규 추천 근거의 가격 단절 교차 검사 v1

PR #94 결과를 보존한 추가 연구다. 기준/대안 모두 최종 선정 뒤 같은 검사를 적용한다. 원가격, ready, 패턴 우선순위, 진입·손절·목표는 바꾸지 않는다. 보류 시 차순위 패턴을 선택하지 않는다. 계좌 실행이나 전략 채택이 아니다.

## 판정

- 판정일 이하의 관찰된 단절만 사용한다. 근거 시작일 < 단절 to ≤ 판정일이면 `hold_cross_break_source`로 기록한다. 단절과 같은 날 시작한 근거는 이전 가격으로 보지 않는다.
- 근거 재계산이 저장 계획과 다르거나 근거가 없으면 `hold_unresolved_provenance`. 억지로 통과시키지 않는다.
- 나머지는 `no_crossing_in_traced_scope`. **가격 안전성 통과를 뜻하지 않는다.** 미탐지 기업행사, 전체 과거에 의존하는 공통 위험/추세 문맥, 탈락한 구조의 영향, 체결·보유·대기 관리는 검사하지 않는다.
- 96건은 임계값으로 관찰한 단절 목록이다. 공식 확인 기업행사는 원래 메타데이터대로 구별하며 전부 분할·병합으로 단정하지 않는다.

## 추적 범위

- 상승 눌림: 최근 40봉의 상승 구조/지역 조건, 목표 20봉(당일 제외), 손절 10봉. 목표 고가와 손절 저가의 모든 동률 날짜. ATR14를 독립 계산하여 features의 소수 4자리 ATR과 대조한다.
- 회복: 고정 저항, 이전 지지, 기준 저점, 높은 저점, 목표 피벗의 가격·날짜·2봉 확인 창; 이탈·돌파·확인 날짜 및 이탈의 MA20부터 판정일까지 상태 구간. 목표와 손절 재계산. 모든 피벗은 판정일 안에 확정되어야 한다.
- 재지지: 돌파 전 20봉 박스부터 확인일까지, 손절 구간; 목표가 박스 확장인지 과거 고점인지 재계산. 엄격한 `<` 갱신 규칙에 따라 같은 가격이면 먼저 선택한 고점을 유지한다.
- 선택된 구조의 근거만 추적한다. 이 검사를 완전한 엔진 의존성 분석으로 표현하지 않는다. 보류 건수를 계좌 주문 감소나 수익률로 해석하지 않는다.

## 무결성·실행 범위

첨부된 report-243 바이트 해시, inputs의 정규 JSON 해시, 기존 코드 LF 해시, 종목 결과 payload 해시, JSONL 바이트 해시를 검사한다. 전체 모드에서는 24,300쌍 결과를 다시 모아 기존 results 해시와 summary도 대조한다. 원본 KRX API 재검증은 실행하지 않고 PR94에 기록된 원본 대조와 고정 JSONL에 의존한다.

최종 품질 통과 추천의 합집합만 as-of 엔진 재계산 후 추적한다. 8종목 모드는 명시적 `--symbols`가 있어야 하며 complete=false다. 전체 자료 누락을 부분 실행으로 숨기지 않는다. 출력은 새 경로에만 쓰고 기존 출력이 다르면 거부한다. 동일 재실행은 쓰지 않는다. 예전 결과를 덮어쓰거나 해시를 자동 갱신하지 않는다.
