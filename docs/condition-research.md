# 단일 조건 가정 손익비 연구

## 실행

```sh
php bin/paper_condition_research.php --account=paper-kr
```

기존 PAPER_STATE_DIR의 원본 감사 로그와 저장 후속 evidence만 읽는다. 새 시세를 조회하지 않는다. 결과는 별도의 `condition-research/paper-kr/latest.json`과 이력으로 저장한다.
화면: `paper_rr.php?account=paper-kr&mode=forward&condition_research=1`.

저장소의 동결 자료로 재현하려면:

```sh
php bin/paper_condition_research.php --account=paper-kr --source-dir=docs/paper-kr-5d-source
```

`--output-dir`로 연구 결과 디렉터리를 지정할 수 있다. 원본 rr-audit/followup 하위에는 결과를 쓰지 못한다. 기본 최근 5개 기록일, `--days`로 지정한다.

## 방법과 한계

- 손익비만 미확인이고 눌림 조건 하나만 실패한 모든 사례를 선택한다. 이후 수익률로 대상을 고르지 않는다.
- 원본 일봉과 참조된 가격 자료의 SHA-256을 검증한다. 해시가 맞지 않으면 실행을 중단한다.
- 원본 관측 해시·파일·종목·판정봉이 정확히 일치하는 evidence만 연결하며 기존 가격 동일성·품질·늦은 관측 차단을 유지한다.
- 현재 엔진으로 당시 입력·시각·프로필·추세 옵션을 재현하고 저장 판정과 주요 필드를 대조한다. 다르면 가정 매매를 계산하지 않는다. 이는 과거 코드 버전을 확인했다는 뜻이 아니다.
- 조건 하나를 완전히 제거하는 가정이다. 거래량 85→95 등 특정 완화 폭을 시험하거나 최적화하는 기능이 아니다.
- 진입: 당시 완료봉 종가. 손절: 당시 최근 10봉 저가 최소값 - 0.2 ATR. 목표: 당일 제외 이전 20봉 고가 최대값. 가격은 기존 방식으로 절삭한다.
- RR 1.5, 유효 가격 순서, 기존 상위 추세 추가 RR 조건을 다시 확인한다. 통과한 경우에만 다음 봉부터 기존 3봉 지정가/20봉 보유 시뮬레이터로 검증한다. 비용과 장중 손절 규칙도 기존과 같다.
- 원본 추천·기존 지정가 후보와 연구 결과는 별도다. 과거 로그나 계좌 상태를 수정하지 않는다.
- 원래 지정가 취소 원인을 기존 시뮬레이터와 같은 분기 순서로 설명한다. 목표·지정가 동시 접촉의 실제 순서는 일봉만으로 알 수 없다. 손절과 지정가만 같은 봉에서 닿으면 기존 시뮬레이터는 체결 후 손절로 처리한다.
- 재지지 화면의 원래 상태·사유는 저장된 진단값이다. 제공되지 않은 상세 게이트를 만들어 통과로 표시하지 않는다.
- 미기록 전략 버전은 계속 미기록으로 유지한다. ETF 제외 전후 자료는 원본을 보존하며 현재 종목군 성과와 동일시하지 않는다.

## 집계 수정

분석 불가 기록과 판정봉 미기록 기록을 단일 조건 분류에서 별도 제외한다. 같은 종목의 null 판정봉을 중복으로 합치지 않는다. 실제 유효한 종목·판정봉의 중복만 제외한다. 모든 원본 기록은 그대로 보존한다.
