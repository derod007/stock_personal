# 단일 조건 탈락 비교

`paper_rr.php?account=paper-kr&mode=forward&review=1`의 최근 5개 기록일 진단에 표시한다.

- 저장된 선택 패턴만 사용한다. 원본·당시 판정·매매 임계값을 바꾸거나 과거 전략을 현재 전략으로 추정하지 않는다.
- 모든 필수 증거가 있고 한 조건만 실패하면 **단일 탈락 확인**이다.
- 실패한 조건은 하나지만 RR/위험/품질/세부 조건 등이 미평가이면 **단독 미충족 · 나머지 미확인**이다. 이 그룹은 비교 가능한 추천 후보 수가 아니다.
- 거래량 두 조건, RR와 추세, 서로 다른 위험 유형의 동시 실패는 단일 실패로 합치지 않는다. risk_blocked와 그 상세 원인 중복만 제거한다.
- 재지지는 세부 게이트가 없으므로 ready/rejected_rr로 확인이 끝난 경우만 확인 통과를 인정한다.
- 확인 전 후보의 RR은 확인 시점 RR로 쓰지 않는다. 조건 변경 시 RR을 다시 평가해야 한다.
- 기존 추천은 별도 참고군이다. 같은 전략 버전·패턴·추세 적용 여부끼리 보되, 버전 미기록 그룹은 관찰용으로만 사용한다. 최초 추천 참고군이 0건이면 생성하지 않는다.
- 선택 기간은 최근 5개 저장일이다. 동일 종목·판정봉은 그 기간의 첫 기록만 집계한다. 이후 저장 기록으로 빠진 결과를 임의 연결하지 않는다.
- 원본 관측 해시·파일·종목·판정봉이 일치하는 기존 후속 결과만 연결한다. pending/complete/no_future_bars 이외 상태의 잔존 수익률은 집계하지 않는다.
- 각 1·3·5·10·20봉별 완료 표본/대상, 상승 비율, 평균 종가 수익률, 평균 최대 상승·하락폭을 표시한다. 미완료는 0%가 아니다.
- 서로 다른 날 같은 종목은 독립 표본이 아니며, 관찰 수익률은 비용 반영 체결 성과나 필터의 인과 효과가 아니다.

## 새 완료봉 갱신

```sh
php bin/paper_followup.php --account=paper-kr
```

일반 실행은 가격 공급자에서 일봉을 조회한다(기존 캐시 최대 1시간). 원본과 추적 가격의 품질·동일성 검사는 계속 적용된다. 로컬 서버의 상태를 갱신하려면 로컬 프로젝트에서 실행한다.

`--saved-evidence`는 기존 저장 가격과 기존 평가 시점으로 재계산하므로 새 완료봉을 추가하지 않는다.
기존 `paper_daily.py`는 거래대금 스캔 후 추천 0건/계좌 처리 실패에도 finally에서 일반 후속 실행을 호출한다. 예약 작업은 새로 만들지 않는다.

5개 기록일 누적과 각 판정 이후 5개 완료봉은 다르다. 페이지는 새로 저장된 후속 결과를 읽어 표시하며 페이지 조회 자체는 가격을 수집하지 않는다.
