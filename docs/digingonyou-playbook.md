| 근거 | `data/alpha/digingonyou_srls.json` 수집분 (일부 430 차단) |
| 목적 | 노라무처럼 **규칙으로 고정** → **현재 차트**에 적용 |

> 과거 글 가격을 그대로 복붙하는 것이 아니라,  
> 글에서 반복되는 **판단 방식**을 뽑아 오늘 일봉에 쓴다.

## 노라무와 차이

| | 노라무 | 디깅온유 |
|--|--------|----------|
| 핵심 | 절반 되돌림 + 저점 상향 | **급락·투매 후 분할 매수**, 반등 시 분할 매도 |
| 진입 | 스윙 절반 ±4% | **투매 저점 근처**(플러시 저~저+α) |
| 익절 | 절반~스윙고 중간 | **반등 구간에서 분할 청산** 후 재매수 대기 |
| 무효화 | 구조 스윙저 | **매수 시점 저점(플러시 저) 이탈** |
| 지수 | 보조 | **코스피 지지/시나리오 레벨**을 강하게 봄 |
| 스타일 | 구조 스윙 | 시나리오·복기·비중 회전 (국장↔미장) |

## 가져올 규칙 (엔진화 대상)

1. **투매·하한가 연속 ≈ 바닥 후보**  
   주도주가 급락(하한가/대폭 음봉 연속)이면 “거의 바닥 근처”로 본다.  
   → 현재 차트: 최근 구조 플러시(급락봉) 존재 + 가격이 플러시 저 근처.

2. **저점에서 분할 매수 → 반등에서 분할 매도 → 다시 저점 매수**  
   예: 하닉 169만 매수 → 211~220만 분할매도 → 지수 6730대에서 재매수.  
   → 엔진:  
   - 관심구간 = 플러시 저 ~ 플러시 저×1.08 (투매대)  
   - 익절 힌트 = 플러시 저 대비 약 +20~30% 또는 최근 반등고  
   - 무효화 = 플러시 저(또는 매수일 저)

3. **지수 시나리오**  
   “이 레벨 지키면 비중”, “최악이면 여기” 식으로 코스피 레벨을 먼저 잡음.  
   → 1차는 개별주 플러시 규칙만 자동화. 지수는 글 라벨 보강 후.

4. **상대 강도 / 시장 로테이션**  
   국장 약하면 미장(반도체 등) 선호 언급.  
   → 바이어스 메모로만 (개별 타점은 플러시 규칙).

5. **애프터·ADR·지지 확인**  
   하방 단단해졌다는 확인을 좋아함.  
   → `higher_low` 또는 플러시 이후 저점 방어를 가산.

6. **하이라이트/채널 지지 «밟으면 매수»** (추가 배치)  
   APP·ASTS·SNDK·삼전 글에서 반복: 미리 그어둔 지지·채널 하단을 **밀면(프로그램이 누르면) 잡는다**.  
   지지 이탈 시 다음 하단(2차·3차)까지 연다고 봄.  
   → 엔진: 스윙저/플러시저를 «1차 하이라이트»로 보고, 그 근처를 관심구간.  
   → 무효화=1차 저. 이탈 시 2차 ≈ 저×0.90 메모.

7. **지지 지키면 홀딩, 깨면 던짐**  
   삼전 예: 채널 이탈해도 하이라이트 지지 밟고 올라오면 홀딩 유지.  
   → 가격이 관심구간 안·위면 신규/홀딩 쪽, 무효화 아래면 관망.

8. **섹터·로테이션 계획**  
   러셀↔빅테크 실적↔반도체+소부장. 폭락 후 **바닥 지지하고 올라온 체력주** 위주.  
   → 개별 타점 엔진과 분리, 바이어스/메모용.

## 버릴 것 / 주의

- 지인 대화·감정적 복기 문장 → 규칙으로 안 씀  
- 글에만 있는 **과거 절대가**(169만·84불 등) → 참고 라벨일 뿐, **오늘 타점은 현재 지지/투매 구조**  
- 파싱 오류 단가(예: `25`) → 무시  
- TV 채널 색(민트/노랑/빨강) 자체는 자동 추출 어려움 → 스윙저·플러시저로 근사

## 데이터 더 주면 좋은 것

1. 매수/매도 숫자가 있는 복기  
2. 채널·하이라이트 레벨이 숫자로 적힌 글  
3. 지수 시나리오(지지/최악 레벨) 글
