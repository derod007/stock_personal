# 유형 1: 계좌 한도를 적용한 후속 탐색

최근 기간에서 유형 1이 대조군보다 나았다. 이전 기간은 저장 봉 문제로 중단되어 두 기간 일관성은 미확정이다. 운영 채택·독립 검증을 뜻하지 않는다.

## 결과

초기자금 각각 100,000,000원. 두 비교군의 현금·포지션은 독립이다. 최근 기간은 2025-10-10~2026-10-08의 244거래일이다.

| 최근 기간 | 전체 유형 | 유형 1 |
|---|---:|---:|
| 종료 상태 | 완주 | 완주 |
| 최종 현금·평가액 | 112,626,686.63원 | 140,561,615.81원 |
| 계좌 순수익률 | +12.63% | +40.56% |
| 종가 평가액 최대 낙폭 | 32.59% | 12.73% |
| 체결·청산 거래 | 255 | 183 |
| 손절 / 목표 / 만기 청산 | 179 / 69 / 7 | 118 / 57 / 8 |
| 보유 한도 차단 | 2,319 | 797 |
| 현금·위험·섹터 한도 차단 | 73 | 30 |
| 최대 동시 보유 | 4 | 4 |
| 시가 주문 후 최대 투자 비중 | 62.17% | 62.43% |

유형 1의 계좌 수익률 차이는 +27.93%p, 최대 낙폭 차이는 −19.86%p다. 이는 5% 손절·15% 목표를 바꿔서 얻은 결과가 아니다. 동일 진입·비용·계좌 한도 아래 후보 집합만 다르게 적용한 결과다. 손절 빈도는 여전히 높다.

## 이전 기간: 완주 실패, 연간 수익률 미표시

| 비교군 | 마지막 정상 평가일 | 중단일 | 체결 / 청산 | 중단 근거 |
|---|---|---|---:|---|
| 전체 유형 | 2024-10-11 | 2024-10-14 | 4 / 0 | 당일 진입 의향 004870.KS·050110.KQ의 유효 봉 없음 |
| 유형 1 | 2025-09-18 | 2025-09-19 | 96 / 93 | 보유 032640.KS·033780.KS·086280.KS의 해당 날짜 봉 없음 |

전체 유형의 두 원시 봉은 존재하지만 종가가 고가보다 커서 기존 `valid_bar()`를 통과하지 못한다(004870: 종가 4180 > 고가 4045; 050110: 종가 23565.2266 > 고가 23242.4160). 왜 이런 값이 저장됐는지는 미확정이다. 현재 모형은 당일 후보가 한도로 차단될 상황이라도 유효 봉 누락을 숨기지 않고 중단한다.

유형 1의 세 종목은 해당 날짜 행 자체가 없다. 원인을 추정하지 않았고 봉을 채우거나 계좌를 이어 실행하지 않았다. 중단 시점 평가액을 연간 수익으로 제시하지 않는다. 서로 다른 기간까지 실행된 두 계좌의 손익도 비교하지 않는다.

## 입력 일치와 검증

- 사용자 업로드 중심값 6×120을 그대로 읽었다. 학습 호출 없음.
- 후보 파일 SHA256 차이는 Windows CRLF/LF 차이임을 확인했다. 현재 파일을 CRLF로 표현한 해시는 기존 보고서의 이전 `f3759695...` / 최근 `94060187...`와 각각 일치했다. 파일 자체를 변경하지 않았다.
- 이미 풀려 있던 봉 1,234개 / 926개를 업로드 ZIP과 바이트 SHA256으로 대조했다. 차이 0개. TOP100 종목 중 파일 자체 미존재는 14개 / 7개이며, 신호일에 알 수 있는 자료 부족으로 제외된다.
- 기존과 같이 미래창이 완전한 표본으로만 따로 점검하면 3,146개 / 2,643개이고, 유형 1은 896개 / 1,010개, 거래 평균 +0.52204495% / +1.05662531%로 PR #106과 일치한다. 이 점검용 집합을 계좌 후보 필터로 쓰지 않았다.
- 실제 연구 포트폴리오는 미래봉 누락을 사전에 필터링하지 않아 총 분류 가능 신호가 3,294개 / 2,647개다. 기존 차트 표본과 완전히 같은 분모라고 주장하지 않는다.
- 모든 체결 538건(4+96+255+183)의 주문 직전 현금, 종목·섹터·개별위험·총위험·보유 한도를 점검했다. 위반 0. 청산 손익·미청산 매입액과 잔여 현금의 대사도 일치했다.
- 신규 합성 테스트 9개와 기존 v2/v3/v4 테스트 총 39개 통과. 목표·손절·갭·같은 봉·만기 청산의 거래 손익은 기존 v2 모형과 대조했다.

## 해석과 한계

이번 결과로 유형 1을 단순한 관찰 대상으로만 버릴 이유는 줄었다. **최근 기간의 계좌 제약 실험에서는 후속 모의 관찰 후보로 남길 근거가 있다.** 두 기간 모두 검증됐다고 말할 수는 없다.

시가에 수량을 계산하는 연구 모형이며 운영의 전일 예약 지정가 주문을 재현한 것이 아니다. 업종표는 현재 분류의 과거 적용이고, 가격 조정 여부는 미검증이다. 고정 중심은 이전 기간 전체에서 만들어졌고 유형 1은 이미 결과를 본 뒤 선택했다. 최근 기간도 이미 사용한 구간이다. 높은 수익률을 향후 기대 수익률로 사용하지 않는다.

운영 소스·설정·예약·기존 계좌·원본 봉은 변경하지 않았다. 이번 실행은 서로 분리된 신규 연구 출력만 만들었다. 병합·운영 반영은 하지 않는다.
