## 실행

실행: `php bin/paper_stop_research.php --account=paper-kr`

동결 입력: `--source-dir=docs/paper-kr-5d-source` 추가. 결과는 기본 PAPER_STATE_DIR의 `stop-research/paper-kr/`에 저장한다. `--output-dir`로 변경 가능. 원본 rr-audit/followup 하위에는 쓰지 않는다.
화면: `paper_rr.php?account=paper-kr&mode=forward&stop_research=1`.

## 사전 고정한 구간 정의

1. 판정 시각까지 완료된 원본 봉만 사용한다. 최근 10봉에서 좌측 2봉과 우측 2봉의 고가보다 **엄격하게 높은** 마지막 고점을 찾는다. 우측 2봉이 판정일까지 존재해야 하므로 최근 2봉은 고점 후보가 될 수 없다. 같은 고가의 평탄한 구간은 추정하지 않는다.
2. 해당 고점 다음 봉부터 판정봉까지를 후보 구간으로 삼는다. 판정봉 이전에 직전 종가보다 낮은 종가가 적어도 1번 있어야 한다. 고점 대비 구간 최저가 조정 폭이 0.5 ATR 이상이어야 한다.
3. 마지막 고점에서 조건이 부족하면 오래된 다른 고점을 골라 통과시키지 않는다. 구간이 없으면 별도 상태로 남기고 양쪽 성과 비교에서 제외한다.
4. 대안 손절은 구간 최저가 - 판정 시점 0.2 ATR. 기존 손절도 같은 ATR과 가격 절삭 규칙을 사용한다.

이는 최근 눌림의 유일한 정답이나 저자의 매매 규칙 복원이 아니라, 결과를 보기 전에 고정한 연구 가설이다. 임계값/봉 수를 이번 수익률에 맞춰 선택하지 않는다.

## 통제와 그룹

- 원본 전체 해시와 참조 evidence 해시를 먼저 확인한다. 가격·종목·관측 시각·원본 재현 차단을 유지한다.
- 선택된 눌림 패턴의 raw ready/rejected_rr를 확인 완료 그룹으로 선택한다. 독립 위험/품질 차단은 유지한다. 재지지의 다른 손절 공식은 섞지 않는다.
- 앞선 단일 조건 제거 연구 13건은 별도 그룹이다. 같은 조건 제거를 두 손절에 동일 적용한다. 확인 완료 사례와 합산하지 않는다.
- 진입가, 목표가, 신호 시점, 3봉 주문 유효기간, 비용, 20봉 보유·체결 규칙을 고정한다. 확인 완료 그룹은 계산한 기존 가격이 저장된 가격과 일치해야 한다.
- 손절 변경에 따른 RR 및 상위 추세 RR 조건은 동일 공식으로 다시 판정한다. 목표가가 진입가 이하인 경우 손절 변경으로 통과시키지 않는다.
- 비교 가능한 동일 사례에 대해 각 방식의 통과/체결/청산/손절 수와 순손익을 기록한다. 서로 다른 청산 표본의 평균 차이를 개선 효과로 사용하지 않는다. 양쪽 모두 청산한 사례의 차이는 별도 집계한다.
- 좁은 손절 때문에 진입 전 취소나 체결가가 달라질 수 있다. '더 이른 손절'은 양쪽 체결 시각·가격이 동일할 때만 집계하며, 이것만으로 잡음 손절임을 단정하지 않는다.
- 운영 전략/계좌/원본 증거 변경 없음. 연구 CLI를 다시 실행하면 저장된 후속 evidence의 최신 완료봉 기준으로 비교한다. 일반 followup 수집이 먼저 필요하며 연구 자체는 네트워크 조회하지 않는다.
