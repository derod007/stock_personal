# 20일 고가 돌파 표시

종목 분석 `index.php?symbol=005930.KS`에 표시한다. 유형1과 무관하며 점수·추천·주문 규칙을 바꾸지 않는다. 추가 스캔 필터는 아니다.

- 해당 봉을 제외한 직전20개 완료 일봉의 최고 고가가 기준선이다.
- 종가(진행봉은 제공가격) / 기준선 - 1을 %로 표시한다. 별도 현재가 API와 섞지 않는다.
- 완료봉 종가 > 기준선: 종가 돌파 확인. 같은 가격은 돌파가 아니다.
- 최근20봉 중 마지막 종가 돌파 당시 기준선 아래: 돌파 후 기준선 아래. 진행봉이면 미확정을 명시한다.
- 고가 > 기준선: 진행봉이면 장중 돌파·종가 미확정, 완료봉이면 장중 돌파 후 종가 미유지.
- 나머지는 돌파 전이다. 접근 거리 임계값은 임의로 정하지 않았다.

최근40봉 차트의 노란선은 각 날짜 직전20봉 최고가다. 이전 돌파 당시 고정선은 별도 숫자로 표시한다. 무효·합성·미완료 과거봉을 제거해 21번째 이후 봉으로 대신 채우지 않는다. 거래소 달력과 대조하지 않으므로 공급자에서 통째로 누락된 거래일은 검출하지 못한다.

일봉 선택은 이 프로젝트의 구현 선택이며 원문 작성자의 정확한 수식을 복원했다는 뜻이 아니다. 기존 Yahoo/Naver 일봉 조회 캐시를 사용하며 수정주가 검증이나 거래소 공식 인증을 추가하지 않는다. 마지막 봉 날짜와 완료 상태를 명시한다. 실제 실시간 시세 수신은 별도 운영 확인 대상이다.
