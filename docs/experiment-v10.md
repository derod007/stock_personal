# 기준·후보 모의 계좌 비교

기존 계좌에 쌓인 추천/품질/가격을 공통 입력으로 받아 새 기준 계좌와 후보 계좌를 각각 계산합니다. 기존 자산과 거래를 복제하지 않으며 동일 초기자금으로 비교 실행일부터 시작합니다. 원본 계좌의 확정 추천을 사용하므로 이번 버전은 주문 유효기간 등 주문 계획 변경을 위한 기반입니다. 신규 진입 신호 생성기를 비교하는 기능은 별도 확장이 필요합니다.

## 기본 시작 및 예약

기존 daily 명령 대신 아래 래퍼를 예약하면 기존 계좌 갱신 뒤 비교를 실행합니다. 기존 예약과 중복 등록할 필요는 없습니다. 자동으로 PC의 예약 작업을 수정하지 않습니다.

```
python bin/paper_compare_daily.py --config=config/paper-us.json --experiment=us-identity
python bin/paper_compare_daily.py --config=config/paper-kr.json --experiment=kr-identity
```

웹 `paper_compare.php`에서 실험 ID로 조회합니다. 기존 Python/PHP PATH 및 PAPER_STATE_DIR 설정을 그대로 사용합니다. 로그는 experiment-runs/<ID>에 시작/종료/실패 단계를 남깁니다. 원본 수집 실패/계좌 중단이면 비교 단계로 진행하지 않습니다.

기본은 동일 전략 두 개를 독립 실행해 전체 포트폴리오 상태가 같은지 확인하는 시험입니다. 수익률이 같다는 것을 수익성 입증으로 해석하지 않습니다. 초기에 거래가 없으면 동일성 시험도 주문/체결 경로를 충분히 검증하지 못한 상태입니다.

## 실험 격리와 시간

experiments/<ID>-forward.json 또는 -replay.json 하나에 두 계좌 상태와 이벤트를 함께 원자적으로 저장합니다. 실패하면 두 계좌 모두 이전 상태를 유지합니다. 원본 계좌 파일은 읽기만 합니다. 공유 입력에는 추천 이벤트 해시, 실제 사용한 snapshot과 일봉을 기록합니다. 계좌 상태 해시와 이벤트 연결 검증을 유지합니다.

forward 최초 실행은 원본의 최신 세션만 사용하며 주문 기록 시각은 비교 실제 실행 시각입니다. 이전 세션은 과거 수익으로 소급 적용하지 않습니다. 이후 놓친 기간은 catchup으로 신규 주문을 만들지 않고 기존 주문만 진행합니다. 기존 원본 주문과 비교 계좌 주문은 실제 기록 시각이 달라 체결도 다를 수 있습니다. 비교하는 두 계좌끼리는 같은 시각/입력/비용/자금 조건을 사용합니다.

과거 재현은 이미 별도로 생성된 replay 원본에서:

```
php bin/paper_compare.php --source=paper-us --experiment=us-replay --mode=replay
```

forward 원본을 replay로 변환하지 않습니다. source의 과거 기록 축소/변조, 설정/전략/실험 코드 변경은 동일 ID에서 거부합니다. 기존 src 코드는 변경하지 않으므로 기존 계좌의 전략 버전을 유지합니다. 중단된 원본/비교 계좌는 검토 전 추가 실행을 거부합니다.

## 단일 변경 후보

비교 엔진 시험 및 향후 검토를 위해 `--candidate-ttl=1`~`5` 옵션을 제공합니다. 후보의 order_valid_bars만 변경합니다. 기본값에는 후보 변경이 없습니다. 새 조건은 반드시 새 실험 ID로 시작합니다. 예:

```
python bin/paper_compare_daily.py --config=config/paper-us.json --experiment=us-ttl2 --candidate-ttl=2
```

이는 TTL 2가 더 낫다는 추천이 아닙니다. 기준과 후보는 서로 다른 보유 자금 경로를 허용하되 초기 자금과 위험 한도는 같습니다. 조건은 코드/설정으로 고정되며 자동 전략 승격은 없습니다.

## 결과와 보류

평가자산/순손익/실현손익/수익률/완료 거래/최대 종가 낙폭/평균 자금 사용률을 표시합니다. 자금 사용률=(보유 평가액+미체결 예약금)/평가자산의 세션별 평균입니다. 원화와 달러, replay와 forward를 합치지 않습니다.

표본 30건 미만, 품질 차단, 기간 불일치, 계좌 중단, 동일전략 불일치에 보류 사유를 표시합니다. 30건 이상은 통계적 입증 기준이 아닙니다. 같은 전략 시험은 거래 수와 관계없이 수익성 판단 대상이 아닙니다. source 갱신과 비교 갱신이 다르면 화면에 표시합니다. 웹 조회는 수집/매매를 실행하지 않습니다.

## 검증

기존 회귀 검사 + tests/v10.php: 실제 체결이 있는 동일 전략 상태 일치, 재실행 무변경, source 무변경, forward 시작일/기록 시각, 정의 변경 거부, source 변경/중단 차단, 단일 후보 변경, 원자적 롤백.
