# 엔벨로프 눌림 관찰 연구 v1

노라무 「기법이나 뿌려야겠당」(2026-06-29, 10016561104)의 엔벨로프 20/9를 관찰 가설로 기록한다. 본문·작성자 댓글의 정성 설명을 매수 규칙으로 확정하지 않는다. 운영 엔진·점수·진입/손절/목표·기존 목표가 연구는 변경하지 않는다.

## 실행과 화면

- 기존 20:20 KR 예약 작업의 마지막 독립 단계 `envelope_research`. 추천 0건, 스캔 실패, 다른 후속 작업 실패에도 실행한다. 고정 종목/US 작업에는 붙이지 않는다.
- 수동: `php bin/paper_envelope_research.php --account=paper-kr`
- 동결 과거 자료: `php bin/paper_envelope_research.php --account=paper-kr --source-dir=docs/paper-kr-5d-source --saved-evidence`
- `--saved-evidence`는 수집하지 않는다. 정확히 연결되는 후속 증거 또는 자체 보존 가격으로만 계산한다. `--prices=DIR`, `--as-of=ISO8601`로 오프라인 검증도 가능하다. 이전 기준 시각으로 현재 장부를 덮어쓰지 않는다.
- 탈락 로그 → **엔벨로프 눌림 관찰 연구 보기**: `paper_rr.php?account=paper-kr&mode=forward&envelope_research=1`
- 저장: `PAPER_STATE_DIR/envelope-research/paper-kr/latest.json`, 실행 이력 JSON 및 `evidence/` 해시 파일. 화면 GET은 읽기 전용이다.
- 상태 `saved`는 저장 성공이지 새 거래일 봉 확보를 보장하지 않는다. 행의 **평가 시각과 실제 완료봉 날짜**를 따로 확인한다.

## 연구 정의 (작성자의 확정 수치와 구별)

| 항목 | v1 정의 |
|---|---|
| 밴드 | 당시 완료 일봉 종가 SMA20의 91% / 109%. SMA 방식·종가 기준·중심선=SMA20은 연구 가정 |
| 정배열 | SMA20 > SMA60 > SMA240. 이평 기울기는 필수로 두지 않음 |
| 이격 | `(SMA60 / SMA240 - 1) * 100`. 과다 임계값 없음 |
| 데이터 | 최소 240 완료봉. 부족하면 평가 불가, 추가로 현재 가격을 받아 과거 값을 보충하지 않음 |
| 하단 접촉 | `low <= lower <= high`. 봉 전체가 하단 아래면 별도 상태 |
| 종가 복귀 | 하단 접촉 봉의 `close > lower`. 같으면 복귀 아님 |
| 중심 지지 관찰 | 중심 접촉 봉의 `close > SMA20`. 강한 상승 확인·매수 신호는 아님 |
| 하단 구간 | `low <= lower`로 시작, 한 봉 전체가 하단 위(`low > lower`)일 때 종료. 연속 체류를 여러 접촉으로 세지 않음 |
| 재진입 | 위의 종료 후 새 하단 구간. 반등 크기를 확인하는 정의는 아님. 시작 간격과 중간 이탈 봉 수 기록 |
| 단기간 | 5·10·20봉 안의 구간 시작 횟수를 모두 기록. 하나를 최적화하거나 2회만으로 차단하지 않음 |
| 저점 상향 | 좌우 각 2봉보다 엄격히 낮은 확정 저점 두 개 비교. 마지막 두 봉은 저점 확정 불가 |
| 박스 대용 조건 | 최근 20봉 안에서 이전 20봉 최고가를 종가로 돌파한 가장 최근 봉을 찾고, 현재 저가 접촉·종가 유지 여부 기록 |
| 첫 박스 | 원문 정의 미정으로 `null`. 위 대용 조건을 원문 첫 박스와 동일시하지 않음 |

최초 접촉은 **저장 범위 첫 구간**일 뿐 종목 역사상 최초가 아니다. 관찰 시작 이전에 진행 중이던 구간일 수 있다. 당일 종가가 포함된 밴드로 당일 저가 접촉을 판정하므로 장중 사전 주문 신호로 사용할 수 없다.

## 범위와 원본 고정

13건만 대상으로 하지 않고 `observed_scan_only` 감사 로그의 모든 평가 종목을 처리한다. 같은 종목·같은 판정 완료봉은 첫 저장 기록 하나만 보존한다. 원본 미평가/HTTP 오류는 별도 건수, 240봉 미만은 등록 행의 평가 불가 상태로 표시한다. 과거 로그에는 ETF 제외 전 기록과 전략·종목군 버전 미기록 자료가 포함될 수 있다. 과거를 현재 종목군 성과로 해석하지 않는다.

원본 일봉·해시·기존 판정·패턴·전략 버전·연구 계산 버전을 등록 시 고정한다. 원본 변경은 오류로 남기고 원래 기록을 보존한다. 현재 실행 코드를 과거 전략 버전으로 채우지 않는다. TOP100 이탈이나 원본 로그 삭제 후에도 등록 원본과 자체 가격 증거가 남는다. 실행 정의가 달라지면 기존 진행 결과를 조용히 재계산하지 않고 갱신 오류로 보류한다.

## 후속 비교

판정 다음 완료봉부터 1·3·5·10·20봉 종가 변화, 최대 상승/하락폭을 계산한다. 실제 매매·손절·목표·수수료 가정은 없다. 실제 체결 수익률이나 필터의 인과 효과가 아니다. 20봉 완료 결과는 고정한다. 실패 시 이전 성공 결과와 기준 시각을 보존한다.

- 일별 상태 그룹은 연속 체류까지 포함한다.
- 첫 구간/재진입, 정배열, 저점 상향, 돌파·재지지 대용 조건 및 조합, 5·10·20봉 반복 비교는 **새 하단 접촉 구간 시작 봉만** 집계한다.
- 연구 계산 버전·원본 전략 버전·선택 패턴·최종 판정으로 분리한다. 미기록 버전은 관찰용.
- 그룹은 중복되므로 합산하지 않는다. 동일 종목의 여러 날짜도 독립 표본은 아니다. 완성 표본 수를 반드시 같이 본다.
- 추적 가격의 종목 일치·과거 OHLC·품질 검증은 기존 엄격한 후속 검증을 재사용한다. 조정주가/기업행사 검증의 기존 한계도 유지된다.
- 신규 일봉 조회는 기존 일반 후속의 가격 캐시를 재사용하고, 활성 종목당 한 번 조회한다. 현재 비교 연구와 성과를 합치지 않는다.

다음 판단은 별도 기간에 충분한 완료 결과를 모은 뒤 한다. 이 구현만으로 엔벨로프를 필수 매수 조건이나 위험 차단으로 승격하지 않는다.
