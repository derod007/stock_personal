# 가격 후보·복수 패턴·큰 추세 v2

## 바뀐 동작
- new_entry.available / candidate_available는 가격 후보 존재 여부다.
- new_entry.order_ready / trade_plan.ready만 확인된 주문 가능 상태다. buy_now는 항상 false다.
- 후보가 보여도 스캐너의 추천 여부와 백테스트 주문은 order_ready/ready만 사용한다.
- 진입 구간 하단·중앙·상단에서 같은 손절·목표를 사용한 비용 전 손익비를 각각 표시한다.
- 확인 지정가는 관심 구간과 별도다. 확인 봉 종가로 다음 3봉 지정가를 검토한다.
- 점수는 기존 특징 점수로 유지하며, 높은 점수가 가격 후보나 주문을 강제로 만들지 않는다.

## 후보와 패턴
기존 돌파 재지지는 유지한다. 신규 상승 추세 눌림은 MA20 상승, 최근20봉 고저가 이전20봉보다 높음,
MA20 부근 접근, 최근3봉 거래량이 앞20봉의 85% 미만, 이후 양봉의 직전 고가 회복과 거래량 회복을 확인한다.
관심 구간은 MA20 ±0.4ATR, 손절은 최근10봉 최저가 -0.2ATR, 목표는 직전20봉 고가다.
돌파 재지지 확정 신호를 우선하고, 그 외 상승 눌림 후보/신호를 선택한다.
두 패턴에 해당하지 않더라도 기존 구조 중간값·근처 가로 지지를 중심으로 ±0.4ATR(최대±4%) 후보를 계산한다.
구조가 유지되고 손절 < 후보 하단 <= 상단 < 목표인 경우만 제공한다. 목표를 늘려 손익비를 맞추지 않는다.
구간 손익비가 부족해도 타당한 후보는 표시한다. 확인 지정가의 손익비가 1.5 미만이면 주문하지 않는다.

## 주봉·일봉
완료 일봉의 거래소 현지 주차로 주봉을 집계한다. 현재 주의 월~목 데이터는 주봉 추세에 포함하지 않는다.
일봉은 20봉 평균과 5봉 전 평균, 주봉은 20주 평균과 3주 전 평균을 비교한다.
종가와 평균 기울기 방향으로 상승/하락/횡보를 구분한다. 주봉 23개가 없으면 자료 부족으로 표시한다.
일봉 하락은 신규 진입 보류. 주봉 하락은 일봉 상승 및 확인 손익비 2 이상이 추가로 필요하다.
주봉 하락만으로 후보를 숨기지 않는다. 오래된 데이터·차단 종목은 후보를 숨긴다.
이는 고정 연구 가설이며 작성자가 직접 제시한 임계값이나 수익성 검증 결과가 아니다.

## 비교 재생
php tests/v2.php
php bin/compare_strategies.php --file=data/ohlcv/example.json --symbol=MU

동일한 과거 데이터에서 v1 / v2_without_context / v2를 비교한다.
후보 표시일 수와 실제 청산 매매 수익률을 분리한다. 70%/30% 기간 분리, 단일 대기 주문/보유, 비용 가정은 동일하다.
기존 v1의 클래스는 LegacyChartPlanEngine으로 보존하여 비교할 때만 쓴다.
bin/fetch_comparison_data.py는 MU/AAPL/삼성전자 일봉을 수집하고 원본 출처·시각·정규화 파일 해시를 기록한다.
미국 Yahoo 실패 시 Stooq로 대체하지만, 같은 비교 안에서는 모든 버전이 동일한 데이터를 사용한다.
한국 데이터 실패 시 미국 데이터로 대체하지 않는다. 공급자 오류는 sources.json에 명시한다.
GitHub Actions의 comparison-data-and-results 아티팩트에 데이터와 보고서가 저장된다.
표본이 적거나 손실이 늘어도 임계값을 사후 조정하지 않는다. 수익률 평균은 계좌 수익률이 아니다.
주식 분할·수정주가·거래정지·호가단위·부분 체결 관련 기존 한계는 남아 있다.
