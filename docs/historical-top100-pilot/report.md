# 2025년 10월 거래대금 TOP100 복원 1개월 파일럿

계좌 재현·수익률·운영 수정은 하지 않았습니다. 종가×거래량으로 거래대금을 대체하지 않았습니다.

## 결론

**일부 제한.** 2025년 10월 후보 18거래일 모두 KOSPI·KOSDAQ 주권 일별매매정보를 받아, 양쪽이 검증된 날만 TOP100을 저장했습니다. 합집합 고유 종목은 **305**개입니다. 종가×거래량으로 대체하지 않았습니다.

운영 스캐너와 **같은 TOP100이라고 보지 않습니다.** 운영은 20:20 실시간 다음 `accTradePrice`(ETF를 받은 뒤 이름으로 제외)이고, 이번 복원은 KRX Open API **주권** `ACC_TRDVAL`입니다. 정규장/시간외·KRX/NXT 합산은 명세서 없이 단정하지 않습니다.

## 상장·상품 구분

- 일자별 Open API 행 = 그 날 시세가 있는 종목. 현재 상장 목록을 과거에 적용하지 않는 방식입니다.  
- 주식 API는 **주권**만 준다고 안내되어 있습니다. ETF/ETN은 증권상품 API.  
- 스팩은 주권에 남을 수 있어 이름 규칙을 그대로 적용합니다.  
- 이번 원본은 주권 API라 ETF/ETN 행이 없습니다. 이름 제외는 스팩만 걸렸습니다(일 69–76건, 18일 합 1283).  
- TOP100 합집합 305종목에서 같은 코드의 이름 변경은 없었습니다. 상장폐지 공시 장부와는 따로 대조하지 않았습니다.  
- 대금 0인 행은 순위에 넣지 않았습니다(일 96–105건). 수집 실패가 아닙니다.

## 재현

```
python docs/research/historical-amount-top100-pilot.py --probe
python -m unittest tests.test_historical_amount_top100_pilot
php tests/amount_exclude.php
```

인증키는 Git 밖 `data/raw/research/historical-amount-top100-202510/.krx-auth-key`에만 둡니다. 도구는 환경 변수 또는 이 파일을 읽고, 키 값은 로그·Git에 쓰지 않습니다.

Windows PowerShell. 키가 gitignore 파일에 있으면 환경 변수 없이 `--collect`만 실행해도 됩니다.

```powershell
python docs\research\historical-amount-top100-pilot.py --collect
```

환경 변수로 넣을 때는 기록에 남지 않게:

```powershell
$env:KRX_AUTH_KEY = Read-Host 'KRX AUTH KEY'
python docs\research\historical-amount-top100-pilot.py --collect
Remove-Item Env:KRX_AUTH_KEY
```

원본 위치: `data/raw/research/historical-amount-top100-202510/` (`.gitignore`의 `/data/raw/`). 운영 캐시 `data/raw/cache`는 건드리지 않습니다.
