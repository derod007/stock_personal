# 추세 이탈 후 회복 — 독립 추천 패턴 v1

근거 자료: `docs/fmkorea-10423117635.html`, `docs/fmkorea-10423117635-chart.png`.
원문의 저점 이탈→회복→저항 돌파→다음 저점 상향을 구현한 **프로그램의 명시적 가설**이다. 글쓴이의 모든 매매 규칙을 재현한 것이 아니다. 손그림 추세선/매물대를 임의의 숫자로 읽지 않는다.

## 다른 패턴과의 관계

`breakout_retest`, `trend_pullback`, `trend_recovery`를 각각 계산한다. 모든 패턴의 동시 충족이나 조건 몇 개의 단순 합계로 추천하지 않는다. 유효한 기존 추천이 있으면 기존 우선순위를 유지한다. 기존 추천이 없거나 기존 추세 조건에 막혔을 때, 회복형의 조건을 충족하면 독립적으로 추천할 수 있다. 구조 점수에 임의의 가산점은 추가하지 않는다.

회복형은 일봉 하락 판정만으로 배제하지 않는다. 아래 구조 확인이 그 역할을 맡는다. 주봉 하락이면 손익비 2 이상이 필요하다(그 외에는 1.5). 주봉 자료 부족은 상승 확인을 뜻하지 않는다. 급등 후 급락, 고점 붕괴, 매수 금지, 오래된 자료 등 기존 공통 차단은 그대로 적용한다.

## v1의 고정 정의

1. 완료 일봉 60개부터 판정한다. 좌우 각 2봉보다 엄격하게 낮거나 높은 봉만 피벗으로 인정한다. 같은 봉이 저점·고점 둘 다이면 순서를 추정하지 않는다. 피벗 날짜와 **확정된 날짜**를 모두 보존한다.
2. 최근 확정된 두 저점이 높아졌던 구조에서, 직전 저점을 종가로 처음 깨고 종가가 MA20 아래이면 시작한다. **깨진 직전 저점 가격을 저항 R로 고정**한다. 원문의 매물대나 손그림 선을 그대로 계산한 것은 아니다.
3. 이탈 다음에 R 아래의 낮은 피벗 L0가 확정돼야 한다. 회복 전 추가 하락으로 더 낮은 피벗이 확정되면 L0를 갱신한다. 그 후 종가가 R을 엄격하게 넘으면 돌파로 기록하고 L0를 고정한다. 고가 접촉과 종가 동률은 돌파가 아니다.
4. **돌파 이후에 생긴** 눌림 저점 L2가 좌우 2봉으로 확정되고 L0보다 엄격하게 높아야 한다. 돌파 이전의 높은 저점은 이 추천 경로를 완성하지 않는다.
5. L2 확정 이후(확정일 포함), 종가가 직전봉 고가와 R을 모두 넘고 양봉이어야 진입 확인이다. 확인 전 L2를 저가로 다시 건드리면 새 피벗 확정을 기다린다. 회복 후 종가가 L0 아래면 무효다.
6. 진입은 확인 종가, 손절은 확정 L2, 목표는 진입 위의 **당시 이미 확정된 가장 가까운 미돌파 피벗 고점**이다. 이후 종가가 한 번이라도 넘은 고점은 목표에서 제외한다. 상단 후보가 없으면 목표를 만들어 추천하지 않는다. 정수 절삭 후 `손절 < 진입 < 목표`와 손익비를 검사한다. 비용 전 손익비이며 표시 반올림으로 통과시키지 않는다.
7. 이탈 후 60봉 안에 패턴이 완성돼야 하고, L2 이후 10봉 안에 재상승이 확인돼야 한다. 같은 구조에서 확인 신호는 한 번만 낸다. 확인 다음 3거래봉 지정가, 기존 체결·비용·보유기간 규칙을 사용한다.

**손절 구분:** L0 종가 이탈은 진입 전 구조 무효화 조건이다. 거래 진입 후의 L2 손절은 기존 모형과 동일한 **장중 저가 접촉 손절**이며 종가 손절로 바꾸지 않았다. 일봉 체결 시각은 실제 체결 시각을 증명하지 않는다.

## 표시와 이력

종목 상세·탈락 감사·수동 관찰의 패턴별 표에 세 번째 패턴이 표시된다. 필수 조건의 통과/미충족/미평가와 R·L0·L2·목표의 가격/확정 시각을 저장한다. 선택된 최종 상태와 패턴 자체 상태를 구분한다. 과거 기록에 이 패턴이 없으면 당시 기록 없음으로 표시한다. 장중 점수와 마지막 완료봉 추천 근거를 섞지 않으며, 수동 장중은 기존 잠정 관찰 규칙을 유지한다.

## 적용 및 버전 보호

실제 추천 전략 변경이므로 `src/TrendRecovery.php`를 전략 지문 대상에 추가한다. 기존 모의 계좌가 이전 전략 지문을 고정했다면 새 전략으로 자동 재개/이관되지 않는다. **새 전략용 별도 계좌 ID와 설정을 준비해야 하며 기존 장부를 삭제하거나 버전 값을 직접 덮어쓰면 안 된다.** 이 PR은 계좌·예약 설정을 자동 변경하지 않는다.

과거 원본·고정 진입/손절/목표·종료 손익을 수정하지 않는다. 새 코드로 과거 판정을 다시 계산해 다르면 기존 격리 규칙을 따른다. 실행 지문이 달라진 기존 연구 거래도 자동 재산정하지 않는다. 과거 연구 회귀는 테스트 전용 동결 엔진으로 검증하고, 실제 엔진의 과거 불일치 격리 검사는 별도로 실행한다.

검증: `php tests/trend_recovery.php` 및 기존 PHP/버전/장중/후속/UI CI. 이것은 구현 검증이며 수익성·실제 매수 성공을 입증하는 백테스트가 아니다.
