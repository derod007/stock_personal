# 지수 60거래일 평균 탐색 결과

조건은 계산 전에 커밋한 `protocol.md` 그대로다. 1차와 2차는 탐색이며 독립 검증이 아니다. 60일은 연구 가정이다. 주 지표는 보존된 20거래일 차이(신호 종가 변화율에서 같은 날 비교 종목 중앙값을 뺀 값)의 중앙값이다. 단위는 %p다. 차이가 0보다 큰 비율은 매매 승률이 아니다.

기준 집합 A는 지수 판정이 통과 또는 비통과이고 20거래일 차이가 있는 신호다. B는 그 안의 지수 통과만이다. 차이는 B 중앙값에서 A 중앙값을 뺀 값이다.

## 손익비 조건 통과

1차, 신호 98. 지수 통과 81, 비통과 17, 미확정 0. 20거래일은 완료 95, 미확정 3.
- A: 95신호, 79종목, 확인일 60일. 중앙값 +0.282%p, 양수 49/95 (51.58%).
- B: 79신호, 66종목, 확인일 51일. 중앙값 +0.282%p, 양수 41/79 (51.90%). 유지 79/95 (83.16%).
- 차이 0%p.

2차, 신호 107. 지수 통과 53, 비통과 28, 미확정 26. 미확정 26은 모두 2025-10-03·06·07을 지나는 창이다. 20거래일은 완료 104, 미확정 3.
- A: 78신호, 68종목, 확인일 46일. 중앙값 -1.914%p, 양수 36/78 (46.15%).
- B: 50신호, 45종목, 확인일 31일. 중앙값 -0.178%p, 양수 25/50 (50.00%). 유지 50/78 (64.10%).
- 차이 +1.736%p.

1차는 차이가 0이라 개선이 아니고, 2차는 +1.736%p 개선이다. 두 기간에서 모두 개선되어야 한다는 사전 기준을 충족하지 못했다. 이 가설은 채택 근거가 부족하다. 다른 평균 기간이나 임계값은 찾지 않았다. 추천 기능에 넣지 않는다.

## 보조

결론에 쓰지 않는다. 더 좋아 보여도 규칙으로 채택하지 않는다.

1차 손익비 부족은 차이 +0.037%p, 저항 미확정은 +0.753%p다. 2차 손익비 부족은 -0.914%p, 저항 미확정은 +0.253%p다. 2차 미확정은 창이 세 미분류 평일을 지나는 경우뿐이고, 손익비 부족 55, 저항 미확정 23이다.

## 입력

보존 gzip·JSON 해시, 지수 정규화 해시, 원응답 묶음 해시가 기록과 같았다. 어긋나면 중단하도록 되어 있고 이번 실행은 통과했다. 연구 달력과 코드 해시는 `result.json`의 `inputs`에 있다. 개별주 일봉은 읽지 않았다. 지수 종가 수준은 결과에 넣지 않았다. 운영 파일은 바꾸지 않았다. 신호별 판정을 다시 합산하면 같은 통계가 나온다.

### 병합 전 검토

60거래일 창 내부의 임의 날짜에 달력 공백·충돌이 있어도 미확정이 되도록 검사 범위를 보완했다. 두 회귀 사례를 추가해 테스트 32개가 통과했다. 보존 입력 해시와 원응답 묶음 해시를 확인하고 지수 판정을 다시 계산한 결과, 1차 294건·2차 399건의 신호별 판정과 집계가 모두 원래 결과와 같았다. 개별주 일봉은 읽지 않았다. `result.json`은 덮어쓰지 않았으며 그 안의 코드 해시는 최초 계산 당시 코드의 해시다.
