# 돌파 전 높은 저점형 — 독립 관찰 v1

근거: `docs/fmkorea-10426879241/index.html`의 크루드오일 차트 6·7. 원문은 선물 60분봉 설명이다. 아래는 국내 완료 **일봉에 적용하는 프로그램의 연구 가설**이며 원문 거래의 복제가 아니다.

기존 회복형은 돌파 **후** 높은 저점을 기다린다. 이 연구는 높은 저점이 돌파 **전**에 확정된 경로를 별도로 관찰한다. 추천 패턴 목록·점수·공통 위험 차단·계좌 주문에는 연결하지 않는다. 3:7 분할매수, SQQQ·숏·선물 거래, 목표가·손절가 주문도 추가하지 않는다.

## 고정 정의

1. 저장된 거래대금 스캔의 평가 완료 종목 전체를 읽는다. 원본 해시·종목·품질을 검증하고 관측 시각까지의 완료 일봉만 사용한다. 최근 최대 180봉을 검사하며 최소 60봉이 필요하다. 검사 구간의 잘못된 봉은 통째로 제외해 패턴을 만들지 않고 품질 보류한다.
2. 저점·고점 피벗은 좌우 각 2봉보다 엄격하게 낮거나 높아야 한다. 동률과 동시에 저점/고점인 바깥봉은 피벗에서 제외한다. 발생일과 확정일을 따로 기록한다.
3. 이미 확정된 가장 최근 저점을 종가가 처음 밑돌면 구조가 시작된다. 직전 종가는 그 지지 이상이어야 한다. 초기 59봉은 이전 구조를 확보하는 준비 구간이다.
4. 이탈 이후 지지보다 낮은 확정 저점 L0를 찾는다. 반등 상단 확정 전에는 더 낮은 확정 저점으로 갱신할 수 있다.
5. L0 뒤의 첫 확정 고점 중 깨진 지지보다 높은 고점을 상단 R로 고정한다. 손그림 매물대/추세선의 대용 정의다. 이후 상단을 유리하게 다시 그리지 않는다.
6. R의 고점 발생일 이후에 생긴 저점 L1이 L0보다 높고 R보다 낮으며 좌우 2봉으로 확정되면 **높은 저점 확인 / 돌파 대기** 단계다.
7. L1 확정일 다음 완료봉부터 종가가 R을 엄격하게 넘으면 **상단 종가 돌파 관찰**이다. 고가 접촉·종가 동률은 돌파가 아니다. L1 확정과 같은 봉 또는 그 전에 돌파하면 이 경로로 인정하지 않는다.
8. R 고정 이후 L0 아래 종가 이탈, L1 확정 이후 저가가 L1에 다시 닿거나 하회하면 구조를 종료한다. 같은 봉에서 저점을 훼손하고 상단도 돌파하면 저점 훼손을 우선하며 봉 내부 순서를 추정하지 않는다. 구조 시작 후 60봉, L1 발생 후 20봉을 넘으면 만료한다. 손절 체결을 뜻하지 않는다.

## 표본과 후속 결과

- 종목×관측 완료봉별 최초 스캔 원본을 보존한다. 같은 날짜 재실행은 덮어쓰지 않고 원본 변경을 오류로 기록한다.
- `종목 + 고정 구조 + 연구 실행 버전 + 단계`별 최초 관측만 추적한다. 돌파 대기 상태가 여러 날 반복돼도 그 단계의 표본은 1건이다. 고정 구조 식별에 이동하는 배열 인덱스는 쓰지 않는다.
- 높은 저점 확인 단계와 돌파 단계는 서로 겹치는 표본이며 분리 집계한다. 원래 최종 판정·전략 버전·연구 실행 버전도 나눈다. 위험 차단된 종목을 관찰하더라도 운영 차단은 해제되지 않는다.
- 해당 단계가 스캔에서 **처음 관측된 날의 종가** 대비 이후 1/3/5/10/20 완료봉의 종가 변화, 최대 상승·하락을 계산한다. 과거 피벗일로 소급하여 진입하거나 체결 수익률로 표시하지 않는다.
- 기준 종목의 고정 원본·수집 시각·수정주가 변경·미래 자료는 기존 엄격한 후속 검증을 재사용한다. 마지막 성공 결과는 갱신 오류 때도 보존하며 오류 표본은 현재 통계에서 제외한다. 미도달 구간은 0%가 아닌 미완료다.
- 추천이 없거나 다른 후속 단계가 실패해도 한국 예약의 독립 단계로 실행한다. TOP100에서 빠지거나 감사 원본 파일이 사라져도 등록된 동결 원본으로 추적한다. 완료 20봉 결과는 고정한다.
- 기존 저장 스캔의 재분석도 포함한다. 관측일·원본 수집 시각·연구 등록 시각을 보존하며 당시 추천이 있었다고 소급 주장하지 않는다. 효과나 수익성이 검증됐다는 뜻이 아니다.

## 사용법

한국 예약 실행에서 자동 등록·추적한다. 연구만 수동 갱신하려면:

```powershell
php bin/paper_higher_low.php --account=paper-kr-recovery-v1
```

기존 후속 추적이 저장한 가격 증거만 사용하려면 `--saved-evidence`를 추가한다. 일치하는 증거가 없으면 보류하며 네트워크 자료로 몰래 대체하지 않는다. 독립 재현용 `--prices=폴더`, `--source-dir=원본상태폴더`, `--as-of=ISO시각`도 지원하며 더 오래된 실행은 최신 결과를 덮어쓰지 못한다.

화면: **탈락 이유·연구 → 돌파 전 높은 저점형**

`paper_rr.php?account=paper-kr-recovery-v1&higher_low_research=1`

저장: `PAPER_STATE_DIR/higher-low-research/<계좌>/latest.json`, 실행 이력, `frozen/`, `evidence/`. 기존 계좌·엔벨로프·후속 장부는 수정하지 않는다. 연구 코드 변경은 자체 실행 버전으로 검출한다. 계좌 전략 지문은 유지한다.

검증: `php tests/prebreak_higher_low.php`, `python -m unittest discover -s tests -p 'test_*daily.py'`. 고정 정의의 경계·중복·미래 봉·실제 CLI/GET·가격 변경·원본 보존·예약 실패 격리를 검사한다.
