# 코스피·코스닥 지수 일봉

요청 구간은 2024-09-01~2026-10-08이다. 두 시장 모두 일봉을 받지 못했다. 확인일 종가와 최근 60거래일 단순평균을 비교할 자료가 없다. 60일은 이 연구의 가정이며 작성자 원문 규칙이 아니다.

## 접근

2026-11-16 16:11 KST에 거래일 2024-10-08 하루만 확인했다. 가격 본문은 저장하지 않았다. 기록은 `access.json`이다.

로컬에 있던 주식 일별매매용 키로 지수 API를 호출했고 401을 받았다. 이 응답만으로 지수 API 미승인, 키 만료·비활성 등 구체적인 인증 실패 원인을 구분할 수 없다. 계정의 인증키 유효 상태와 두 지수 API 이용 승인 상태는 별도 확인이 필요하다. 키는 기록하지 않았다. 공개 샘플 키로 본호출을 대신하지 않았고, 로그인 세션도 만들지 않았다. 날짜·종가 필드의 의미는 응답이 없어 확인하지 못했다. 공식 설명은 2010-01-04부터의 일별시세, 요청 인자는 기준일자 `basDd`다.

Open API 이용약관은 제3자 제공을 금지한다. 받은 원응답이 없으므로 Git에 둘 원본도 없다. `data/ohlcv`와 `data/cache`는 쓰지 않았다.

## 기존 부분 캐시

`data/cache/kospi_naver.json`은 18837바이트, sha256 `1d495adcea3f55da345b220f202a278398b30c77e3d1cf65149569b6a5ac18df`. 날짜 285개, 2025-06-02~2026-07-31로 요청 구간의 앞뒤를 덮지 않는다. 별도로 `data/type1-cache/intraday/^KS11_1mo_1d_closed_v2.json`과 `^KQ11_1mo_1d_closed_v2.json`에 코스피·코스닥 단기 자료가 있다. 앞선 조사에서 각각 2026-09-30~10-30의 21행으로 확인됐으며, 요청 구간과 60거래일 준비 기간을 충족하지 않는다. 공식 시계열이 없어 겹치는 날짜를 대조하지 않았고 캐시를 수정하지 않았다.

## 하지 않은 일

봉이 없어 정렬, 중복, 숫자가 아닌 값, 비양수 종가, 거래일 공백, 연구 달력과의 불일치는 검사하지 않았다. 빠진 날짜를 채우지 않았다. 236종목 보존 결과를 다시 계산하지 않았다. 1차·2차 기간을 새 검증 기간으로 부르지 않는다. 신호 분류, 성과, 화면은 없다.
