# 1번 계좌용 플레이북 (노라무식 → 변환)

## 1번 계좌 전제

- 국장: SK하이닉스, 삼성전자, 유진테크
- 미장: 마이크론
- ISA/연금/IRP: S&P500 + AI/HBM ETF + 단기채
- 성격: **메모리 집중 중장기**. 레버리지 단타 계좌가 아님

## 가져올 것 / 버릴 것

| 노라무 | 1번 계좌 |
|--------|----------|
| 차트 구조(쌍봉·슈팅·저점상향·절반지지) | **그대로 사용** (진입·비중 조절 필터) |
| 프로그램 타점 숫자 | 보조 점수화 (`pullback_long_score`) |
| 레버/인버스/양빵 | **사용 금지** |
| 3% 초단기 손절 단타 | 구조 무효화(스윙 저점 이탈) 시에만 비중 축소 |
| “따라하지 마라”식 저점 스캘핑 | FOMO 금지, 눌림만 |
| 애매하면 양빵 | 애매하면 **현금/관망** |

## 운영 규칙

1. **신규 매수 조건**
   - 최근 하방 슈팅(급락) 이후
   - 저점이 직전 저점보다 높음
   - 가격이 최근 스윙의 절반 되돌림 ±4% 이내
   - 점수 70+ 일 때만 가용현금 10~20% 분할

2. **보유 중**
   - 점수 35 미만 + 저점 갱신 실패 → 반등 시 일부 축소 검토
   - 펀더(메모리 업황)와 충돌하면 차트만으로 풀매수 금지

3. **절대 금지**
   - SOXS/코루/2배 상품으로 1번 계좌 헤지
   - 장중 고점 추격
   - “오늘 반등하니까” 일시 몰빵

4. **주간 루틴**
   - `php bin/score_symbol.php MU`
   - `php bin/score_symbol.php SNDK`
   - 국·미장 핵심 종목 점수와 무효화 라인만 메모
