# 국내 개별주 스윙 연구: 첫 작업 지침

작성일: 2026-11-12. 범위: 국내 개별주, 며칠~수주 보유.

## 사용자 확정: 별도 탭과 독립 기능

노라무 사이트 안에 **새로운 ‘스윙 연구’ 탭(가칭)**을 추가한다. 기존 유형1 화면이나 추천 결과에 끼워 넣지 않는다. 별도 페이지·연구 모듈·설정·결과 저장 영역을 사용하고, 기존 계좌·예약·전략 실행 경로에 연결하지 않는다. 기존 화면의 변경은 새 탭으로 이동하는 메뉴 링크 추가에 한정한다.

기존 코드는 비교와 참고 대상으로 삼는다. 입출력이 명확하고 저장·계좌 갱신 부작용이 없는 공통 계산만 필요한 경우 재사용한다. 기존 전략 엔진 전체를 호출해 그 결과를 새 이름으로 보여 주거나, 기존 전략 설정을 새 연구의 설정으로 공유하지 않는다. 새 연구 규칙과 버전은 독립적으로 관리한다.

이미 확보한 가격 자료는 읽기 전용 입력으로 활용할 수 있다. 기존 스냅샷·장부·`breakout-watch`에는 쓰지 않는다. 새 탭 조회도 파일 생성·수집·복구·갱신을 일으키지 않는다. 첫 단계는 저장하지 않는 진단 화면이며, 향후 결과 저장이 필요하면 전용 영역에만 저장한다.

## 조사 범위와 결론

사용자가 제공한 FMKorea 글 43개의 본문을 확인했다. 일부 핵심 그림도 확인했으나 전체 댓글과 모든 첨부 차트를 분석하지 않았다. 실제 체결 기록과 수익률을 검증하지 않았으며, 모델 학습이나 전략 성능 검증을 수행한 것은 아니다.

글은 개별 종목 선정 공식보다 지수·선물·ETF의 시장 환경, 지지·저항, 돌파 후 재시험, 전망 무효화에 집중한다. 국내 개별주 일봉으로 옮기는 부분은 별도의 연구 가설이다. 글쓴이와 동일한 매매를 재현한다고 표현하지 않는다.

첫 실험은 **돌파 후 지지 확인을 기다리고, 가까운 저항 때문에 보상이 부족하면 거래하지 않는 일봉 전략**이다. 하락 중 지지선 반등 매수는 별도 전략이므로 이번 실험에 섞지 않는다. 기존 계좌·예약·원본·매매 규칙은 변경하지 않는다.

## 근거가 되는 글

- [9/21: 진입 위치와 손익비](https://www.fmkorea.com/10361662895): 저항 바로 아래 추격보다 지지 재시험을 기다린다. 반복된 지지 시험도 고려한다.
- [10/13: 손절을 따르지 않은 사례](https://www.fmkorea.com/10441837366): 전망과 실제 실행은 다를 수 있다. 성공 사례만으로 실력을 평가하지 않는다.
- [10/21: 돌파와 재시험](https://www.fmkorea.com/10469641279): 돌파 이후 지지 확인, 여러 저항 근거의 중첩을 다룬다.
- [10/23: 지지·저항의 역할 전환](https://www.fmkorea.com/10474978413): 깨진 지지는 저항이 될 수 있고, 저항 부근에서는 일부 청산을 고려한다.
- [10/30: 실패한 재시험](https://www.fmkorea.com/10499380861): 이전 상승 전망도 가격이 조건을 깨면 변경한다.
- [11/2: 가격과 수급](https://www.fmkorea.com/10510141631): 수급 해석만으로 가격의 무효화 조건을 무시하지 않는다.
- [11/5: 거래하지 않는 선택](https://www.fmkorea.com/10520904081): 과거 지지 가격에 다시 도달했다고 같은 매수 조건이 성립하지 않는다.
- [11/11: 이벤트와 재진입](https://www.fmkorea.com/10542551772): 이벤트 전 청산·이후 재시험이라는 조건부 접근. 직감 표현은 그대로 규칙화할 수 없다.
- [11/12: 익절과 재시험](https://www.fmkorea.com/10545389784): 다음 저항, 돌파 이후 역할 전환, 일봉 재시험을 설명한다.

본문의 사후 성공 보고는 사전 예측과 구분한다. 수정된 본문 전체가 최초 게시 시점에 존재했다고 가정하지 않는다. 글에 나오는 확률 숫자는 측정된 적중률로 사용하지 않는다.

## 기존 구현과 겹치는 부분

- `src/BreakoutRetest.php`: 완료 일봉의 박스 돌파, 거래량, 재시험, 확인 봉, 손절·목표·최소 손익비, 주문 유효기간이 이미 있다. 우선 비교 기준으로 사용한다.
- 현재 ATR 배수·거래량 배수·손익비 1.5·유효기간 등은 기존 시스템의 가설이다. 글쓴이가 정한 수치라고 표시하지 않는다.
- `src/ChartPlanEngine.php`: 여러 가격 전략과 문맥을 결합한다. 새 엔진을 만들기 전에 기존 출력과 호출 관계를 확인한다.
- `src/TrendContext.php`: 완료 일봉과 주봉의 이동평균 기반 문맥이다. 일목균형표나 시장 지수 문맥과 동일하지 않다.
- `bin/paper/TargetResearch.php`: 저항·목표 관련 기존 계산을 재사용할 수 있는지 확인한다.
- `bin/type1/BreakoutRetest.php`: 다음 거래일 5분봉 관찰이다. 일봉 스윙 전략과 혼동하지 않는다.
- 유형1 분류·`breakout-watch`는 관찰 자료다. 기존 분류를 검증된 매수 순위로 취급하지 않는다.

## 자료와 계산의 주의점

1. 개별주 선정 공식은 본문만으로 확정할 수 없다. 기존 유동성 기반 후보군을 임시 연구 대상으로 사용하되 이것이 별도 설계 결정임을 표시한다. 오늘의 TOP100을 과거 전체에 적용하지 않는다.
2. 지수·환율·외국인 선물·옵션 자료는 기준 시점에 실제 확보한 자료만 사용한다. 없으면 미확정으로 둔다. 가격만으로 외국인 의도나 옵션 감마를 만들어내지 않는다.
3. 일목 선행스팬 B는 52개 기간의 최고·최저 중간값을 26개 기간 앞으로 표시한 값이다. 투자자 평균 매입가가 아니다. 일봉과 주봉의 기간 및 표시 이동을 구분한다. [TradingView 공식 설명](https://www.tradingview.com/support/solutions/43000589152-ichimoku-cloud/)
4. 옵션 미결제약정은 미청산 계약 수이며 매수·매도 양쪽이 존재한다. 그 수만으로 외국인 방향이나 딜러 포지션을 확정할 수 없다. [OIC 설명](https://www.optionseducation.org/referencelibrary/faq/general-information)
5. 마감 이후 생성한 신호의 체결 가능 시점은 다음 거래일부터다. 같은 봉을 보고 그 봉의 저가에 샀다고 가정하지 않는다. 손절선은 갭 하락 때의 체결가를 보장하지 않는다.

## 그록에게 전달할 다음 작업 프롬프트

국내 개별주를 며칠~수주 보유하는 연구 기능의 첫 단계를 진행해줘. 먼저 `docs/work-log.md`, `docs/ronny-swing-research.md`와 최신 코드를 읽어줘.

목표는 노라무 안에 별도 ‘스윙 연구’ 탭을 만들고, Ronny 글에서 확인한 '돌파 → 재시험 → 지지 확인, 다음 저항까지 여유가 없으면 대기'를 독립 연구 기능으로 검증하는 것이다. 위의 '사용자 확정: 별도 탭과 독립 기능'을 우선 적용해줘. 첫 PR은 별도 탭과 읽기 전용 진단까지로 제한하고 자동 주문은 만들지 마.

1. `src/BreakoutRetest.php`, `src/ChartPlanEngine.php`, `src/TrendContext.php`와 목표·저항 계산을 읽고 실제 호출 경로를 확인해줘. 원문에 명시된 원칙, 기존 구현의 수치 가설, 추가 자료가 필요한 조건을 구분해줘. 기존 전략은 비교 대상으로 두고, 부작용 없는 공통 계산만 재사용 여부를 판단해줘. 기존 전략의 수치 조건을 새 전략으로 자동 채택하지 마.
2. 별도 페이지·연구 모듈로 읽기 전용 진단을 구현하고 사이트 메뉴에 새 탭을 연결해줘. 첫 화면에는 연구 단계임을 표시하고, 자료가 없으면 빈 상태와 부족한 자료를 설명해줘. 운영 수집·계좌·예약·장부 갱신은 호출하지 마. 임시 폴더와 고정 자료로 검증하고 운영 파일을 만들거나 보충하지 마. 검증용 종목을 운영 결과처럼 표시하지 마.
3. 종목·판단 시각·자료 기준일, 돌파 기준선, 재시험 상태, 진입 조건, 무효화 가격, 다음 저항/목표와 산출 근거, 예상 손익비, 대기 사유를 출력해줘. 기존 출력에 없는 값을 임의로 생성하지 마. 시장 지수 문맥과 개별 종목 추세도 구분해줘. 이 단계는 수익 확률이나 검증된 추천 점수를 출력하지 않아야 해.
4. 최소 검증 사례는 돌파만 발생, 재시험 후 확인, 지지 이탈, 저항이 가까워 손익비 부족, 자료 부족이다. 판단일 이후 봉을 추가해도 당시 진단이 달라지지 않는지 확인해줘. 재사용한 공통 계산은 기존 함수와 결과가 일치하는지 검증해줘. 실제 브라우저에서 새 탭 이동과 운영 CSS를 확인하고, 조회 전후 기존 자료가 변경되지 않았는지도 확인해줘.
5. 기존 전략 파일이나 버전 해시에 포함된 파일을 변경해야 한다면 먼저 그 영향을 설명하고, 가능한 한 별도 진단 도구에서 해결해줘. 고정 기록의 해시를 재발급하거나 버전 검사를 완화하지 마.
6. 코드 변경은 작은 PR로 올리고 병합하지 마. 기존 로컬 변경은 보존해줘. 완료 보고에는 재사용한 기능, 실제 실행한 검증, 자료 부족으로 못 본 조건, 다음 작업 하나를 적어줘.

이번 범위에서 제외: 기존 매매 조건 변경, 실계좌·모의계좌 갱신, 예약 변경, 운영 수집, 자동 주문, 옵션 감마 추정, 새 모델 학습, 여러 파라미터 최적화, 과거 수익률을 근거 없이 제시하는 기능.

## 이후 순서

별도 탭의 진단이 정확하면 시간 순서가 보존된 자료로 기존 전략과 비교한다. 비용·슬리피지·갭·같은 봉 안의 체결 순서 불확실성을 반영한다. 이미 연구에 쓴 기간을 미사용 검증 기간이라고 부르지 않는다. 이후 새로 들어오는 자료에서 모의 관찰한 결과를 보고 이 탭에 추천 기능을 추가할지 결정한다. 기존 노라무 매매 시스템과의 독립성은 유지한다.
