# 현금 거래비용 민감도

슬리피지 5bp는 그대로 두고, 현금에서 빼는 매수·매도 비용만 각 10bp / 20bp / 30bp로 바꿨습니다. 끝난 거래에서 비용만 뺀 것이 아니라 계좌를 처음부터 다시 진행했습니다.

운영 계좌·캐시·원본 데이터셋·기존 full-v2는 쓰지 않았습니다. 일봉 범위 밖 모형 가격 9건도 보정하지 않았습니다.

## 실행 전 검증

- 기존 `tests/account_replay.php`와 추가한 비용 고정 사례: 통과. 20bp는 수량이 줄고 예약 현금이 늘며, 30bp는 10bp에서 들어가던 1주를 거절합니다. 매수·매도 비용은 한 번씩만 붙고 슬리피지를 현금으로 다시 빼지 않습니다. 같은 계좌를 다시 돌리면 사건이 늘지 않습니다. 수수료가 다른 설정으로 이어 하면 `Account config changed`로 거절됩니다.
- 기준 10bp 재현 대 full-v2: 이전·최근 모두 주문·체결·청산·수량·현금·평가금액이 같습니다. 이전 통과=True, 최근 통과=True.
- 달라진 메타데이터: 계좌 ID에 `fee10` 접미사가 붙어 config_hash가 바뀌고, `PaperPortfolio.php` 변경으로 전략 지문이 바뀌며, 연구 메타에 `cash_fee_bps`/`slippage_bps`가 들어갑니다. 경제 숫자는 그대로입니다.
