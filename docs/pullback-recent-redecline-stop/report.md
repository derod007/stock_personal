# 최근 10봉 저점 손절 대 최근 재하락 고점 이후 저점 손절

상승 눌림 최종 선택 157건(이전 75, 최근 82)에서 **체결 뒤 손절만** 바꾼 비교다. 신호·주문·진입일·체결가·목표·보유·비용·진입 전 취소 규칙은 그대로이고, 대안 손절은 신호일에 고정했다. 운영 전략은 바꾸지 않았고 반영 여부도 판단하지 않는다. [고정 프로토콜](protocol.md)은 결과 계산 전에 해시로 고정했다.

**탐색 연구다.** 같은 자료를 PR #55~#64에서 이미 여러 번 보았고 기존 거래 결과도 알고 있었다. 블라인드나 독립 검증이 아니다. 수익률은 거래별 순수익률의 평균이며 계좌 수익률이 아니다. 같은 종목·인접일은 독립 표본이 아니다.

## 결론

- **이전 기간**: 대안 손절이 기존과 같은 수준인 사례가 적용 가능 72건 중 58건이라 거래가 같다. 공통 종료 64건에서 평균 -0.40% → -0.24%, 개선 7 · 악화 1 · 동일 56. 수준이 실제로 다른 14건만 보면 평균 +0.60% → +1.32%.
- **최근 기간**: 대안 손절이 기존과 같은 수준인 사례가 적용 가능 81건 중 66건이라 거래가 같다. 공통 종료 69건에서 평균 +1.03% → +0.99%, 개선 3 · 악화 2 · 동일 64. 수준이 실제로 다른 12건만 보면 평균 +4.02% → +3.80%.
- 평균 변화는 이전 기간 +0.16%p(상승), 최근 기간 -0.04%p(하락)로 방향이 서로 다르다. 차이는 소수의 거래가 만든다. 이 결과로 대안이 낫다 또는 못하다고 말할 수 없다. 운영 변경 근거로 쓰지 않는다.
