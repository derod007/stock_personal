# 이전 기간 recovery_close 계좌 비교 v1

기간 2024-10-08~2025-10-02, 243세션. KRX 일별 TOP100 100종, 합집합 1248종의 v2 일봉과 전체 섹터 맵 사용.
PR #84 조건을 그대로 고정한다. 상승 눌림 recovery_close 한 조건만 제거하며 나머지 패턴 선택·상위 추세·위험·비용·한도·청산은 유지한다.
운영 src/config/지문, PR #84 실행 도구 및 최근 결과는 변경하지 않는다. #84·#85 의존성을 새 작업 브랜치에서만 통합한다.

## 기준과 검증

최근 기간의 `hist-rc-account-v1-baseline`을 읽기만 하여 PR #76 고정 거래·일별 기록·요약 전체와 대조하고 이벤트 장부 대사한다.
최근 원본을 새로 재시뮬레이션하는 검사는 아니다. 최근 엔진 경로 회귀 테스트도 유지한다.

이전 기간에는 정답 수익률이나 PR #76과 같은 기준 장부가 없다. 따라서 두 개의 새 논리 계좌 각각을:
1. 기본 8세션 소규모 → 나머지 날짜로 분할 실행한다(내부 3세션 트랜잭션).
2. 검사용 별도 경로에서 243세션을 단일 트랜잭션으로 실행한다.
3. 시각 필드만 제외한 전체 이벤트와 최종 상태 해시가 동일한지 대조한다.
4. 이벤트 현금·수량·비용·실현/평가 장부와 모든 주문의 당일 TOP100·as-of 엔진 계획을 검증한다.

기준 계좌 243세션 완료, 장부/주문 검증, 분할/일괄 일치 전에는 대안을 실행하지 않는다.
대안도 같은 검증을 거친 뒤에만 comparison.json을 생성한다. 동일 엔진 기반이며 독립 전략 구현은 아니다.
완료 날짜 목록은 선정 날짜 243개와 정확히 일치해야 한다. 정지나 봉 누락을 임의 건너뛰지 않는다.
검사용 계좌는 같은 논리 계좌 ID를 쓰되 별도 `-check` 디렉터리에 저장한다. 이로써 상태 해시까지 비교한다.
단일 트랜잭션 검사 중 중단되면 체크 경로의 완료되지 않은 기록을 이어서 성공으로 세지 않는다.

## 고정 및 저장

`docs/recovery-close-prior-account/frozen-inputs.json`이 PR #85 공개 입력의 LF 해시를 고정한다.
로컬 자료는 verify 통과, v2 종목군의 공개 JSON 내용 일치, 기간 메타데이터 일치가 필요하다.
원본 dataset.json/universe.json 및 봉별 해시는 최초 실행 전 `inputs.json`에 고정한다. 이 최초 고정은 공개 원본 봉 해시와의 독립 대조를 뜻하지 않는다.
이후 데이터·연구 코드·프로토콜·설정·PHP 버전 변경 시 이어하기를 거부한다. 과거 해시를 고치지 않는다.

새 계좌 경로: PAPER_STATE_DIR/history-account/hist-rc-prior-v1-{baseline,baseline-check,variant,variant-check}/account-replay.json
산출: PAPER_STATE_DIR/history-research/recovery-close-prior-account-v1/
운영·최근 계좌나 기존 원본에 쓰지 않는다. 재수집 없음. 마지막 보유 강제 청산 없음.

## 해석

처음 122세션과 나머지 121세션을 구분하되 보유는 경계에서 이어진다.
추천·주문·체결·종료·보유·취소와 거래별 추가/누락/수량 차이, 자산·낙폭을 비교한다.
현재 업종을 과거에 적용했고 수정주가 기준은 미확인이다. KRX 연구 TOP100은 운영 다음 순위와 다르다.
이전 고정 종목군 연구를 이미 본 기간이므로 완전한 블라인드/독립 미관측 검증이라고 부르지 않는다.
조건 재조정·보유 한도 확대·운영 적용·PR 병합은 이번 작업에 포함하지 않는다.
