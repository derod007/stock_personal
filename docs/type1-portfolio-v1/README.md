# 유형 1 별도 포트폴리오 연구 v1

상태: 구현·합성 검증 및 두 기간 실행 완료. 최근 기간 완주, 이전 기간 데이터 문제로 중단. 결과는 `report.md`. 유형 1의 사후 선택과 이미 연구한 두 기간의 재사용은 그대로다.

## 고정 프로토콜

- PR #106의 6개 중심을 입력으로만 읽는다. 재학습·유형 선택·조건 최적화 없음.
- 종목별 TOP100 비중첩 T..T+20 관찰 구간. T까지 완료된 60봉으로 분류한다.
- 전체 유형 대조군과 유형 1을 각각 독립적인 새 연구 포트폴리오에서 비교한다.
- T+1 시가 매수, 5% 손절, 15% 목표, T+20 종가 만기. 비용은 기존 v2와 같은 매수 1.0015 / 매도 0.9985 배수.
- 동일 봉 손절·목표는 손절 우선이며 실제 장중 순서는 미확정. 시가가 손절 아래면 시가 청산. 목표는 목표 가격 청산.
- 운영 설정의 초기자금 1억원, 최대 4종목, 종목당 위험 1%, 종목 비중 20%, 섹터 40%, 총 계획위험 3%를 읽는다. 운영 설정은 수정하지 않는다.
- 같은 날 종목코드 오름차순. 결과·유형 내 거리·미래 수익으로 순서를 바꾸지 않는다.
- 수량은 **진입일 시가에** 계좌의 시가 평가액·현금·기존 위험·섹터 사용량으로 결정한다. 한도별 금액의 최솟값을 사용하고 정수 주 단위로 내린다.
- 신호일에는 매수 의향만 저장하는 연구 모형이다. 대기 의향의 예약금은 0이며 모든 시가 진입을 처리한 뒤 당일 봉 청산을 처리한다. 따라서 당일 장중 매도대금을 같은 날 시가 매수에 쓰지 않는다.
- 이는 운영 `PaperPortfolio`의 전일 예약 지정가 주문을 그대로 재현하는 엔진이 아니다. **한도 수치와 한도 계산 구조를 공유하는 별도 다음 시가 연구 모형**이다. 운영 배포 검증으로 해석하지 않는다.
- 업종 미확인은 하나의 `unclassified` 버킷으로 합산한다. 기존 전체 업종표는 현재 분류를 과거에 적용한 자료이며 당시 업종 복원이 아니다. 맵 파일 SHA256을 남긴다.

## 미래 데이터와 누락

PR #106의 차트 집계는 미래 20봉이 완전한 표본만 포함했다. 이 도구는 주문 전에 미래 봉 존재 여부로 후보를 빼지 않는다. 그러므로 표본 수가 달라질 수 있다.

T일 완료봉·60봉 이력이 없으면 그 시점에서 제외한다. 기간말 T+20을 관찰할 수 없는 구간은 종료일이 정해진 연구 범위 규칙으로 제외한다. 보유 또는 당일 진입 의향 종목의 봉이 없는 날은 해당 비교군을 중단한다(한도로 차단될 후보라도 봉 누락을 숨기지 않는 보수적 처리).

중단 시 전체 기간 수익률은 `null`, 종료 코드는 2다. 부분 기간의 손익·MDD를 완주 결과와 비교하지 않는다. `common_through`는 공통 기록 범위만 나타내고, 짝 비교 결과가 아니다. MDD는 종가 계좌 평가액 기준이며 장중 최대손실이 아니다.

## 실행

경로 인수를 받아 Windows 경로를 하드코딩하지 않는다. 새 출력 폴더만 허용하며 기존 출력은 덮어쓰지 않는다.

```bash
python -m unittest tests.test_top100_type1_portfolio -v
python docs/research/top100_type1_portfolio.py \
  --centers /path/to/original/centers.json \
  --candidates docs/historical-top100-20241008-20251002/candidates.json \
  --dataset /path/to/kr-dated-amount-top100-20241008-20251002-v2 \
  --sector-map docs/historical-top100-20241008-20251002/sector-map-full-v2.json \
  --output /path/to/new/research-type1-prior
```

최근 기간도 `20251008-20261008` candidates·dataset·sector-map으로 별도 실행한다. 운영 장부·계좌 CLI를 호출하지 않는다.

`results.json`에 설정, 입력·봉 파일 SHA256, 연구 ID, 전체/유형1 신호·체결·차단 사유, 주문 직전 현금·보유·위험·섹터 사용량, 거래별 가격·수량·손익·보유봉, 일별 계좌 평가액, 수익률·MDD·동시 보유·투입 비중을 저장한다. 유형별 단순 평균과 계좌 수익률을 구별한다.
