# 오늘 달라진 종목

`paper_changes.php?account=paper-kr` 또는 모의 계좌 **오늘 변화** 탭. 날짜는 한국 시간이며 수동 프로필을 선택할 수 있습니다. 기존 저장 자료를 읽기만 하므로 신규 예약 작업이나 재계산은 필요하지 않습니다.

- 판정 변화: 출처별 직전 실행에서 같은 종목의 ready 값이 바뀐 경우만 새 확인/해제로 표시합니다. 직전 자료에 없거나 조회 실패면 첫 관측 확인으로 분리합니다. TOP100에서 빠진 종목을 확인 해제로 만들지 않습니다. 동일 봉 재실행은 표시하며 전략 동일성은 미확인입니다.
- 수동: 같은 프로필·시장 범위의 완료봉 분석만 비교합니다. 장중 잠정과 완료봉 대체 자료는 비교 불가로 취급합니다. 완료봉 감사와 수동은 서로 비교하지 않습니다.
- 개별 추천: 감사 원본 해시·파일·종목·판정봉·추적 정책이 일치하는 baseline 후속 모의 결과만 사용합니다. limit 연구는 제외합니다. 체결·청산은 저장된 모형 거래일 기준입니다.
- 만료·취소: 발생일 필드가 없는 기존 결과는 보존 후속 이력에서 처음 확인된 생성일에 표시합니다. 실제 만료/취소일이 아닙니다. 오래된 종료 상태를 매일 다시 알리지 않으며 latest.json 중복도 제외합니다. 과거 이력을 삭제했다면 남아 있는 기록 중 최초일입니다.
- 모의 계좌: 해시 검증된 계좌 장부의 fill/exit/order_cancelled를 별도 표시합니다. 개별 추천 모형 결과와 합산하지 않습니다.
- 오류: 감사/수동 파일을 읽지 못하면 해당 출처의 전환 비교를 보류합니다. 후속 이력 오류는 만료·취소 최초 확인일 집계를 보류합니다. 날짜·상태가 없으면 추정하지 않습니다.

상단 종목 수, 확인 후 손익비 탈락, 연구 포함은 선택일 최신 감사 원본의 요약입니다. 연구 포함은 추천 수·체결 수가 아닙니다. 선택일 파일이 없으면 자료 없음으로 표시합니다. 최종 후속 평가 시각은 실제 이벤트 발생일과 별개입니다.
