# 유형1 + 20일 고가 돌파 후보

①을 관찰용 후보 보기로 개발한 기능이다. 기존 자동 추천/매매 조건을 교체하지 않는다.

- `type1_scan.php?scope=breakout`: 현재 조회 TOP100의 유형1 중 동일 완료봉에서 종가가 직전20봉 고가를 넘은 종목.
- `type1_scan.php?scope=all`: 유형1 전체와 돌파 상태·기준선·분석 종가의 거리.
- `type1_breakout.php`: 마지막 마감 스냅샷 해시를 검증한 후 당시 봉으로 계산한 돌파 후보. 기본 돌파 확인만 표시; 전체 보기 가능. 외부 시세 조회·장부 쓰기 없음.

장중 미완료봉의 돌파와 전일 유형1을 섞지 않는다. 유형1 분석 기준일과 돌파 기준일이 같아야 confirmed=true이다. 현재 조회 순위는 당일 최종 TOP100임을 보장하지 않는다. 마감 스냅샷도 제공자 순위 거래일 미확정 정보를 유지한다.

유형1은 동일한 고정 중심 사용. 20봉 조건은 PR141 표시 계산 사용. 자동 주문·추천점수·기존 고정 관찰의 다음시가/손절5%/목표15%/20봉 규칙은 변경하지 않는다.

이 목록은 **날짜별 조건 일치 후보**다. 연구의 같은 종목 재진입 간격·중복 거래 제외·자금 한도를 적용한 주문 목록이 아니다. 마감 고정 후보 화면의 신규 관찰 여부로 필터하지 않으므로 처음 유형1 등장 후 나중에 돌파한 종목도 표시 가능하다.

과거 연구: 두 기간 독립 실행 평균 +0.64%/+1.21%, 그러나 반기별 음수 및 기존 진입일 고정 필터의 이전기간 음수. 수익성 확정 아님. 이 기능은 자동 선택 목록으로 개선할 첫 단계이며 연구 성과를 계좌 수익률로 표시하지 않는다.

검사: `php tests/type1_breakout.php` 및 기존 type1_scan/type1_tracking/type1_tracking_ui/breakout20 검사. 제공된2026-10-29 마감 복제본에서100대상95분류72유형1,종가돌파0. 파일해시불변 확인. 원본 파일을 Git에 포함하지 않는다.

## 진입 판단표
- 스캔과 마감 화면: 판단 종가의 직전20봉 고가선 대비 거리 및 최근 확정 저점까지 변화율.
- 확정 저점: 판단일 포함 최근20봉 안에서 좌우2봉보다 저가가 엄격히 낮은 가장 최근 봉. 우측2봉도 당시 완료되어야 하며 동률·미확정 저점은 제외. 매매 조건이 아닌 참고 가격 정의다.
- 마감 화면 날짜 선택(day=YYYY-MM-DD): 원래 스냅샷으로 분류/기준선/저점을 계산. 다음 시가만 최신 해시검증 스냅샷의 정확한 다음 거래일 봉을 사용한다. 이후 가격으로 당시 저점을 바꾸지 않는다.
- 다음 날짜는 저장 KOSPI/KOSDAQ 일봉 합의 달력 기준이며 거래소 공식 휴장표 독립 대조는 없다. 봉 누락/오류/미완료/합성이면 미확정, 이후 날짜로 대체하지 않는다. 조회 시점 장중 시가 제공 기능이 아니며 마감 수집 후 반영된다. 최신 스냅샷에서 종목이 사라지면 시가도 미확정이다. 공급자 사후 수정 가능성과 자료 저장일을 표시한다.
- 갭=(다음시가/판단종가-1)*100, 기준선 대비=(가격/기준선-1)*100, 저점까지=(저점/가격-1)*100. 비용 제외 가격 변화이며 손절/손실 상한을 의미하지 않는다.
- 새 장부/외부 조회/자동 주문 없이 기존 스냅샷만 읽는다. 기존 독립 추적 규칙은 불변.
- 신규13개 포함 PHP164개 검사 통과. 실제 외부 시세 및 브라우저 시각 검증 미실시.
