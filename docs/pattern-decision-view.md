# 패턴 자체 판정과 공통 차단 읽기

- 종목 상세의 간단/분석 모드 모두 차트 구조 점수의 항목별 배점·가감·근거를 표시합니다. 점수는 승률이나 진입 확정 기준이 아닙니다.
- 두 패턴을 모두 통과해야 한다는 뜻이 아닙니다. 원래 패턴 상태, 엔진이 선택한 패턴, 선택 이후 최종 상태를 구분합니다.
- 공통 차단은 선택된 계획의 기록입니다. 선택 안 된 패턴의 가상 최종 판정을 만들지 않습니다. 미평가 조건은 통과로 보지 않습니다.
- 장중 점수는 진행 중인 당일 자료를 사용합니다. 패턴 표는 마지막 완료봉의 별도 참고이며 기준 시각을 표시합니다. 오늘 진입 신호가 아닙니다.
- 마감 감사 로그의 `analysis.plan.diagnostics.patterns`와 `patterns[].exclusion_reasons`를 읽습니다. 과거 로그·해시를 다시 쓰지 않습니다. 간략 원본에서 빠진 필드는 미기록으로 표시합니다.
- 새 수동 스캔 관찰 기록에는 `pattern_evidence`를 추가 보존합니다. 기존 기록에는 소급 생성하지 않으며 실제 주문이나 과거 체결을 만들지 않습니다.

## 새 글의 추천 패턴 편입에 대한 판단

`docs/fmkorea-10423117635.html`과 차트는 추세 붕괴 뒤 저항 회복·저점 상승의 시나리오를 설명합니다. 독립된 추천 패턴으로 발전시킬 수 있지만, 이번 표시 변경은 새 추천 조건을 추가하지 않습니다.

운영 편입 전에 저항의 선정 시점과 가격, 저점 확정 시점, 돌파 후 확인형과 돌파 전 저점 상승형의 차이, 각 경우의 손절·목표·손익비, 기존 큰 추세/위험 차단의 적용 범위를 고정해야 합니다. 확인에 미래 봉이 필요한 저점은 확인된 시점부터만 이용합니다. 기준은 특정 종목의 사후 상승에 맞춰 조정하지 않습니다.

기존 두 패턴과 같은 자료·비용·다음 봉 체결 규칙으로 결과를 비교한 후 별도 패턴의 추천 편입을 결정합니다. 조건 개수나 기존 구조 점수만으로 새로운 회복형의 진입을 확정하지 않습니다.
