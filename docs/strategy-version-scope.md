# 전략 버전 범위와 스캔 비교 가격

표시용 src 변경으로 모의 계좌가 중단되던 문제를 해결합니다. config/paper-strategy-files.json에 명시된 추천·품질·체결·위험 관리 의존 코드와 계좌 실행 코드, 부트스트랩, 버전 검증 코드만 해시에 포함합니다. ScanSnapshot 등 표시용 코드는 제외합니다. 의존 클래스가 추가되면 manifest도 추가해야 하며, CI가 누락된 참조를 검사합니다.

기존 all-src 버전은 두 개의 검증된 해시만 호환 목록에 등록했습니다. 각 버전의 근거 커밋은 config/paper-legacy-versions.json에 있습니다. 이전/현재 src 비교에서 매매 의존 파일은 동일하고 ScanSnapshot만 다름을 확인했습니다. 기존 계좌 실행부의 차이는 변경 상세 진단 추가와 버전 검증 교체이며 매매·입력 병합·중단 조건을 완화하지 않습니다.

호환 목록은 특정 새 전략 해시에만 연결됩니다. 이후 매매 코드가 달라지면 같은 과거 해시라도 자동 허용하지 않습니다. 확인 불가능한 버전·설정 변경·중단 계좌는 차단합니다. 알 수 없는 버전을 직접 호환 목록에 추가하거나 halted를 해제하지 마세요.

첫 정상 실행에서 검증된 기존 계좌에 strategy_fingerprint와 strategy_scope_verified 이벤트 하나를 추가합니다. 원래 version 식별자, 기존 snapshot, 주문, 보유, 현금, 손익은 유지합니다. 후속 snapshot에도 기존 version을 유지하므로 기존 비교 계좌의 실험 서명과 연결이 끊기지 않습니다. 매번 새 fingerprint로 실행 코드 일치를 확인합니다. 신규 계좌는 처음부터 새 범위의 version을 사용합니다. 비교 CLI도 동일 검증을 사용합니다.

## 적용

머지 후 main에서 git pull --ff-only. 기존 스케줄러 명령은 그대로 실행합니다. 지원되는 기존 계좌는 첫 정상 실행에 한 번만 검증 기록을 추가합니다. historical_revision으로 중단된 계좌는 이 업데이트로 재개되지 않습니다. 기존 실험의 candidate 설정과 실험 ID를 변경하지 마세요.

## 스캔 가격

저장과 비교가 같은 규칙을 사용합니다: 유효한 양수·유한 네이버 가격 → 유효한 기존 price 필드 → 값 없음. 비숫자·0·음수·무한대는 가격으로 사용하지 않습니다. price_source와 price_observed_at을 저장하고 review 결과에도 양쪽 출처/관측 시각을 제공합니다.

이는 전일 종가 대비가 아니라 이전 저장 스캔가 대비 오늘 스캔가입니다. 대체 price 필드는 분석 성공 시 차트 가격, 실패 시 원본 스캔 가격일 수 있으므로 row_price_fallback으로 표시합니다. 관측 시각은 스캔 보고서 생성 시각으로 거래소 체결 시각이나 실시간 보장을 뜻하지 않습니다. 이전 스냅샷의 출처가 없으면 legacy_unknown으로 유지합니다. 기존 기록을 네이버 값으로 재작성하지 않습니다. 화면의 기존 표시는 유지하고 저장 데이터/비교 결과에 메타데이터를 추가합니다.
