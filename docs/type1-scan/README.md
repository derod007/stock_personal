# 유형1 거래대금 스캔

`index.php`의 거래대금 스캔(코스피) 바로 옆에서 `type1_scan.php`로 이동한다.
기존 순위 클라이언트의 코스피·코스닥 통합 TOP100을 조회하고 유형1만 거래대금 순으로 표시한다.
종목 클릭은 기존 차트 분석으로 연결된다. `?refresh=1`은 가격 재조회, `?format=json`은 동일 결과 JSON이다.

## 분류

- 과거 연구의 고정 K=6 중심을 그대로 사용한다. 재학습하거나 점수 조건을 더하지 않는다.
- 완료된 최근 60일봉의 종가/마지막 종가와 거래량/평균 거래량을 각각 L2 정규화한 뒤 연결한다.
- 유클리드 거리 최소인 중심이 1이면 표시한다. 1은 성적 순위가 아니다.
- 조회 시작 시각 이후에 완료되는 봉과 미완료봉은 사용하지 않는다.
- 60봉 부족·중복·잘못된 OHLCV·합성봉·최신 완료봉이 144시간보다 오래된 경우는 평가 불가다. 잘못된 최근 봉을 과거 봉으로 대체하지 않는다.
- 144시간은 거래일 달력 검증이 아니다. 종목별 분석 날짜를 반드시 확인한다. 조회 순위·조회 가격과 완료봉 분석 종가는 시점이 다를 수 있다.

## 운영 경계

일별 모양 일치 목록이다. 연구의 20세션 비중첩 구간·재진입 간격·계좌 자금/업종/보유 한도는 적용하지 않는다.
매수 추천 점수 또는 자동주문 목록으로 연결하지 않는다. 기존 daily·설정·장부·전략 지문 대상 소스를 수정하지 않는다.
순위 및 가격은 기존 클라이언트를 사용한다. 별도 `data/type1-cache` 경로에 캐시를 저장하며 기존 공급자 폴백을 유지한다.
서버에서 해당 캐시 폴더 생성/쓰기 권한과 기존 시세 조회 의존성이 필요하다. 외부 조회 실패 시 평가 불가를 따로 표시한다.

## 검증

`php tests/type1_scan.php`

실제 가격 자료 대신 고정 중심으로 만든 합성 6유형을 Python 연구 코드의 `series60`/`assign`으로 계산한 정답과 비교한다.
미래/미완료 봉 제외, 부족/오류/중복/오래된 봉 차단, 순위 정렬, 오류 집계와 HTML 이스케이프를 검사한다.
중심 파일의 SHA256은 LF 줄바꿈으로 정규화하여 확인하므로 Windows 체크아웃에서도 동일하다.
