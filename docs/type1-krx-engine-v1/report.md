# KRX 유형1 연구 계좌 실행

새 연구 계좌 두 개를 각각 한 번 실행했다. 두 계좌 모두 참고가격 불연속으로 중단됐다. 1년 수익률은 미확정이다. 운영·원본·기존 장부·전략 조건은 변경하지 않았다.

## 같은 기간 비교

2023-07-03~2023-09-04 (45세션), 비용 반영·보유 평가손익 포함.

|계좌|평가수익률|최대낙폭|
|---|---:|---:|
|전체 유형|-10.18%|10.64%|
|유형1|+1.07%|4.93%|

이 짧은 공통 구간에서는 유형1이 상대적으로 나았다. 전체 기간 완주·독립 전진검증·운영 채택의 근거는 아니다. 미래 기간에서 만든 고정 중심을 과거 구간에 적용했다.

## 각 계좌의 실행 끝

|계좌|마지막 정상일|해당일까지 평가수익률|낙폭|체결/청산|중단일|
|---|---|---:|---:|---:|---|
|전체 유형|2023-12-26|-19.43%|22.75%|88/86|2023-12-27|
|유형1|2023-09-04|+1.07%|4.93%|25/22|2023-09-05|

기간이 다른 두 수익률을 직접 우열 비교하면 안 된다. 중단일에는 advance를 호출하지 않았으며 마지막 정상일까지만 평가했다. 연간수익률은 null이다.

## 정확한 중단 근거

- 유형1: 코스모신소재(005070.KS), 2023-09-05 **미체결 대기 주문**. 9/4 종가156,100원, 9/5 종가164,200원−전일비10,000원=비교가격154,200원. 기준가격 차이 원인 미확정. 실제 시가 전에 이를 알고 취소했다고 가정하지 않았다.
- 전체 유형: 유한양행(000100.KS), 2023-12-27 **보유 포지션**. 12/26 종가69,900원, 12/27 종가67,900원−전일비1,000원=비교가격66,900원. 원인 미확정. 가격·수량·현금 보정 없음.

다음 조사는 위 두 종목·날짜의 공식 기업행사/기준가격 변경 기록을 확보하는 것이다. 근거 없이 그날을 건너뛰거나 손실을 지우고 재실행하지 않는다. 현재 중단 판정은 PR112 데이터 해석 정책에 따른 것이며 가격 경보 자체가 전략 실패를 뜻하지 않는다.

## 입력과 검증

- 평가243세션, 준비123세션, 원본과 선정파일1,098개 해시 검사 통과.
- 입력 신호3,550개, 유형1 771개. 유형별 0:380 / 1:771 / 2:359 / 3:613 / 4:1020 / 5:407.
- 품질 보류359구간, 기간말323구간. 원본의 잘못된 OHLCV도 PHP 품질 검사에 보존.
- 현재 업종을 과거에 적용하는 가정. 이번 업종조회 미확인20개와 기존 미분류9개는 공통 unclassified. 이전 Yahoo 결과와 업종맵 바이트 동일 여부는 주장하지 않는다.
- KRX 단일 출처 `krx_tdd_ohlcv_adjustment_unverified`. Yahoo와 혼합·수정 없음.
- 기존 PHP 엔진 검사21개+KRX 연결 검사8개=29개 통과. 정책 Python 테스트7개 통과.
- 두 계좌 모두 현금 대사·주문 한도 검사 통과. 실행 전후 엔진·운영 설정·고정 프로토콜 해시 일치.
- 이번 연구는 기존 지정가 엔진 비교이며 다음시가 사이징 모형을 추가 실행하지 않았다.

## 재현

